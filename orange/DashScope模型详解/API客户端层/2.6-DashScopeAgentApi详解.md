## 一、类概述

### 1.1 设计目的

`DashScopeAgentApi` 是专门用于与阿里云百炼Agent应用服务通信的API客户端。它支持Agent应用的同步和流式调用，集成了会话管理、记忆、RAG、多模态输入等高级功能。

### 1.2 核心职责

```
┌─────────────────────────────────────┐
│  DashScopeAgent                     │
│   (Agent应用封装)                    │
└──────────────┬──────────────────────┘
               │
               ↓
┌─────────────────────────────────────┐
│  DashScopeAgentApi (本类)           │ ← 本文档介绍的核心
│  - 同步/流式调用                     │
│  - 会话管理                          │
│  - RAG集成                           │
│  - 多模态输入                        │
│  - 思维链输出                        │
└──────────────┬──────────────────────┘
               │
               ↓
┌─────────────────────────────────────┐
│  DashScope Agent Application        │
│  (阿里云百炼Agent应用服务)           │
└─────────────────────────────────────┘
```

### 1.3 核心特性

| 特性 | 说明 |
|------|------|
| **双模式调用** | 同步 + 流式 |
| **会话管理** | session_id管理多轮对话 |
| **记忆机制** | memory_id持久化上下文 |
| **RAG集成** | 知识库检索增强 |
| **多模态输入** | 支持图像输入 |
| **思维链输出** | 可观察Agent推理过程 |
| **文档引用** | 返回RAG引用的文档片段 |
| **工具调用** | 集成外部工具 |

### 1.4 Agent应用模式

```
Agent应用类型：
├── 简单对话型：直接问答
├── RAG增强型：基于知识库回答
├── 工具调用型：可调用外部API/函数
└── 多模态型：支持图文混合输入
```

## 三、核心功能

### 3.1 同步调用

**方法签名**：
```java
public ResponseEntity<DashScopeAgentResponse> call(DashScopeAgentRequest request)
```

**功能**：同步调用Agent应用，等待完整响应

**实现逻辑**：
```java
public ResponseEntity<DashScopeAgentResponse> call(DashScopeAgentRequest request) {
    String uri = "/api/v1/apps/" + request.appId() + "/completion";
    return restClient.post()
        .uri(uri)
        .body(request)
        .retrieve()
        .toEntity(DashScopeAgentResponse.class);
}
```

**URI格式**：
```
POST /api/v1/apps/{app_id}/completion
```

**使用场景**：
- 简单问答
- 不需要实时反馈
- 短对话

---

### 3.2 流式调用

**方法签名**：
```java
public Flux<DashScopeAgentResponse> stream(DashScopeAgentRequest request)
```

**功能**：流式调用Agent应用，实时接收响应片段

**实现逻辑**：
```java
public Flux<DashScopeAgentResponse> stream(DashScopeAgentRequest request) {
    String uri = "/api/v1/apps/" + request.appId() + "/completion";
    return webClient.post()
        .uri(uri)
        .body(Mono.just(request), DashScopeAgentResponse.class)
        .retrieve()
        .bodyToFlux(DashScopeAgentResponse.class)
        .handle((data, sink) -> {
            sink.next(data);
        });
}
```

**使用场景**：
- 长文本生成
- 需要实时反馈
- 复杂任务（工具调用、RAG）

## 六、最佳实践

### 6.1 会话管理封装

```java
public class AgentConversationManager {
    
    private final DashScopeAgentApi api;
    private final String appId;
    private String currentSessionId;
    
    public AgentConversationManager(DashScopeAgentApi api, String appId) {
        this.api = api;
        this.appId = appId;
    }
    
    /**
     * 发送消息（自动管理sessionId）
     */
    public String sendMessage(String message) {
        DashScopeAgentRequest.DashScopeAgentRequestInput input = 
            new DashScopeAgentRequest.DashScopeAgentRequestInput(
                message,
                null,
                currentSessionId,  // 使用当前会话ID
                null, null, null
            );
        
        DashScopeAgentRequest request = new DashScopeAgentRequest(
            appId,
            input,
            null
        );
        
        ResponseEntity<DashScopeAgentResponse> response = api.call(request);
        
        // 更新sessionId
        this.currentSessionId = response.getBody().output().sessionId();
        
        return response.getBody().output().text();
    }
    
    /**
     * 重置会话
     */
    public void resetSession() {
        this.currentSessionId = null;
    }
}

// 使用
AgentConversationManager manager = new AgentConversationManager(api, "your-app-id");

String reply1 = manager.sendMessage("我叫张三");
System.out.println(reply1);

String reply2 = manager.sendMessage("我叫什么名字？");
System.out.println(reply2);  // 输出: 你叫张三

manager.resetSession();  // 重置会话
```

### 6.2 流式输出累积

```java
public class StreamingResponseAccumulator {
    
    /**
     * 累积流式响应
     */
    public CompletableFuture<String> accumulateStream(
            DashScopeAgentApi api,
            DashScopeAgentRequest request) {
        
        CompletableFuture<String> future = new CompletableFuture<>();
        StringBuilder accumulated = new StringBuilder();
        
        api.stream(request).subscribe(
            response -> {
                String text = response.output().text();
                if (text != null) {
                    accumulated.append(text);
                    System.out.print(text);  // 实时打印
                }
            },
            error -> future.completeExceptionally(error),
            () -> {
                System.out.println();
                future.complete(accumulated.toString());
            }
        );
        
        return future;
    }
}
```

### 6.3 错误处理

```java
public String safeCall(DashScopeAgentRequest request) {
    try {
        ResponseEntity<DashScopeAgentResponse> response = api.call(request);
        
        if (!response.getStatusCode().is2xxSuccessful()) {
            throw new RuntimeException("API call failed");
        }
        
        DashScopeAgentResponse body = response.getBody();
        
        // 检查业务错误
        if (body.code() != null && !"Success".equals(body.code())) {
            throw new RuntimeException("Agent error: " + body.message());
        }
        
        return body.output().text();
        
    } catch (DashScopeException e) {
        logger.error("DashScope error", e);
        return "抱歉，服务暂时不可用";
    } catch (Exception e) {
        logger.error("Unexpected error", e);
        return "抱歉，发生了未知错误";
    }
}
```

### 7.1 关键注意事项

| 注意事项 | 说明 |
