## 一、类概述

### 1.1 设计目的

`DashScopeApi` 是 Spring AI Alibaba 框架中的**底层HTTP客户端**，负责与阿里云百炼（DashScope）平台的所有服务进行通信。它是所有模型实现类（ChatModel、ImageModel、EmbeddingModel等）的基础。

### 1.2 核心职责

```
┌─────────────────────────────────────┐
│        Model Layer                  │
│  (ChatModel, ImageModel, etc.)      │
└──────────────┬──────────────────────┘
               │
               ↓
┌─────────────────────────────────────┐
│     DashScopeApi (本类)              │ ← 本文档介绍的核心
│  - HTTP通信                          │
│  - 请求构建                          │
│  - 响应解析                          │
│  - 错误处理                          │
└──────────────┬──────────────────────┘
               │
               ↓
┌─────────────────────────────────────┐
│    DashScope Platform               │
│  (阿里云百炼服务)                    │
└─────────────────────────────────────┘
```

### 1.3 支持的服务

| 服务类别 | 功能 | 相关方法 |
|---------|------|---------|
| **对话服务** | Chat Completions | `chatCompletionEntity()`, `chatCompletionStream()` |
| **嵌入服务** | Text Embeddings | `embeddings()` |
| **重排序服务** | Document Rerank | `rerankEntity()` |
| **文件管理** | 文件上传/查询 | `upload()`, `queryFileInfo()`, `getFileParseResult()` |
| **文档处理** | 文档分割 | `documentSplit()` |
| **RAG服务** | 向量存储/检索 | `upsertPipeline()`, `retriever()`, `deletePipelineDocument()` |

### 1.4 核心特性

| 特性 | 说明 |
|------|------|
| **双客户端** | RestClient（同步）+ WebClient（流式） |
| **认证管理** | 自动处理API Key认证 |
| **工作空间** | 支持多工作空间隔离 |
| **错误处理** | 统一的响应错误处理器 |
| **流式支持** | SSE（Server-Sent Events）流式响应 |
| **重试机制** | 配合 RetryTemplate 使用 |

## 四、主要方法详解

### 4.1 chatCompletionEntity() - 同步对话

**完整方法签名**：
```java
public ResponseEntity<ChatCompletion> chatCompletionEntity(
    ChatCompletionRequest chatRequest,
    MultiValueMap<String, String> extraHeaders
)
```

**实现逻辑**：
```java
public ResponseEntity<ChatCompletion> chatCompletionEntity(
        ChatCompletionRequest chatRequest,
        MultiValueMap<String, String> extraHeaders) {
    
    Assert.notNull(chatRequest, "The request body can not be null.");
    
    return this.restClient.post()
        .uri(this.completionsPath)
        .headers(headers -> {
            if (!CollectionUtils.isEmpty(extraHeaders)) {
                headers.addAll(extraHeaders);
            }
        })
        .body(chatRequest)
        .retrieve()
        .toEntity(ChatCompletion.class);
}
```

---

### 4.2 chatCompletionStream() - 流式对话

**完整方法签名**：
```java
public Flux<ChatCompletionChunk> chatCompletionStream(
    ChatCompletionRequest chatRequest,
    MultiValueMap<String, String> extraHeaders
)
```

**实现逻辑**：
```java
public Flux<ChatCompletionChunk> chatCompletionStream(
        ChatCompletionRequest chatRequest,
        MultiValueMap<String, String> extraHeaders) {
    
    Assert.notNull(chatRequest, "The request body can not be null.");
    Assert.isTrue(chatRequest.stream(), "Request must set the stream property to true.");
    
    return this.webClient.post()
        .uri(this.completionsPath)
        .headers(headers -> {
            if (!CollectionUtils.isEmpty(extraHeaders)) {
                headers.addAll(extraHeaders);
            }
        })
        .body(BodyInserters.fromValue(chatRequest))
        .retrieve()
        .bodyToFlux(String.class)
        .handle((data, sink) -> {
            if (SSE_DONE_PREDICATE.test(data)) {
                sink.complete();
                return;
            }
            sink.next(data);
        })
        .map(content -> ModelOptionsUtils.jsonToObject(content, ChatCompletionChunk.class));
}
```

**关键点**：
1. 使用 `WebClient` 而不是 `RestClient`
2. 接收 `Flux<String>`（SSE流）
3. 过滤 `[DONE]` 标记
4. 将每个JSON字符串转换为 `ChatCompletionChunk`

ChatCompletionRequest streamRequest = new ChatCompletionRequest(

);
