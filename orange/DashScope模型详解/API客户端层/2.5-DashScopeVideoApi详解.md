## 一、类概述

### 1.1 设计目的

`DashScopeVideoApi` 是专门用于视频生成服务的REST客户端，负责与阿里云百炼的视频生成API进行通信。它采用异步任务模式，支持文本生成视频（T2V）、图像生成视频（I2V）和关键帧生成视频（KF2V）。

### 1.2 核心职责

```
┌─────────────────────────────────────┐
│  DashScopeVideoModel                │
│   (视频生成模型)                     │
└──────────────┬──────────────────────┘
               │
               ↓
┌─────────────────────────────────────┐
│  DashScopeVideoApi (本类)           │ ← 本文档介绍的核心
│  - 异步任务管理                      │
│  - 提交视频生成任务                  │
│  - 轮询任务状态                      │
│  - 获取视频URL                       │
└──────────────┬──────────────────────┘
               │
               ↓
┌─────────────────────────────────────┐
│  DashScope Video Service            │
│  (阿里云百炼视频生成服务)            │
└─────────────────────────────────────┘
```

### 1.3 核心特性

| 特性 | 说明 |
|------|------|
| **异步任务模式** | 提交任务 → 轮询状态 → 获取结果 |
| **多种生成模式** | T2V/I2V/KF2V |
| **5种模型** | Turbo/Plus系列 |
| **20+种视频模板** | 特效模板（旋转、膨胀、舞蹈等） |
| **丰富参数** | 分辨率、时长、种子、prompt扩展 |
| **Builder模式** | 灵活的请求构建 |

## 三、核心功能

### 3.1 提交视频生成任务

**方法签名**：
```java
public ResponseEntity<VideoGenerationResponse> submitVideoGenTask(
    VideoGenerationRequest request
)
```

**功能**：提交视频生成任务，返回taskId

**实现逻辑**：
```java
public ResponseEntity<VideoGenerationResponse> submitVideoGenTask(
        VideoGenerationRequest request) {
    
    logger.debug("Submitting video generation task with options: {}", request);
    
    String baseUrl = "/api/v1/services/aigc";
    String firstAndLast = "/image2video/video-synthesis";
    String normal = "/video-generation/video-synthesis";
    
    // 根据是否有首尾帧选择不同的URI
    if (request.input.getFirstFrameUrl() != null || 
        request.input.getLastFrameUrl() != null) {
        baseUrl += firstAndLast;  // 关键帧生成视频
    } else {
        baseUrl += normal;  // 普通文本/图像生成视频
    }
    
    return this.restClient.post()
        .uri(baseUrl)
        .body(request)
        .header(HEADER_ASYNC, ENABLED)  // 异步标记
        .retrieve()
        .toEntity(VideoGenerationResponse.class);
}
```

**关键点**：
- 根据输入参数动态选择API端点
- 设置异步头（`X-DashScope-Async: enable`）
- 返回包含taskId的响应

**URI选择逻辑**：
```
有首帧/尾帧？
├─ 是 → /api/v1/services/aigc/image2video/video-synthesis (KF2V)
└─ 否 → /api/v1/services/aigc/video-generation/video-synthesis (T2V/I2V)
```

### 3.2 查询任务状态

**方法签名**：
```java

```

**功能**：根据taskId查询视频生成任务的状态和结果

**实现逻辑**：
```java
public ResponseEntity<VideoGenerationResponse> queryVideoGenTask(String taskId) {
    return this.restClient.get()
        .uri("/api/v1/tasks/{taskId}", taskId)
        .retrieve()
        .toEntity(VideoGenerationResponse.class);
}
```

**任务状态**：
- `PENDING`: 等待中
- `RUNNING`: 运行中
- `SUCCEEDED`: 成功（可获取视频URL）
- `FAILED`: 失败

## 五、使用示例

### 5.1 基础文本生成视频（T2V）

```java
// 创建API实例
DashScopeVideoApi api = DashScopeVideoApi.builder()
    .apiKey("your-api-key")
    .build();

// 构建输入
VideoInput input = VideoInput.builder()
    .prompt("一只可爱的橘猫在阳光下的草地上追逐蝴蝶，画面温馨美好")
    .negativePrompt("模糊，低质量，变形")
    .build();

// 构建参数
VideoParameters params = VideoParameters.builder()
    .resolution("1080p")
    .duration(5)
    .promptExtend(true)  // 启用智能扩展
    .build();

// 构建请求
VideoGenerationRequest request = VideoGenerationRequest.builder()
    .model(VideoModel.WANX2_1_T2V_TURBO.getValue())
    .input(input)
    .parameters(params)
    .build();

// 提交任务
ResponseEntity<VideoGenerationResponse> submitResponse = 
    api.submitVideoGenTask(request);

String taskId = submitResponse.getBody().getOutput().getTaskId();
System.out.println("任务已提交，taskId: " + taskId);

// 轮询任务状态
while (true) {
    ResponseEntity<VideoGenerationResponse> queryResponse = 
        api.queryVideoGenTask(taskId);
    
    String status = queryResponse.getBody().getOutput().getTaskStatus();
    System.out.println("任务状态: " + status);
    
    if ("SUCCEEDED".equals(status)) {
        String videoUrl = queryResponse.getBody().getOutput().getVideoUrl();
        System.out.println("视频生成成功！");
        System.out.println("视频URL: " + videoUrl);
        break;
    } else if ("FAILED".equals(status)) {
        System.err.println("视频生成失败");
        break;
    }
    
    Thread.sleep(5000);  // 等待5秒后重试
}
```

### 5.5 智能轮询封装

```java
public class VideoGenerationService {
    
    private final DashScopeVideoApi api;
    
    /**
     * 生成视频并等待完成
     */
    public String generateVideoAndWait(VideoGenerationRequest request) 
            throws InterruptedException {
        
        // 提交任务
        ResponseEntity<VideoGenerationResponse> submitResponse = 
            api.submitVideoGenTask(request);
        
        String taskId = submitResponse.getBody().getOutput().getTaskId();
        
        // 智能轮询（指数退避）
        int waitTime = 3000;  // 初始等待3秒
        int maxWaitTime = 30000;  // 最大等待30秒
        int attempts = 0;
        int maxAttempts = 60;  // 最多轮询60次（约30分钟）
        
        while (attempts < maxAttempts) {
            ResponseEntity<VideoGenerationResponse> queryResponse = 
                api.queryVideoGenTask(taskId);
            
            VideoOutput output = queryResponse.getBody().getOutput();
            String status = output.getTaskStatus();
            
            if ("SUCCEEDED".equals(status)) {
                return output.getVideoUrl();
            } else if ("FAILED".equals(status)) {
                throw new RuntimeException(
                    "Video generation failed: " + output.getMessage()
                );
            }
            
            // 继续等待
            Thread.sleep(waitTime);
            
            // 指数退避
            waitTime = Math.min(waitTime * 2, maxWaitTime);
            attempts++;
        }
        
        throw new RuntimeException("Video generation timeout");
    }
}
```

### 6.3 批量生成管理

```java
public class BatchVideoGenerator {
    
    private final DashScopeVideoApi api;
    private final ExecutorService executor;
    
    /**
     * 批量提交视频生成任务
     */
    public Map<String, CompletableFuture<String>> batchSubmit(
            List<VideoGenerationRequest> requests) {
        
        Map<String, CompletableFuture<String>> tasks = new ConcurrentHashMap<>();
        
        for (VideoGenerationRequest request : requests) {
            // 提交任务
            ResponseEntity<VideoGenerationResponse> response = 
                api.submitVideoGenTask(request);
            
            String taskId = response.getBody().getOutput().getTaskId();
            
            // 异步轮询
            CompletableFuture<String> future = CompletableFuture.supplyAsync(
                () -> {
                    try {
                        return waitForCompletion(taskId);
                    } catch (InterruptedException e) {
                        throw new RuntimeException(e);
                    }
                },
                executor
            );
            
            tasks.put(taskId, future);
        }
        
        return tasks;
    }
    
    private String waitForCompletion(String taskId) throws InterruptedException {
        // 轮询逻辑...
        return "video-url";
    }
}
```

### 7.2 常见问题

**Q1: 为什么生成的视频与prompt描述不一致？**
```
A: 
1. 启用promptExtend让模型扩展描述
2. 使用更详细、准确的prompt
3. 添加负面提示词排除不想要的内容
4. 尝试不同的seed找到最佳结果
```

**Q2: 如何提高视频质量？**
```
A: 
1. 使用Plus模型而非Turbo
2. 选择1080p分辨率
3. 提供高质量的参考图像（I2V模式）
4. 优化prompt描述
```

**Q3: 任务一直处于RUNNING状态？**
```
A: 
1. 视频生成通常需要1-5分钟
2. 复杂的请求可能需要更长时间
3. 建议设置30分钟超时
4. 如果超时，联系服务支持
```

**Q4: 如何保存视频到本地？**
```java
// 下载视频
public void downloadVideo(String videoUrl, String savePath) throws IOException {
    URL url = new URL(videoUrl);
    try (InputStream in = url.openStream();
         FileOutputStream out = new FileOutputStream(savePath)) {
        
        byte[] buffer = new byte[8192];
        int bytesRead;
        while ((bytesRead = in.read(buffer)) != -1) {
            out.write(buffer, 0, bytesRead);
        }
    }
}
```

**Q5: 如何使用模板特效？**
```
A: 
1. 模板通常需要配合I2V模型使用
2. 某些模板对输入图像有要求（如单人/双人）
3. 参考VideoTemplate枚举查看所有可用模板
4. 模板会覆盖部分prompt描述
```
