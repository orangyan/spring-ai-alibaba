## 一、类概述

### 1.1 设计目的

`DashScopeRerankModel` 是 Spring AI Alibaba 框架中用于文档重排序的核心实现类。在 RAG（检索增强生成）场景中，它可以对初步检索的文档进行精准的相关性排序，显著提升检索质量和最终生成效果。

### 1.2 什么是 Rerank（重排序）？

**Rerank** 是在初步检索后，对候选文档进行二次精排的过程。它使用更精细的相关性模型，为每个文档打分并重新排序。

```
传统检索流程：
用户查询 → 向量检索 → Top-K文档 → 直接使用

增强Rerank流程：
用户查询 → 向量检索 → Top-100文档 
         ↓
      Rerank重排序（精准打分）
         ↓
      Top-K最相关文档 → 使用
```

**为什么需要 Rerank？**
- ✅ **提高精准度**：向量检索可能不够精确，Rerank 提供更精细的相关性判断
- ✅ **召回更多候选**：先广泛召回，再精准筛选
- ✅ **考虑语义细节**：Rerank 模型通常比 Embedding 模型更大、更精准
- ✅ **提升 RAG 质量**：更相关的文档 → 更好的生成效果

### 1.3 核心特性

| 特性 | 说明 |
|------|------|
| **精准打分** | 为每个文档提供 0-1 的相关性分数 |
| **批量重排** | 一次可处理多个文档 |
| **Top-N 筛选** | 自动返回最相关的 N 个文档 |
| **文档保留** | 可选择是否在结果中保留原文档 |
| **重试机制** | 内置重试逻辑，提高可靠性 |
| **简单易用** | 一个方法调用完成重排序 |

### 1.4 支持的模型

| 模型名称 | 模型ID | 特点 |
|---------|--------|------|
| **通用重排-v1** | `gte-rerank` | 通用文本重排序 |
| **多语言重排** | `gte-rerank-multilingual` | 支持多语言 |

### 1.5 使用场景

- ✅ **RAG 应用**：检索后重排，提升上下文质量
- ✅ **搜索引擎**：对搜索结果精排
- ✅ **推荐系统**：对候选内容重排序
- ✅ **问答系统**：精准定位最相关文档
- ✅ **文档筛选**：从大量候选中筛选最相关内容

```java
@Service
public class RAGService {
    
    private final VectorStore vectorStore;
    private final RerankModel rerankModel;
    private final ChatModel chatModel;
    
    public String answer(String question) {
        // 1. 向量检索（广泛召回）
        List<Document> candidates = vectorStore.similaritySearch(
            SearchRequest.query(question).withTopK(50)  // 召回50个候选
        );
        
        // 2. 重排序（精准筛选）
        RerankRequest rerankRequest = new RerankRequest(
            question,
            candidates,
            DashScopeRerankOptions.builder()
                .withTopN(5)  // 只保留最相关的5个
                .build()
        );
        
        RerankResponse rerankResponse = rerankModel.call(rerankRequest);
        List<Document> topDocs = rerankResponse.getResults().stream()
            .map(DocumentWithScore::getDocument)
            .toList();
        
        // 3. 构建上下文
        String context = topDocs.stream()
            .map(Document::getText)
            .collect(Collectors.joining("\n\n"));
        
        // 4. 生成回答
        String prompt = String.format(
            "基于以下上下文回答问题：\n\n%s\n\n问题：%s",
            context, question
        );
        
        return chatModel.call(new Prompt(prompt))
            .getResult().getOutput().getContent();
    }
}
```

## 五、主要方法详解

### 5.1 call() - 执行重排序

**方法签名**：
```java
@Override
public RerankResponse call(RerankRequest request)
```

**内部实现逻辑**：
```java
public RerankResponse call(RerankRequest request) {
    // 1. 参数验证
    Assert.notNull(request.getQuery(), "query must not be null");
    Assert.notNull(request.getInstructions(), "documents must not be null");
    
    // 2. 合并配置选项
    DashScopeRerankOptions requestOptions = mergeOptions(
        request.getOptions(), 
        this.defaultOptions
    );
    
    // 3. 创建API请求
    DashScopeApi.RerankRequest rerankRequest = createRequest(
        request, 
        requestOptions
    );
    
    // 4. 执行重试调用
    ResponseEntity<DashScopeApi.RerankResponse> responseEntity = 
        this.retryTemplate.execute(ctx -> 
            this.dashscopeApi.rerankEntity(rerankRequest)
        );
    
    // 5. 获取响应
    var response = responseEntity.getBody();
    
    // 6. 检查响应
    if (response == null) {
        logger.warn("No rerank returned for query: {}", request.getQuery());
        return new RerankResponse(Collections.emptyList());
    }
    
    // 7. 转换为 DocumentWithScore 列表
    List<DocumentWithScore> documentWithScores = response.output()
        .results()
        .stream()
        .map(data -> DocumentWithScore.builder()
            .withScore(data.relevanceScore())  // 相关性分数
            .withDocument(request.getInstructions().get(data.index()))  // 原文档
            .build())
        .toList();
    
    // 8. 构建元数据
    var metadata = new RerankResponseMetadata(
        DashScopeAiUsage.from(response.usage())
    );
    
    // 9. 返回响应
    return new RerankResponse(documentWithScores, metadata);
}
```

```java
private DashScopeApi.RerankRequest createRequest(
        RerankRequest request, 
        DashScopeRerankOptions requestOptions) {

    List<String> docs = request.getInstructions().stream()
        .map(Document::getText)

    // 2. 构建参数
    DashScopeApi.RerankRequestParameter parameter = 
        new DashScopeApi.RerankRequestParameter(
            requestOptions.getTopN(),              // top_n
            requestOptions.getReturnDocuments()    // return_documents
        );
    
    // 3. 构建输入
    var input = new DashScopeApi.RerankRequestInput(
        request.getQuery(),  // query
        docs                 // documents
    );
    
    // 4. 构建并返回请求
    return new DashScopeApi.RerankRequest(
        requestOptions.getModel(),  // model
        input,                      // input
        parameter                   // parameters
    );
}
```

### 5.3 mergeOptions() - 合并配置

**方法签名**：
```java
private DashScopeRerankOptions mergeOptions(
    @Nullable RerankOptions runtimeOptions,
    DashScopeRerankOptions defaultOptions
)
```

**实现逻辑**：
```java
private DashScopeRerankOptions mergeOptions(
        @Nullable RerankOptions runtimeOptions,
        DashScopeRerankOptions defaultOptions) {
    
    // 1. 转换运行时配置
    var runtimeOptionsForProvider = ModelOptionsUtils.copyToTarget(
        runtimeOptions, 
        RerankOptions.class,
        DashScopeRerankOptions.class
    );
    
    // 2. 如果没有运行时配置，直接返回默认配置
    if (runtimeOptionsForProvider == null) {
        return defaultOptions;
    }
    
    // 3. 合并配置
    return DashScopeRerankOptions.builder()
        .withModel(ModelOptionsUtils.mergeOption(
            runtimeOptionsForProvider.getModel(), 
            defaultOptions.getModel()
        ))
        .withTopN(ModelOptionsUtils.mergeOption(
            runtimeOptionsForProvider.getTopN(), 
            defaultOptions.getTopN()
        ))
        .withReturnDocuments(ModelOptionsUtils.mergeOption(
            runtimeOptionsForProvider.getReturnDocuments(),
            defaultOptions.getReturnDocuments()
        ))
        .build();
}
```

### 7.2 重排序原理

```
输入：
  查询: "如何使用 Spring AI?"
  文档列表: [Doc1, Doc2, Doc3, ..., DocN]

Rerank模型内部处理：
  1. 对每个文档构建 [查询, 文档] 对
  2. 通过深度学习模型计算相关性分数
  3. 按分数降序排列
  4. 返回 Top-N 结果

输出：
  [
    {doc: Doc1, score: 0.95},
    {doc: Doc5, score: 0.87},
    {doc: Doc3, score: 0.72},
    ...
  ]
```

### 7.3 与向量检索的区别

| 维度 | 向量检索（Embedding） | 重排序（Rerank） |
|------|---------------------|----------------|
| **速度** | 快（毫秒级） | 较慢（秒级） |
| **精度** | 中等 | 高 |
| **成本** | 低 | 中等 |
| **适用阶段** | 初步召回 | 精准筛选 |
| **候选数量** | 大量（1000+） | 少量（100以内） |
| **模型大小** | 小 | 大 |

**最佳实践组合**：
```
查询 → Embedding检索(召回100) → Rerank重排(精选5) → 使用
```

### 8.2 RAG 完整流程示例

```java
@Service
public class EnhancedRAGService {
    
    private final EmbeddingModel embeddingModel;
    private final VectorStore vectorStore;
    private final RerankModel rerankModel;
    private final ChatModel chatModel;
    
    public String answer(String question) {
        // Step 1: 向量检索（广泛召回）
        List<Document> candidates = vectorStore.similaritySearch(
            SearchRequest.query(question)
                .withTopK(50)  // 召回50个候选
                .withSimilarityThreshold(0.3)  // 较低阈值
        );
        
        System.out.println("初步召回: " + candidates.size() + " 个文档");
        
        // Step 2: 重排序（精准筛选）
        RerankRequest rerankRequest = new RerankRequest(
            question,
            candidates,
            DashScopeRerankOptions.builder()
                .withTopN(5)  // 只保留最相关的5个
                .build()
        );
        
        RerankResponse rerankResponse = rerankModel.call(rerankRequest);
        List<DocumentWithScore> reranked = rerankResponse.getResults();
        
        System.out.println("重排后保留: " + reranked.size() + " 个文档");
        
        // 打印分数
        reranked.forEach(doc -> 
            System.out.printf("相关性分数: %.3f%n", doc.getScore())
        );
        
        // Step 3: 构建上下文
        String context = reranked.stream()
            .map(docWithScore -> docWithScore.getDocument().getText())
            .collect(Collectors.joining("\n\n---\n\n"));
        
        // Step 4: 生成回答
        String prompt = """
            你是一个helpful的助手。基于以下上下文回答用户问题。
            如果上下文中没有相关信息，请如实告知。
            
            上下文：
            %s
            
            问题：%s
            
            回答：
            """.formatted(context, question);
        
        ChatResponse chatResponse = chatModel.call(new Prompt(prompt));
        String answer = chatResponse.getResult().getOutput().getContent();
        
        // Step 5: 附加来源信息
        StringBuilder result = new StringBuilder(answer);
        result.append("\n\n📚 参考来源:\n");
        for (int i = 0; i < reranked.size(); i++) {
            result.append(String.format("[%d] (相关性: %.2f) %s\n", 
                i + 1,
                reranked.get(i).getScore(),
                reranked.get(i).getDocument().getText().substring(0, 100) + "..."
            ));
        }
        
        return result.toString();
    }
}
```

```java
    // 按分数分类
    public Map<String, List<Document>> categorizeByScore(
            String query, 
            List<Document> documents) {
        
        Map<Document, Double> scores = scoreDocuments(query, documents);
        
        Map<String, List<Document>> categorized = new HashMap<>();
        categorized.put("高度相关 (>0.8)", new ArrayList<>());
        categorized.put("相关 (0.5-0.8)", new ArrayList<>());
        categorized.put("低相关 (<0.5)", new ArrayList<>());
        
        scores.forEach((doc, score) -> {
            if (score > 0.8) {
                categorized.get("高度相关 (>0.8)").add(doc);
            } else if (score > 0.5) {
                categorized.get("相关 (0.5-0.8)").add(doc);
            } else {
                categorized.get("低相关 (<0.5)").add(doc);
            }
        });
        
        return categorized;
    }
}
```

### 9.1 召回与重排的平衡

**推荐策略**：
```java
// ✅ 推荐：广泛召回 + 精准筛选
List<Document> candidates = vectorStore.similaritySearch(
    SearchRequest.query(question)
        .withTopK(50)              // 广泛召回
        .withSimilarityThreshold(0.3)  // 较低阈值
);

RerankRequest request = new RerankRequest(
    question,
    candidates,
    DashScopeRerankOptions.builder()
        .withTopN(5)  // 精准筛选
        .build()
);
```

**不推荐策略**：
```java
// ❌ 召回太少，Rerank 没有施展空间
List<Document> candidates = vectorStore.similaritySearch(
    SearchRequest.query(question).withTopK(5)
);
// Rerank 没有意义

// ❌ 召回太多，Rerank 成本高、速度慢
List<Document> candidates = vectorStore.similaritySearch(
    SearchRequest.query(question).withTopK(500)
);
// Rerank 处理时间过长
```

```java
@Service
public class CachedRerankService {
    
    private final RerankModel rerankModel;
    private final Map<String, RerankResponse> cache = new ConcurrentHashMap<>();
    
    @Cacheable(value = "rerank", key = "#query + #documents.hashCode()")
    public RerankResponse rerankWithCache(
            String query, 
            List<Document> documents) {
        
        // 生成缓存键
        String cacheKey = query + ":" + documents.size();
        
        // 检查缓存
        return cache.computeIfAbsent(cacheKey, k -> 
            rerankModel.call(new RerankRequest(query, documents))
        );
    }
}
```

### 10.1 注意事项

| 注意事项 | 说明 |
|---------|------|
| **文档数量限制** | 建议不超过100个文档 |
| **查询长度** | 查询文本不宜过长（< 512 tokens） |

| **成本控制** | 按 Token 计费，控制文档数量和长度 |
| **适用场景** | 适合二次精排，不适合大规模初筛 |

### 10.2 常见问题

**Q1: Rerank 和向量检索哪个更准确？**
```
A: Rerank 更准确，但速度慢、成本高。
推荐组合使用：
  向量检索（快速召回） + Rerank（精准筛选）
```

**Q2: 何时需要使用 Rerank？**
```
A: 以下场景建议使用：
1. RAG 应用，需要高质量上下文
2. 搜索引擎，需要精准排序
3. 向量检索结果不够准确
4. 文档数量较多，需要筛选
```

**Q3: Top-N 应该设置为多少？**
```
A: 根据应用场景：
- 对话问答：3-5个
- 文档总结：10-15个
- 搜索展示：20-30个
一般不超过 50 个
```

**Q4: Rerank 分数的含义是什么？**
```
A: 分数范围 0.0-1.0：
- 1.0：完全相关
- 0.8-1.0：高度相关
- 0.5-0.8：中等相关
- 0.3-0.5：低相关
- < 0.3：几乎不相关

建议阈值：> 0.5
```

**Q5: 如何平衡速度和精度？**
```
A: 
1. 控制召回数量（20-50个）
2. 合理设置 Top-N（3-10个）
3. 使用缓存减少重复调用
4. 异步处理（如果不需要实时）
5. 根据场景降级（如向量检索结果已经很好）
```
