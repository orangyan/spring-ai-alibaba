## 一、枚举概述

### 1.1 设计目的

`DashScopeAgentFlowStreamMode` 枚举定义了Agent应用在流式输出时的行为模式，控制思维链（thoughts）的输出方式。

### 1.2 完整定义

```java
package com.alibaba.cloud.ai.dashscope.agent;

public enum DashScopeAgentFlowStreamMode {
    
    /**
     * 所有节点的流式结果都会输出到thoughts字段
     */
    FULL_THOUGHTS("full_thoughts"),
    
    /**
     * 使用与Agent应用相同的输出格式
     */
    AGENT_FORMAT("agent_format");
    
    private final String value;
    
    DashScopeAgentFlowStreamMode(String value) {
        this.value = value;
    }
    
    public String getValue() {
        return value;
    }
}
```

### 1.3 应用场景

| 场景 | 推荐模式 |
|------|---------|
| **调试Agent** | FULL_THOUGHTS |
| **观察推理过程** | FULL_THOUGHTS |
| **生产环境** | AGENT_FORMAT |
| **用户交互** | AGENT_FORMAT |

## 二、枚举值详解

### 2.1 FULL_THOUGHTS

**值**：`"full_thoughts"`

**说明**：所有节点的流式结果都会输出到`thoughts`字段中

**特点**：
- ✅ **完整透明**：可以看到Agent的完整推理过程
- ✅ **调试友好**：便于观察每个节点的执行情况
- ✅ **工具调用可见**：可以看到工具的调用和返回
- ❌ **数据量大**：输出内容较多，增加传输成本
- ❌ **用户不友好**：普通用户不需要看到技术细节

**输出结构**：
```json
{
  "output": {
    "text": "最终回复",
    "thoughts": [
      {
        "thought": "用户询问天气，我需要调用天气API",
        "action_type": "tool",
        "action_name": "get_weather",
        "action_input": "{\"city\": \"北京\"}",
        "observation": "天气晴朗，温度25°C"
      },
      {
        "thought": "已获取天气信息，现在回复用户",
        "response": "今天北京天气晴朗，温度25°C"
      }
    ]
  }
}
```

**适用场景**：
1. **开发阶段**：调试Agent行为
2. **测试环境**：验证Agent逻辑
3. **问题排查**：分析Agent执行过程
4. **学习研究**：理解Agent工作原理

---

### 2.2 AGENT_FORMAT

**值**：`"agent_format"`

**说明**：使用与Agent应用相同的输出格式

**特点**：
- ✅ **简洁高效**：只输出必要信息
- ✅ **用户友好**：输出格式清晰易懂
- ✅ **性能好**：减少数据传输量
- ❌ **调试困难**：不可见内部推理过程
- ❌ **黑盒模式**：无法观察工具调用

**输出结构**：
```json
{
  "output": {
    "text": "今天北京天气晴朗，温度25°C",
    "finish_reason": "stop"
  }
}
```

**适用场景**：
1. **生产环境**：面向用户的正式服务
2. **用户交互**：聊天机器人、智能助手
3. **性能要求高**：需要快速响应
4. **隐藏细节**：不暴露内部实现

## 三、使用场景

### 3.1 场景对比

| 维度 | FULL_THOUGHTS | AGENT_FORMAT |
|------|--------------|--------------|
| **可见性** | 完全透明 | 黑盒 |
| **数据量** | 大 | 小 |
| **调试** | 友好 | 困难 |
| **性能** | 较慢 | 快 |
| **用户体验** | 技术化 | 友好 |
| **适用环境** | 开发/测试 | 生产 |

---

### 3.2 流式输出对比

#### FULL_THOUGHTS 模式

```
流式输出序列：
1. {"thoughts": [{"thought": "分析用户问题..."}]}
2. {"thoughts": [{"thought": "调用天气API..."}]}
3. {"thoughts": [{"action_name": "get_weather"}]}
4. {"thoughts": [{"observation": "天气数据..."}]}
5. {"text": "今天", "thoughts": [...]}
6. {"text": "北京", "thoughts": [...]}
7. {"text": "天气晴朗", "thoughts": [...]}
```

**特点**：
- 每个思考步骤都实时输出
- 可以看到完整的推理链
- 适合开发调试

---

#### AGENT_FORMAT 模式

```
流式输出序列：
1. {"text": "今天"}
2. {"text": "北京"}
3. {"text": "天气"}
4. {"text": "晴朗"}
5. {"text": "，温度"}
6. {"text": "25°C"}
```

**特点**：
- 只输出最终文本
- 思考过程在服务端完成
- 用户体验流畅

## 四、使用示例

### 4.1 FULL_THOUGHTS 模式

```java
// 构建Agent选项（调试模式）
DashScopeAgentOptions options = DashScopeAgentOptions.builder()
    .withAppId("your-app-id")
    .withFlowStreamMode(DashScopeAgentFlowStreamMode.FULL_THOUGHTS)
    .withHasThoughts(true)  // 必须启用
    .withIncrementalOutput(true)
    .build();

// 流式调用
Prompt prompt = new Prompt(
    new UserMessage("今天北京天气怎么样？"),
    options
);

agent.stream(prompt).subscribe(
    response -> {
        // 获取完整输出
        Map<String, Object> metadata = response.getResult()
            .getOutput()
            .getMetadata();
        
        DashScopeAgentResponse.DashScopeAgentResponseOutput output = 
            (DashScopeAgentResponse.DashScopeAgentResponseOutput) 
            metadata.get("output");
        
        // 查看思维链
        if (output.thoughts() != null) {
            for (var thought : output.thoughts()) {
                System.out.println("【思考】" + thought.thought());
                if (thought.actionName() != null) {
                    System.out.println("【调用】" + thought.actionName());
                }
                if (thought.observation() != null) {
                    System.out.println("【结果】" + thought.observation());
                }
            }
        }
        
        // 输出文本
        String text = output.text();
        if (text != null && !text.isEmpty()) {
            System.out.print(text);
        }
    }
);
```

**输出示例**：
```
【思考】用户询问北京天气，需要调用天气查询工具
【调用】get_weather
【结果】{"city": "北京", "weather": "晴", "temperature": 25}
【思考】已获取天气数据，整理回复
今天北京天气晴朗，温度25°C
```

### 4.2 AGENT_FORMAT 模式

```java
// 构建Agent选项（生产模式）
DashScopeAgentOptions options = DashScopeAgentOptions.builder()
    .withAppId("your-app-id")
    .withFlowStreamMode(DashScopeAgentFlowStreamMode.AGENT_FORMAT)
    .withIncrementalOutput(true)
    .build();

// 流式调用
Prompt prompt = new Prompt(
    new UserMessage("今天北京天气怎么样？"),
    options
);

agent.stream(prompt).subscribe(
    response -> {
        String text = response.getResult().getOutput().getText();
        System.out.print(text);  // 实时输出文本
    },
    error -> System.err.println("错误: " + error.getMessage()),
    () -> System.out.println("\n完成")
);
```

**输出示例**：
```
今天北京天气晴朗，温度25°C
完成
```

### 4.3 动态切换模式

```java
public class AdaptiveAgentService {
    
    private final DashScopeAgent agent;
    private boolean debugMode;
    
    /**
     * 根据调试标志选择模式
     */
    public Flux<ChatResponse> chat(String message) {
        DashScopeAgentFlowStreamMode mode = debugMode 
            ? DashScopeAgentFlowStreamMode.FULL_THOUGHTS 
            : DashScopeAgentFlowStreamMode.AGENT_FORMAT;
        
        DashScopeAgentOptions options = DashScopeAgentOptions.builder()
            .withAppId("your-app-id")
            .withFlowStreamMode(mode)
            .withHasThoughts(debugMode)
            .withIncrementalOutput(true)
            .build();
        
        Prompt prompt = new Prompt(new UserMessage(message), options);
        return agent.stream(prompt);
    }
    
    /**
     * 启用调试模式
     */
    public void enableDebugMode() {
        this.debugMode = true;
    }
    
    /**
     * 禁用调试模式
     */
    public void disableDebugMode() {
        this.debugMode = false;
    }
}
```

### 4.4 条件输出处理

```java
public class ConditionalThoughtsProcessor {
    
    /**
     * 根据模式处理输出
     */
    public void processResponse(
            ChatResponse response,
            DashScopeAgentFlowStreamMode mode) {
        
        Map<String, Object> metadata = response.getResult()
            .getOutput()
            .getMetadata();
        
        DashScopeAgentResponse.DashScopeAgentResponseOutput output = 
            (DashScopeAgentResponse.DashScopeAgentResponseOutput) 
            metadata.get("output");
        
        if (mode == DashScopeAgentFlowStreamMode.FULL_THOUGHTS) {
            // 处理思维链
            if (output.thoughts() != null) {
                logThoughts(output.thoughts());
            }
        }
        
        // 输出文本
        System.out.println(output.text());
    }
    
    private void logThoughts(List<Thoughts> thoughts) {
        for (var thought : thoughts) {
            logger.debug("Thought: {}", thought.thought());
            logger.debug("Action: {}", thought.actionName());
            logger.debug("Observation: {}", thought.observation());
        }
    }
}
```

## 五、最佳实践

### 5.1 环境区分

```java
public class AgentConfiguration {
    
    @Value("${spring.profiles.active}")
    private String profile;
    
    /**
     * 根据环境选择模式
     */
    public DashScopeAgentFlowStreamMode getFlowStreamMode() {
        return switch (profile) {
            case "dev", "test" -> DashScopeAgentFlowStreamMode.FULL_THOUGHTS;
            case "prod" -> DashScopeAgentFlowStreamMode.AGENT_FORMAT;
            default -> DashScopeAgentFlowStreamMode.AGENT_FORMAT;
        };
    }
}
```

### 5.3 性能监控

```java
public class AgentMetrics {
    
    /**
     * 监控不同模式的性能
     */
    public void measurePerformance(DashScopeAgentFlowStreamMode mode) {
        long startTime = System.currentTimeMillis();
        
        // 执行Agent调用
        ChatResponse response = agent.call(prompt);
        
        long duration = System.currentTimeMillis() - startTime;
        
        // 记录指标
        metricsRegistry.counter(
            "agent.calls",
            "mode", mode.getValue()
        ).increment();
        
        metricsRegistry.timer(
            "agent.duration",
            "mode", mode.getValue()
        ).record(duration, TimeUnit.MILLISECONDS);
    }
}
```

**典型性能数据**：
- `AGENT_FORMAT`: 平均响应时间 800ms
- `FULL_THOUGHTS`: 平均响应时间 1200ms（多50%）

public class AgentABTesting {

    public DashScopeAgentFlowStreamMode selectModeForTest(String userId) {
        // 使用userId的哈希值决定分组

        return isGroupA 
            ? DashScopeAgentFlowStreamMode.FULL_THOUGHTS

}
