## 一、类概述

### 1.1 设计目的

`DashScopeImageModel` 是 Spring AI Alibaba 框架中用于调用阿里云百炼（DashScope）图像生成能力的核心实现类。它将 DashScope 的通义万相（Wanx）图像生成 API 适配到 Spring AI 的标准 `ImageModel` 接口，为开发者提供统一、易用的图像生成访问方式。

### 1.2 核心特性

| 特性 | 说明 |
|------|------|
| **异步任务模式** | 图像生成采用异步模式：提交任务 → 轮询结果 |
| **多种生成模式** | 支持文生图（T2I）、图生图、参考图模式等 |
| **丰富的风格** | 支持摄影、插画、3D卡通等多种艺术风格 |
| **高清输出** | 支持多种分辨率（720\*1280、1024\*1024等） |
| **负提示词** | 支持负提示词（Negative Prompt）控制不想要的内容 |
| **重试机制** | 内置智能重试，自动轮询任务状态直到完成 |
| **可观测性** | 集成 Micrometer Observation 监控 |
| **批量生成** | 一次请求可生成多张图片（1-4张） |

### 1.3 支持的模型

| 模型名称 | 模型ID | 特点 | 适用场景 |
|---------|--------|------|----------|
| **通义万相-基础版** | `wanx-v1` | 基础图像生成 | 一般图像生成需求 |
| **通义万相-绘画版** | `wanx-x-painting-v1` | 艺术绘画风格 | 艺术创作、插画 |
| **通义万相-2.1** | `wanx-2.1` | 更高质量 | 高质量图像生成 |
| **通义万相-涂鸦** | `wanx-sketch-to-image-v1` | 草图转图像 | 从草图生成精美图像 |

### 1.4 使用场景

- ✅ AI 绘画和艺术创作
- ✅ 产品图生成
- ✅ 营销素材制作
- ✅ 游戏美术资产

## 三、核心功能详解

### 3.1 异步任务模式

DashScope 的图像生成采用**异步任务模式**，这是因为图像生成通常需要较长时间（几秒到几十秒）。

**工作流程**：
```
1. 提交任务 (submitImageGenTask)
   ↓
2. 获取 taskId
   ↓
3. 轮询任务状态 (getImageGenTask)
   ↓
4. 状态判断：
   - SUCCEEDED → 返回图片URL
   - FAILED/UNKNOWN → 返回错误
   - PENDING/RUNNING → 继续等待
   ↓
5. 返回 ImageResponse
```

**与同步模式的对比**：
| 维度 | 同步模式 | 异步模式（当前） |
|------|----------|-----------------|
| **响应时间** | 立即返回 | 需要轮询等待 |
| **服务器压力** | 高（长连接） | 低（短连接） |
| **适用场景** | 快速任务 | 耗时任务（图像/视频生成） |
| **实现复杂度** | 简单 | 中等 |

## 五、主要方法详解

### 5.1 call() - 生成图像

**完整方法签名**：
```java
@Override
public ImageResponse call(ImagePrompt request)
```

**内部实现逻辑**：
```java
public ImageResponse call(ImagePrompt request) {
    // 1. 参数验证
    Assert.notNull(request, "Prompt must not be null");
    Assert.isTrue(!CollectionUtils.isEmpty(request.getInstructions()), 
        "Prompt messages must not be empty");
    
    // 2. 提交图像生成任务
    String taskId = submitImageGenTask(request);
    if (taskId == null) {
        return new ImageResponse(List.of(), toMetadataEmpty());
    }
    
    // 3. 创建观测上下文
    ImageModelObservationContext observationContext = 
        ImageModelObservationContext.builder()
            .imagePrompt(request)
            .provider(DashScopeApiConstants.PROVIDER_NAME)
            .build();
    
    // 4. 创建观测对象
    Observation observation = ImageModelObservationDocumentation.IMAGE_MODEL_OPERATION
        .observation(observationConvention, 
                     new DefaultImageModelObservationConvention(),
                     () -> observationContext,
                     this.observationRegistry);
    
    // 5. 执行观测调用
    return observation.observe(() ->
        
        // 6. 重试执行（轮询任务状态）
        retryTemplate.execute(ctx -> {
            observation.lowCardinalityKeyValue("retry.attempt", 
                String.valueOf(ctx.getRetryCount()));
            
            // 7. 获取任务结果
            DashScopeImageApi.DashScopeImageAsyncResponse resp = 
                getImageGenTask(taskId);
            
            if (resp != null) {
                String status = resp.output().taskStatus();
                observation.lowCardinalityKeyValue("task.status", status);
                
                // 8. 根据状态返回结果
                switch (status) {
                    case "SUCCEEDED" -> {
                        return toImageResponse(resp);
                    }
                    case "FAILED", "UNKNOWN" -> {
                        return new ImageResponse(List.of(), toMetadata(resp));
                    }
                }
            }
            
            // 9. 任务未完成，抛出瞬时异常触发重试
            throw new TransientAiException("Image generation still pending");
            
        }, context -> {
            // 10. 重试耗尽后的回退处理
            observation.lowCardinalityKeyValue("timeout", "true");
            return new ImageResponse(List.of(), toMetadataTimeout(taskId));
        })
    );
}
```

### 5.2 submitImageGenTask() - 提交任务

**方法签名**：
```java
public String submitImageGenTask(ImagePrompt request)
```

**实现逻辑**：
```java
public String submitImageGenTask(ImagePrompt request) {
    // 1. 合并配置选项
    DashScopeImageOptions imageOptions = toImageOptions(request.getOptions());
    logger.debug("Image options: {}", imageOptions);
    
    // 2. 构建API请求
    DashScopeImageApi.DashScopeImageRequest dashScopeImageRequest = 
        constructImageRequest(request, imageOptions);
    
    // 3. 提交任务
    ResponseEntity<DashScopeImageApi.DashScopeImageAsyncResponse> submitResponse = 
        dashScopeImageApi.submitImageGenTask(dashScopeImageRequest);
    
    // 4. 检查响应
    if (submitResponse == null || submitResponse.getBody() == null) {
        logger.warn("Submit imageGen error, request: {}", request);
        return null;
    }
    
    // 5. 返回任务ID
    return submitResponse.getBody().output().taskId();
}
```

**配置合并**：
```java
private DashScopeImageOptions toImageOptions(ImageOptions runtimeOptions) {
    // 1. 设置默认模型
    var currentOptions = DashScopeImageOptions.builder()
        .withModel(DEFAULT_MODEL)
        .build();
    
    // 2. 复制运行时配置
    if (Objects.nonNull(runtimeOptions)) {
        currentOptions = ModelOptionsUtils.copyToTarget(
            runtimeOptions,
            ImageOptions.class,
            DashScopeImageOptions.class
        );
    }
    
    // 3. 合并默认配置
    currentOptions = ModelOptionsUtils.merge(
        currentOptions,
        this.defaultOptions,
        DashScopeImageOptions.class
    );
    
    return currentOptions;
}
```

### 5.4 toImageResponse() - 响应转换

**方法签名**：
```java
private ImageResponse toImageResponse(
    DashScopeImageApi.DashScopeImageAsyncResponse asyncResp
)
```

**实现逻辑**：
```java
private ImageResponse toImageResponse(
        DashScopeImageApi.DashScopeImageAsyncResponse asyncResp) {
    
    // 1. 获取输出和结果
    var output = asyncResp.output();
    var results = output.results();
    
    // 2. 构建元数据
    ImageResponseMetadata md = toMetadata(asyncResp);
    
    // 3. 转换为 ImageGeneration 列表
    List<ImageGeneration> gens = results == null ? List.of()
        : results.stream()
            .map(r -> new ImageGeneration(new Image(r.url(), null)))
            .toList();
    
    // 4. 返回 ImageResponse
    return new ImageResponse(gens, md);
}
```

**元数据构建**：
```java
private ImageResponseMetadata toMetadata(
        DashScopeImageApi.DashScopeImageAsyncResponse re) {
    
    var out = re.output();
    var tm = out.taskMetrics();
    var usage = re.usage();
    
    ImageResponseMetadata md = new ImageResponseMetadata();
    
    // 添加使用量信息
    Optional.ofNullable(usage)
        .map(DashScopeImageApi.DashScopeImageAsyncResponse
            .DashScopeImageAsyncResponseUsage::imageCount)
        .ifPresent(count -> md.put("imageCount", count));
    
    // 添加任务指标
    Optional.ofNullable(tm).ifPresent(metrics -> {
        md.put("taskTotal", metrics.total());
        md.put("taskSucceeded", metrics.SUCCEEDED());
        md.put("taskFailed", metrics.FAILED());
    });
    
    // 添加基本信息
    md.put("requestId", re.requestId());
    md.put("taskStatus", out.taskStatus());
    Optional.ofNullable(out.code()).ifPresent(code -> md.put("code", code));
    Optional.ofNullable(out.message()).ifPresent(msg -> md.put("message", msg));
    
    return md;
}
```

### 7.2 重试策略

```java
RetryTemplate retryTemplate = RetryUtils.DEFAULT_RETRY_TEMPLATE;
```

**重试参数**：

- **初始等待时间**：2秒
- **最大等待时间**：3分钟
- **退避倍率**：2（指数退避）

**重试触发条件**：
```java
// 当任务状态为 PENDING 或 RUNNING 时抛出瞬时异常
```

**重试结束条件**：
1. 任务状态为 `SUCCEEDED` → 返回结果
2. 任务状态为 `FAILED` 或 `UNKNOWN` → 返回错误
3. 达到最大重试次数 → 返回超时

```java
public String safeGenerateImage(String prompt) {

        ImageResponse response = imageModel.call(

                DashScopeImageOptions.builder()
                    .withModel("wanx-v1")
```

## 十、注意事项与FAQ

### 10.1 注意事项

| 注意事项 | 说明 |
|---------|------|
| **异步等待时间** | 图像生成通常需要5-30秒，请耐心等待 |
| **并发限制** | 控制并发请求数，避免超出API限制 |
| **成本控制** | 图像生成按次数计费，注意成本 |
| **内容合规** | 确保生成内容符合相关法律法规 |
| **图片有效期** | 生成的图片URL有有效期（通常24小时） |
| **分辨率选择** | 更高分辨率意味着更长生成时间和更高成本 |

---

### 10.2 常见问题

**Q1: 为什么图像生成这么慢？**
```
A: 图像生成是计算密集型任务，通常需要5-30秒。
优化建议：
1. 使用较低分辨率（如512*512）快速预览
2. 选择速度更快的模型
3. 避免不必要的高质量参数
```

**Q2: 如何保存生成的图片？**
```
A: 
1. 从响应中获取图片URL
2. 使用 RestTemplate 或 HttpClient 下载
3. 保存到本地文件系统或对象存储
4. 注意：图片URL有有效期，建议及时下载
```

**Q3: 批量生成时如何提高成功率？**
```
A: 
1. 使用 withN(4) 而不是循环调用
2. 设置合理的重试策略
3. 监控任务状态
4. 处理部分成功的情况
```

**Q4: 如何让生成结果更一致？**
```
A: 
1. 使用固定的 seed 值
2. 保持提示词格式一致
3. 使用相同的配置参数
4. 避免使用"随机"、"不同"等词
```

**Q5: 负提示词不生效怎么办？**
```
A: 
1. 确认模型支持负提示词
2. 负提示词要具体明确
3. 与正提示词保持一致的风格
4. 不要过度使用负提示词
```
