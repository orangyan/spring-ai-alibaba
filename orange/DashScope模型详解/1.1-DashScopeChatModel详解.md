## 一、类概述

### 1.1 设计目的

`DashScopeChatModel` 是 Spring AI Alibaba 框架中用于与阿里云百炼（DashScope）对话模型交互的核心实现类。它将 DashScope 的对话能力适配到 Spring AI 的标准 `ChatModel` 接口，为开发者提供统一、易用的对话模型访问方式。

### 1.2 核心特性

| 特性 | 说明 |
|------|------|
| **同步调用** | 支持阻塞式的对话调用，返回完整响应 |
| **流式调用** | 支持实时流式输出，逐token返回响应 |
| **Function Calling** | 完整支持函数调用（工具调用），可与外部工具集成 |
| **多轮对话** | 支持上下文管理和多轮对话历史 |
| **多模态支持** | 支持文本、图片、音频、视频等多模态输入 |
| **重试机制** | 内置重试逻辑，提高调用可靠性 |
| **可观测性** | 集成 Micrometer Observation 和 OpenTelemetry |
| **配置灵活** | 支持运行时配置和默认配置的合并 |

### 1.3 使用场景

- ✅ 聊天机器人和对话系统
- ✅ 智能客服和问答系统
- ✅ 文本生成和内容创作
- ✅ 代码生成和编程助手
- ✅ 多轮对话和任务规划
- ✅ 工具调用和API集成
- ✅ 多模态内容理解

## 三、核心功能详解

### 3.1 同步对话调用

**方法签名**：
```java
@Override
public ChatResponse call(Prompt prompt)
```

**功能说明**：
- 发送对话请求，阻塞等待完整响应
- 自动处理配置合并（运行时配置 + 默认配置）
- 自动执行 Function Calling（如果需要）
- 返回包含完整回复的 `ChatResponse`

**执行流程**：
```
1. 验证 Prompt 参数
2. 构建请求 Prompt（合并配置）
3. 调用 internalCall() 执行请求
4. 如果需要工具调用：
   4.1 执行工具
   4.2 如果需要返回工具结果 → 直接返回
   4.3 否则 → 将工具结果发回模型，递归调用
5. 返回 ChatResponse
```

**使用示例**：
```java
// 简单调用
ChatResponse response = chatModel.call(
    new Prompt("介绍一下 Spring AI Alibaba")
);
String content = response.getResult().getOutput().getContent();

// 带配置调用
ChatResponse response = chatModel.call(
    new Prompt("生成一首诗", 
        DashScopeChatOptions.builder()
            .withTemperature(0.9)
            .withMaxTokens(500)
            .build())
);
```

### 3.2 流式对话调用

**方法签名**：
```java
@Override
public Flux<ChatResponse> stream(Prompt prompt)
```

**功能说明**：
- 发送对话请求，实时流式返回响应
- 返回 `Flux<ChatResponse>`，每个元素包含增量内容
- 支持 Function Calling 的流式执行
- 自动聚合消息和元数据

**响应式编程特点**：
```java
Flux<ChatResponse> flux = chatModel.stream(prompt);

// 订阅并处理每个chunk
flux.subscribe(
    chatResponse -> {
        // 处理每个增量响应
        String content = chatResponse.getResult().getOutput().getContent();
        System.out.print(content); // 逐字输出
    },
    error -> {
        // 错误处理
        logger.error("Stream error", error);
    },
    () -> {
        // 完成处理
        System.out.println("\n[Stream completed]");
    }
);
```

**流式执行流程**：
```
1. 验证 Prompt 参数
2. 构建请求 Prompt
3. 创建 ChatCompletionRequest（stream=true）
4. 调用 API 获取 Flux<ChatCompletionChunk>
5. 转换每个 Chunk 为 ChatCompletion
6. 处理 Function Calling（如果需要）
7. 使用 MessageAggregator 聚合消息
8. 返回 Flux<ChatResponse>
```

**使用示例**：
```java
// 方式1：subscribe 订阅
chatModel.stream(new Prompt("讲个故事"))
    .subscribe(response -> {
        System.out.print(response.getResult().getOutput().getContent());
    });

// 方式2：block 阻塞收集
String fullContent = chatModel.stream(new Prompt("写首诗"))
    .collectList()
    .map(list -> list.stream()
        .map(r -> r.getResult().getOutput().getContent())
        .collect(Collectors.joining()))
    .block();

// 方式3：使用 ChatClient（推荐）
chatClient.prompt()
    .user("介绍Spring")
    .stream()
    .content()
    .subscribe(System.out::print);
```

### 3.3 Function Calling（工具调用）

**核心组件**：
```java
// 工具调用管理器
private final ToolCallingManager toolCallingManager;

// 工具执行判定
private final ToolExecutionEligibilityPredicate toolExecutionEligibilityPredicate;
```

**工作流程**：
```
第一轮调用：
1. 用户发送问题："北京今天天气怎么样？"
2. LLM 判断需要调用工具
3. 返回 tool_calls（工具名称和参数）

工具执行：
4. toolCallingManager.executeToolCalls()
5. 执行 getWeather(city="北京")
6. 获取工具结果："晴天，25℃"

第二轮调用（自动）：
7. 将工具结果作为 ToolResponseMessage 发回
8. LLM 基于工具结果生成最终回复
9. 返回："北京今天天气晴朗，温度25℃，适合外出。"
```

**定义工具示例**：
```java
@Configuration
public class ToolConfig {
    
    @Bean
    @Description("获取指定城市的天气信息")
    public Function<WeatherRequest, String> getWeather() {
        return request -> {
            // 实际应该调用天气API
            return "晴天，温度" + 25 + "℃";
        };
    }
    
    public record WeatherRequest(
        @JsonProperty(required = true) 
        @JsonPropertyDescription("城市名称，例如：北京、上海") 
        String city
    ) {}
}
```

**使用工具调用**：
```java
// 方式1：通过配置启用
ChatResponse response = chatModel.call(
    new Prompt("北京今天天气怎么样？",
        DashScopeChatOptions.builder()
            .withFunction("getWeather")  // 指定工具名称
            .build())
);

// 方式2：使用 ChatClient（推荐）
String response = chatClient.prompt()
    .user("北京今天天气怎么样？")
    .function("getWeather", getWeather())  // 注册工具
    .call()
    .content();

// 方式3：并行工具调用
ChatResponse response = chatModel.call(
    new Prompt("北京和上海今天天气对比",
        DashScopeChatOptions.builder()
            .withFunction("getWeather")
            .withParallelToolCalls(true)  // 启用并行调用
            .build())
);
```

**内部工具执行控制**：
```java

    .withInternalToolExecutionEnabled(true)
    .build();

// 自定义工具执行判定

        // 自定义判定逻辑
```

## 五、主要方法详解

### 5.1 call() - 同步调用

**完整方法签名**：
```java
@Override
public ChatResponse call(Prompt prompt)
```

**内部实现逻辑**：
```java
public ChatResponse call(Prompt prompt) {
    // 1. 参数验证
    Assert.notNull(prompt, "Prompt must not be null");
    Assert.isTrue(!CollectionUtils.isEmpty(prompt.getInstructions()), 
        "Prompt messages must not be empty");
    
    // 2. 构建请求 Prompt（合并配置）
    Prompt requestPrompt = buildRequestPrompt(prompt);
    
    // 3. 执行内部调用
    return internalCall(requestPrompt, null);
}
```

**internalCall() 核心逻辑**：
```java
public ChatResponse internalCall(Prompt prompt, ChatResponse previousChatResponse) {
    // 1. 创建API请求
    ChatCompletionRequest request = createRequest(prompt, false);
    
    // 2. 创建观测上下文
    ChatModelObservationContext observationContext = ...
    
    // 3. 执行观测调用
    ChatResponse response = observation.observe(() -> {
        // 4. 重试执行API调用
        ResponseEntity<ChatCompletion> completionEntity = 
            this.retryTemplate.execute(ctx -> 
                dashscopeApi.chatCompletionEntity(request, headers)
            );
        
        // 5. 转换响应
        return toChatResponse(completionEntity.getBody(), ...);
    });
    
    // 6. 判断是否需要执行工具
    if (toolExecutionEligibilityPredicate.isToolExecutionRequired(...)) {
        // 7. 执行工具
        ToolExecutionResult toolResult = 
            toolCallingManager.executeToolCalls(prompt, response);
        
        if (toolResult.returnDirect()) {
            // 8a. 直接返回工具结果
            return ChatResponse.builder()
                .from(response)
                .generations(ToolExecutionResult.buildGenerations(toolResult))
                .build();
        } else {
            // 8b. 将工具结果发回模型，递归调用
            return this.internalCall(
                new Prompt(toolResult.conversationHistory(), prompt.getOptions()),
                response
            );
        }
    }
    
    // 9. 返回响应
    return response;
}
```

**请求构建**：
```java
Prompt buildRequestPrompt(Prompt prompt) {
    // 1. 处理运行时配置
    DashScopeChatOptions runtimeOptions = null;
    if (prompt.getOptions() != null) {
        runtimeOptions = ModelOptionsUtils.copyToTarget(
            prompt.getOptions(), 
            ChatOptions.class,
            DashScopeChatOptions.class
        );
    }
    
    // 2. 合并运行时配置和默认配置
    DashScopeChatOptions requestOptions = ModelOptionsUtils.merge(
        runtimeOptions, 
        this.defaultOptions,
        DashScopeChatOptions.class
    );
    
    // 3. 合并 @JsonIgnore 注解的选项
    if (runtimeOptions != null) {
        requestOptions.setInternalToolExecutionEnabled(...);
        requestOptions.setToolNames(...);
        requestOptions.setToolCallbacks(...);
        requestOptions.setToolContext(...);
    }
    
    // 4. 返回新的 Prompt
    return new Prompt(prompt.getInstructions(), requestOptions);
}
```

**内部实现逻辑**：

```java
public Flux<ChatResponse> stream(Prompt prompt) {
```

**internalStream() 核心逻辑**：
```java
public Flux<ChatResponse> internalStream(Prompt prompt, ChatResponse previousChatResponse) {
    return Flux.deferContextual(contextView -> {
        // 1. 创建API请求（stream=true）
        ChatCompletionRequest request = createRequest(prompt, true);
        
        // 2. 获取流式响应
        Flux<ChatCompletionChunk> completionChunks = this.retryTemplate
            .execute(ctx -> this.dashscopeApi.chatCompletionStream(request, headers));
        
        // 3. 角色映射（首次chunk包含role，后续共享）
        ConcurrentHashMap<String, String> roleMap = new ConcurrentHashMap<>();
        
        // 4. 创建观测上下文和观测对象
        ChatModelObservationContext observationContext = ...
        Observation observation = ...
        
        // 5. 启动观测
        observation.parentObservation(...).start();
        
        // 6. 转换 Chunk 为 ChatCompletion
        Flux<ChatResponse> chatResponse = completionChunks
            .map(this::chunkToChatCompletion)
            .switchMap(chatCompletion -> Mono.just(chatCompletion)
                .map(chatCompletion2 -> toChatResponse(
                    chatCompletion2, 
                    previousChatResponse, 
                    request, 
                    roleMap
                ))
            );
        
        // 7. 处理 Function Calling
        Flux<ChatResponse> flux = chatResponse.flatMap(response -> {
            if (toolExecutionEligibilityPredicate.isToolExecutionRequired(...)) {
                return Flux.deferContextual((ctx) -> {
                    // 7a. 执行工具
                    ToolExecutionResult toolResult = ...
                    
                    if (toolResult.returnDirect()) {
                        // 7b. 直接返回工具结果
                        return Flux.just(...);
                    } else {
                        // 7c. 递归流式调用
                        return this.internalStream(
                            new Prompt(toolResult.conversationHistory(), ...),
                            response
                        );
                    }
                }).subscribeOn(Schedulers.boundedElastic());
            } else {
                return Flux.just(response);
            }
        })
        .doOnError(observation::error)
        .doFinally(s -> observation.stop())
        .contextWrite(ctx -> ctx.put(ObservationThreadLocalAccessor.KEY, observation));
        
        // 8. 使用 MessageAggregator 聚合消息
        return new MessageAggregator().aggregate(flux, observationContext::setResponse);
    });
}
```

```java
ChatCompletionRequest createRequest(Prompt prompt, boolean stream) {
    // 1. 转换消息列表
    List<ChatCompletionMessage> chatCompletionMessages = 
        prompt.getInstructions().stream().map(message -> {
            
            if (message.getMessageType() == MessageType.USER || 
                message.getMessageType() == MessageType.SYSTEM) {
                // USER 或 SYSTEM 消息
                Object content = message.getText();
                
                // 处理多模态内容
                if (message instanceof UserMessage userMessage) {
                    if (!CollectionUtils.isEmpty(userMessage.getMedia())) {
                        content = convertMediaContent(userMessage);
                    }
                }
                
                return List.of(new ChatCompletionMessage(
                    content,
                    ChatCompletionMessage.Role.valueOf(message.getMessageType().name())
                ));
            }
            else if (message.getMessageType() == MessageType.ASSISTANT) {
                // ASSISTANT 消息（带工具调用）
                var assistantMessage = (AssistantMessage) message;
                List<ToolCall> toolCalls = null;
                
                if (!CollectionUtils.isEmpty(assistantMessage.getToolCalls())) {
                    toolCalls = assistantMessage.getToolCalls().stream()
                        .map(toolCall -> {
                            var function = new ChatCompletionFunction(
                                toolCall.name(), 
                                toolCall.arguments()
                            );
                            return new ToolCall(toolCall.id(), toolCall.type(), function);
                        })
                        .toList();
                }
                
                return List.of(new ChatCompletionMessage(
                    assistantMessage.getText(),
                    ChatCompletionMessage.Role.ASSISTANT,
                    null, null, toolCalls, null
                ));
            }
            else if (message.getMessageType() == MessageType.TOOL) {
                // TOOL 响应消息
                ToolResponseMessage toolMessage = (ToolResponseMessage) message;
                
                // 验证工具响应
                toolMessage.getResponses().forEach(response -> {
                    Assert.isTrue(response.id() != null, 
                        "ToolResponseMessage must have an id");
                    Assert.isTrue(response.name() != null, 
                        "ToolResponseMessage must have a name");
                });
                
                // 转换为 ChatCompletionMessage
                return toolMessage.getResponses().stream()
                    .map(tr -> new ChatCompletionMessage(
                        tr.responseData(),
                        ChatCompletionMessage.Role.TOOL,
                        tr.name(), tr.id(), null, null
                    ))
                    .toList();
            }
            else {
                throw new IllegalArgumentException(
                    "Unsupported message type: " + message.getMessageType()
                );
            }
        })
        .flatMap(List::stream)
        .toList();
    
    // 2. 获取请求配置
    DashScopeChatOptions requestOptions = (DashScopeChatOptions) prompt.getOptions();
    
    // 3. 解析工具定义
    List<ToolDefinition> toolDefinitions = 
        this.toolCallingManager.resolveToolDefinitions(requestOptions);
    
    if (!CollectionUtils.isEmpty(toolDefinitions)) {
        requestOptions.setTools(getFunctionTools(toolDefinitions));
    }
    
    // 4. 获取 multiModel 标志
    boolean multiModel = requestOptions.getMultiModel();
    
    // 5. 构建并返回请求
    return new ChatCompletionRequest(
        requestOptions.getModel(),
        new ChatCompletionRequestInput(chatCompletionMessages),
        toDashScopeRequestParameter(requestOptions, stream),
        stream,
        multiModel
    );
}
```

**方法签名**：
```java

    ChatCompletion chatCompletion,
    ChatResponse previousChatResponse,
    ChatCompletionRequest request,

```

**实现逻辑**：
```java
private ChatResponse toChatResponse(...) {
    // 1. 空响应检查
    if (chatCompletion == null) {
        logger.warn("Null chat completion returned");
        return new ChatResponse(List.of());
    }
    
    // 2. 获取 choices
    List<ChatCompletionOutput.Choice> choices = chatCompletion.output().choices();
    if (choices == null) {
        logger.warn("No choices returned");
        return new ChatResponse(List.of());
    }
    
    // 3. 获取搜索信息
    DashScopeApi.SearchInfo searchInfo = chatCompletion.output().searchInfo();
    
    // 4. 角色映射
    ConcurrentHashMap<String, String> finalRoleMap = 
        roleMap == null ? new ConcurrentHashMap<>() : roleMap;
    
    // 5. 转换每个 choice 为 Generation
    List<Generation> generations = choices.stream().map(choice -> {
        // 5a. 记录角色
        if (choice.message().role() != null) {
            finalRoleMap.putIfAbsent(
                chatCompletion.requestId(), 
                choice.message().role().name()
            );
        }
        
        // 5b. 构建元数据
        Map<String, Object> metadata = Map.of(
            "id", chatCompletion.requestId(),
            "role", finalRoleMap.getOrDefault(chatCompletion.requestId(), ""),
            "finishReason", finishReasonToMetadataValue(choice.finishReason()),
            "reasoningContent", StringUtils.hasText(choice.message().reasoningContent()) 
                ? choice.message().reasoningContent() : "",
            "search_info", Objects.isNull(searchInfo) ? "" : searchInfo
        );
        
        // 5c. 构建 Generation
        return buildGeneration(choice, metadata, request);
    }).toList();
    
    // 6. 计算 Token 使用量
    DashScopeApi.TokenUsage usage = chatCompletion.usage();
    Usage currentChatResponseUsage = usage != null 
        ? this.getDefaultUsage(usage) 
        : new EmptyUsage();
    
    // 7. 累计使用量（多轮调用）
    Usage accumulatedUsage = UsageCalculator.getCumulativeUsage(
        currentChatResponseUsage, 
        previousChatResponse
    );
    
    // 8. 构建并返回 ChatResponse
    return new ChatResponse(
        generations, 
        this.from(chatCompletion, accumulatedUsage)
    );
}
```

**Generation 构建**：
```java
private static Generation buildGeneration(
        Choice choice, 
        Map<String, Object> metadata,
        ChatCompletionRequest request) {
    
    // 1. 提取工具调用
    List<AssistantMessage.ToolCall> toolCalls = 
        choice.message().toolCalls() == null ? List.of()
        : choice.message().toolCalls().stream()
            .filter(toolCall -> {
                if (toolCall.function() == null) {
                    logger.warn("Filtering out toolCall with null function: {}", toolCall);
                    return false;
                }
                if (toolCall.function().name() == null) {
                    logger.warn("Filtering out toolCall with null function name: {}", toolCall);
                    return false;
                }
                return true;
            })
            .map(toolCall -> new AssistantMessage.ToolCall(
                toolCall.id(),
                "function",
                toolCall.function().name(),
                toolCall.function().arguments()
            ))
            .toList();
    
    // 2. 构建 finishReason
    String finishReason = finishReasonToMetadataValue(choice.finishReason());
    
    // 3. 构建 ChatGenerationMetadata
    var generationMetadata = ChatGenerationMetadata.builder()
        .finishReason(finishReason)
        .build();
    
    // 4. 构建 AssistantMessage
    var assistantMessage = new AssistantMessage(
        choice.message().content(),
        metadata,
        toolCalls
    );
    
    // 5. 返回 Generation
    return new Generation(assistantMessage, generationMetadata);
}
```

```java
private List<MediaContent> convertMediaContent(UserMessage message) {
    // 1. 获取消息格式
    MessageFormat format = MessageFormat.IMAGE;
    if (message.getMetadata().get(DashScopeApiConstants.MESSAGE_FORMAT) 
            instanceof MessageFormat messageFormat) {
        format = messageFormat;
    }
    
    List<MediaContent> contentList = new ArrayList<>();
    
    // 2. 根据格式转换
    if (format == MessageFormat.VIDEO) {
        // 视频格式
        List<String> mediaList = message.getMedia().stream()
            .map(media -> this.fromMediaData(media.getMimeType(), media.getData()))
            .toList();
        
        contentList.add(new MediaContent("video", null, null, mediaList));
        contentList.add(new MediaContent(message.getText()));
    }
    else if (format == MessageFormat.AUDIO) {
        // 音频格式
        contentList.addAll(message.getMedia().stream()
            .map(media -> new MediaContent(
                "audio", 
                null, null, null,
                this.fromMediaData(media.getMimeType(), media.getData())
            ))
            .toList());
        
        contentList.add(new MediaContent(message.getText()));
    }
    else {
        // 图片格式（默认）
        contentList.addAll(message.getMedia().stream()
            .map(media -> new MediaContent(
                "image",
                null,
                this.fromMediaData(media.getMimeType(), media.getData()),
                null
            ))
            .toList());
        
        contentList.add(new MediaContent(message.getText()));
    }
    
    return contentList;
}
```

**媒体数据转换**：
```java
private String fromMediaData(MimeType mimeType, Object mediaContentData) {
    if (mediaContentData instanceof byte[] bytes) {
        // 字节数组 → Base64编码
        return String.format(
            "data:%s;base64,%s",
            mimeType.toString(),
            Base64.getEncoder().encodeToString(bytes)
        );
    }
    else if (mediaContentData instanceof String text) {
        // 字符串（URL或Base64）
        return text;
    }
    else {
        throw new IllegalArgumentException(
            "Unsupported media data type: " + mediaContentData.getClass().getSimpleName()
        );
    }
}
```

```java
            question,
            List.of(new Media(MimeTypeUtils.IMAGE_PNG, imageUrl))
        );
        
        // 创建Prompt
        Prompt prompt = new Prompt(
            List.of(message),
            DashScopeChatOptions.builder()
                .withModel("qwen-vl-max")
                .withVlHighResolutionImages(true)
                .build()
        );
        
        // 调用模型
        ChatResponse response = chatModel.call(prompt);
        return response.getResult().getOutput().getContent();
    }
    
    public String analyzeLocalImage(Path imagePath, String question) throws IOException {
        // 读取本地图片
        byte[] imageBytes = Files.readAllBytes(imagePath);
        
        // 创建消息
        UserMessage message = new UserMessage(
            question,
            List.of(new Media(MimeTypeUtils.IMAGE_PNG, imageBytes))
        );
        
        // 调用模型
        ChatResponse response = chatModel.call(
            new Prompt(message, 
                DashScopeChatOptions.builder()
                    .withModel("qwen-vl-max")
                    .build())
        );
        
        return response.getResult().getOutput().getContent();
    }
}

// 使用示例
String analysis = visionService.analyzeImage(
    "https://example.com/image.png",
```

### 9.1 配置管理

```
全局默认配置（application.yml）
    ↓
Model默认配置（构造时设置）
    ↓
```

```java
// 全局配置
spring.ai.dashscope.chat.options.temperature: 0.7

// Model默认配置
DashScopeChatModel model = DashScopeChatModel.builder()

        .withModel("qwen-plus")
        .withMaxTokens(2000)
        .build())
    .build();

// 运行时配置
ChatResponse response = model.call(
    new Prompt("生成诗歌",
        DashScopeChatOptions.builder()
            .withTemperature(0.9)  // 覆盖默认值
            .build())
);
```

### 9.2 性能优化

**1. 使用流式调用**：
```java
// ❌ 不推荐：阻塞等待完整响应
String response = chatModel.call(new Prompt(longText)).getResult().getOutput().getContent();

// ✅ 推荐：流式返回，用户体验更好
chatModel.stream(new Prompt(longText))
    .subscribe(chunk -> {
        System.out.print(chunk.getResult().getOutput().getContent());
    });
```

**2. 合理设置 maxTokens**：
```java
// 根据实际需要设置，避免浪费
DashScopeChatOptions options = DashScopeChatOptions.builder()
    .withMaxTokens(500)  // 简短回复
    .build();
```

**3. 使用缓存**：
```java
@Cacheable("chatResponses")
public String cachedChat(String message) {
    return chatModel.call(new Prompt(message))
        .getResult().getOutput().getContent();
}
```

## 十、注意事项与FAQ

### 10.1 注意事项

| 注意事项 | 说明 |
|---------|------|
| **API Key 安全** | 不要在代码中硬编码 API Key，使用环境变量或配置中心 |
| **Token 限制** | 注意模型的 token 限制，超出会被截断 |
| **并发控制** | 控制并发请求数，避免超出API限制 |
| **成本控制** | 监控 Token 使用量，选择合适的模型 |
| **超时设置** | 为长文本生成设置合理的超时时间 |
| **错误重试** | 网络错误应该重试，业务错误不应该重试 |

---

### 10.2 常见问题

**Q1: 为什么调用没有响应？**
```
A: 检查以下几点：
1. API Key 是否正确
2. 网络连接是否正常
3. 模型名称是否正确
4. 是否超出 Token 限制
5. 查看日志中的错误信息
```

**Q2: 如何提高响应速度？**
```
A: 
1. 使用流式调用 stream()
2. 选择更快的模型（如 qwen-turbo）
3. 减小 maxTokens
4. 使用缓存
5. 启用 HTTP/2
```

**Q3: Function Calling 不工作？**
```
A: 
1. 确认工具定义正确（@Description 注解）
2. 确认 internalToolExecutionEnabled=true
3. 确认模型支持工具调用
4. 检查工具参数类型是否匹配
5. 查看日志中的工具调用信息
```

**Q4: 如何实现多轮对话？**
```
A: 
方式1：手动管理历史
List<Message> history = new ArrayList<>();
history.add(new UserMessage("你好"));
history.add(new AssistantMessage("你好！"));
history.add(new UserMessage("今天天气怎么样？"));
chatModel.call(new Prompt(history));

方式2：使用 ChatMemory
chatClient.prompt()
    .user("继续刚才的话题")
    .call()
    .content();
```

**Q5: 如何处理超长文本？**
```
A: 
1. 分段处理
2. 使用长文本模型（qwen-long）
3. 提取关键信息
4. 使用 RAG 方案
```
