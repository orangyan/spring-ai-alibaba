## 一、类概述

### 1.1 设计目的

`DashScopeAudioSpeechModel` 是 Spring AI Alibaba 框架中用于将文本转换为语音（TTS, Text-to-Speech）的核心实现类。它基于阿里云百炼的语音合成服务，支持多种音色、语速、音调控制，可实现自然流畅的语音输出。

### 1.2 什么是 TTS（Text-to-Speech）？

**TTS（文本转语音）** 是将文本内容转换为自然语音的技术。

```
输入文本："你好，欢迎使用 Spring AI Alibaba"
    ↓
语音合成模型处理
    ↓
输出音频：🔊 语音文件（WAV/MP3/PCM等格式）
```

### 1.3 核心特性

| 特性 | 说明 |
|------|------|
| **流式输出** | 实时流式返回音频数据，无需等待全部生成 |
| **多种音色** | 支持男声、女声、童声等多种音色 |
| **语速控制** | 可调节语速（0.5-2.0倍） |
| **音调控制** | 可调节音调高低 |
| **多种格式** | 支持 PCM、WAV、MP3 等格式 |
| **高质量音频** | 支持 8k/16k/24k/48k 采样率 |
| **时间戳支持** | 可获取音素和单词级别时间戳 |

### 1.4 支持的音色

| 音色 | Voice ID | 特点 |
|------|----------|------|
| **知性女声** | `zhixiaoxia` | 标准女声，清晰自然 |

| **活力女声** | `zhiqiang` | 年轻活力 |

| **情感男声** | `zhihao` | 情感丰富 |
| **童声** | `zhiqi` | 儿童声音 |

### 1.5 使用场景

- ✅ **有声阅读**：电子书、新闻播报
- ✅ **智能客服**：语音回复、电话机器人

## 五、主要方法详解

### 5.1 call() - 同步合成

**方法签名**：
```java
@Override
public SpeechSynthesisResponse call(SpeechSynthesisPrompt prompt)
```

**实现逻辑**：
```java
public SpeechSynthesisResponse call(SpeechSynthesisPrompt prompt) {
    // 1. 获取流式响应
    Flux<SpeechSynthesisResponse> flux = this.stream(prompt);
    
    // 2. 合并所有音频块
    return flux.reduce((resp1, resp2) -> {
        // 创建合并后的 ByteBuffer
        ByteBuffer combinedBuffer = ByteBuffer.allocate(
            resp1.getResult().getOutput().getAudio().remaining()
            + resp2.getResult().getOutput().getAudio().remaining()
        );
        
        // 合并音频数据
        combinedBuffer.put(resp1.getResult().getOutput().getAudio());
        combinedBuffer.put(resp2.getResult().getOutput().getAudio());
        combinedBuffer.flip();
        
        // 返回合并后的响应
        return new SpeechSynthesisResponse(
            new SpeechSynthesisResult(
                new SpeechSynthesisOutput(combinedBuffer)
            )
        );
    }).block();  // 阻塞等待完成
}
```

---

### 5.2 stream() - 流式合成

**方法签名**：
```java
@Override
public Flux<SpeechSynthesisResponse> stream(SpeechSynthesisPrompt prompt)
```

**实现逻辑**：
```java
public Flux<SpeechSynthesisResponse> stream(SpeechSynthesisPrompt prompt) {
    return this.retryTemplate.execute(ctx -> 
        // 调用 WebSocket API 流式输出
        this.api.streamOut(createRequest(prompt))
            .map(SpeechSynthesisOutput::new)     // ByteBuffer → Output
            .map(SpeechSynthesisResult::new)     // Output → Result
            .map(SpeechSynthesisResponse::new)   // Result → Response
    );
}
```

### 5.3 createRequest() - 创建API请求

**方法签名**：
```java
public DashScopeAudioSpeechApi.Request createRequest(SpeechSynthesisPrompt prompt)
```

**实现逻辑**：
```java
public DashScopeAudioSpeechApi.Request createRequest(SpeechSynthesisPrompt prompt) {
    // 1. 初始化默认选项
    DashScopeAudioSpeechOptions options = DashScopeAudioSpeechOptions.builder().build();
    
    // 2. 合并运行时选项
    if (prompt.getOptions() != null) {
        DashScopeAudioSpeechOptions runtimeOptions = ModelOptionsUtils.copyToTarget(
            prompt.getOptions(),
            SpeechSynthesisOptions.class,
            DashScopeAudioSpeechOptions.class
        );
        
        options = ModelOptionsUtils.merge(runtimeOptions, options, 
            DashScopeAudioSpeechOptions.class);
    }
    
    // 3. 合并默认选项
    options = ModelOptionsUtils.merge(options, this.options, 
        DashScopeAudioSpeechOptions.class);
    
    // 4. 构建请求
    return new DashScopeAudioSpeechApi.Request(
        new DashScopeAudioSpeechApi.Request.RequestHeader(
            "run-task",                    // action
            UUID.randomUUID().toString(),  // task_id
            "out"                          // streaming
        ),
        new DashScopeAudioSpeechApi.Request.RequestPayload(
            options.getModel(),            // model
            "audio",                       // task_group
            "tts",                         // task
            "SpeechSynthesizer",           // function
            new DashScopeAudioSpeechApi.Request.RequestPayload.RequestPayloadInput(
                prompt.getInstructions().get(0).getText()  // text
            ),
            new DashScopeAudioSpeechApi.Request.RequestPayload.RequestPayloadParameters(
                options.getVolume(),                // volume
                options.getRequestTextType().getValue(),  // text_type
                options.getVoice(),                 // voice
                options.getSampleRate(),            // sample_rate
                options.getSpeed(),                 // speed
                options.getResponseFormat().getValue(),   // format
                options.getPitch(),                 // pitch
                options.getEnablePhonemeTimestamp(),  // enable_phoneme_timestamp
                options.getEnableWordTimestamp()      // enable_word_timestamp
            )
        )
    );
}
```

### 7.2 流式实时播放

```java
@Service
public class StreamingTTSService {
    
    private final SpeechSynthesisModel speechModel;
    
    public void streamAndPlay(String text) {
        // 创建提示
        SpeechSynthesisPrompt prompt = new SpeechSynthesisPrompt(
            text,
            DashScopeAudioSpeechOptions.builder()
                .withVoice("zhixiaoxia")
                .withSpeed(1.0)
                .withSampleRate(16000)
                .withResponseFormat(AudioFormat.PCM)
                .build()
        );
        
        // 流式合成
        Flux<SpeechSynthesisResponse> audioStream = speechModel.stream(prompt);
        
        // 初始化音频播放器
        AudioPlayer player = new AudioPlayer(16000, 16, 1);  // 16kHz, 16bit, 单声道
        
        // 处理每个音频块
        audioStream
            .doOnNext(response -> {
                ByteBuffer audioChunk = response.getResult().getOutput().getAudio();
                byte[] audioBytes = new byte[audioChunk.remaining()];
                audioChunk.get(audioBytes);
                
                // 实时播放
                player.play(audioBytes);
            })
            .doOnError(error -> {
                System.err.println("合成失败: " + error.getMessage());
                player.stop();
            })
            .doOnComplete(() -> {
                System.out.println("播放完成");
                player.stop();
            })
            .subscribe();
    }
}
```

### 7.5 REST API 示例

```java
@RestController
@RequestMapping("/api/tts")
public class TTSController {
    
    private final SpeechSynthesisModel speechModel;
    
    @PostMapping("/synthesize")
    public ResponseEntity<byte[]> synthesize(@RequestBody TTSRequest request) {
        try {
            // 创建提示
            SpeechSynthesisPrompt prompt = new SpeechSynthesisPrompt(
                request.getText(),
                DashScopeAudioSpeechOptions.builder()
                    .withVoice(request.getVoice())
                    .withSpeed(request.getSpeed())
                    .withVolume(request.getVolume())
                    .withResponseFormat(AudioFormat.valueOf(request.getFormat()))
                    .withSampleRate(request.getSampleRate())
                    .build()
            );
            
            // 执行合成
            SpeechSynthesisResponse response = speechModel.call(prompt);
            
            // 获取音频数据
            ByteBuffer audioData = response.getResult().getOutput().getAudio();
            byte[] audioBytes = new byte[audioData.remaining()];
            audioData.get(audioBytes);
            
            // 返回音频
            HttpHeaders headers = new HttpHeaders();
            headers.setContentType(MediaType.APPLICATION_OCTET_STREAM);
            headers.setContentDisposition(
                ContentDisposition.attachment()
                    .filename("speech." + request.getFormat().toLowerCase())
                    .build()
            );
            
            return new ResponseEntity<>(audioBytes, headers, HttpStatus.OK);
        }
        catch (Exception e) {
            return ResponseEntity.status(HttpStatus.INTERNAL_SERVER_ERROR).build();
        }
    }
}

@Data
class TTSRequest {
    private String text;
    private String voice = "zhixiaoxia";
    private Double speed = 1.0;
    private Integer volume = 50;
    private String format = "WAV";
    private Integer sampleRate = 16000;
}
```

### 9.1 注意事项

| 注意事项 | 说明 |
|---------|------|
| **文本长度限制** | 单次合成建议 < 300字 |
| **特殊字符** | 需要处理HTML标签、表情符号等 |
| **数字读法** | 数字会自动转为中文读法 |
| **标点符号** | 影响语音停顿和语调 |
| **流式延迟** | 首包延迟约200-500ms |
| **音频格式** | PCM需要自行添加WAV头 |

```java
public byte[] addWavHeader(byte[] pcmData, int sampleRate) {
    int totalDataLen = pcmData.length + 36;
    int byteRate = sampleRate * 2;
    
    byte[] header = new byte[44];
    // ... WAV头部构造逻辑
    
    byte[] wavData = new byte[header.length + pcmData.length];
```
