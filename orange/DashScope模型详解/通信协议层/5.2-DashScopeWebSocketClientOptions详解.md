## 一、类概述

### 1.1 设计目的

`DashScopeWebSocketClientOptions` 是一个简单的配置类，用于存储WebSocket客户端的连接参数。它使用Builder模式实现链式配置，简化了客户端的创建过程。

### 1.2 完整定义

```java
package com.alibaba.cloud.ai.dashscope.protocol;

public class DashScopeWebSocketClientOptions {
    
    // WebSocket服务URL
    private String url = DashScopeApiConstants.DEFAULT_WEBSOCKET_URL;
    
    // API密钥
    private String apiKey;
    
    // 工作空间ID（可选）
    private String workSpaceId = null;
    
    // Getters and Setters...
    
    public static Builder builder() {
        return new Builder();
    }
    
    public static class Builder {
        // Builder实现...
    }
}
```

### 1.3 设计特点

- ✅ **简单配置**：只包含3个必要参数
- ✅ **Builder模式**：链式调用，代码优雅
- ✅ **默认值**：提供合理的默认配置
- ✅ **可选参数**：workSpaceId可选

## 二、字段详解

### 2.1 url（WebSocket URL）

**类型**：`String`  
**默认值**：`DashScopeApiConstants.DEFAULT_WEBSOCKET_URL`  
**必填**：否（有默认值）

**说明**：
- DashScope WebSocket服务的端点地址
- 默认值：`wss://dashscope.aliyuncs.com/api-ws/v1`
- 通常不需要修改，除非使用私有部署或测试环境

**使用场景**：

```java
// 使用默认URL
DashScopeWebSocketClientOptions options = 
    DashScopeWebSocketClientOptions.builder()
        .withApiKey("your-api-key")
        .build();

// 自定义URL（私有部署）
DashScopeWebSocketClientOptions options = 
    DashScopeWebSocketClientOptions.builder()
        .withUrl("wss://custom-dashscope.company.com/api-ws/v1")
        .withApiKey("your-api-key")
        .build();

// 测试环境
DashScopeWebSocketClientOptions options = 
    DashScopeWebSocketClientOptions.builder()
        .withUrl("wss://test-dashscope.aliyuncs.com/api-ws/v1")
        .withApiKey("test-api-key")
        .build();
```

**URL格式**：
```
wss://{domain}/api-ws/v1
│   │  │        │       │
│   │  │        │       └─ API版本
│   │  │        └────────── WebSocket API路径
│   │  └─────────────────── 域名
│   └────────────────────── 协议
└────────────────────────── 安全WebSocket
```

---

### 2.2 apiKey（API密钥）

**类型**：`String`  
**默认值**：`null`  
**必填**：✅ 是

**说明**：
- 阿里云百炼平台的API密钥
- 用于身份认证，会添加到HTTP头的Authorization字段
- 格式：`Bearer {apiKey}`

**获取方式**：
1. 登录阿里云百炼平台
2. 进入API密钥管理页面
3. 创建或查看API Key

**使用示例**：
```java
DashScopeWebSocketClientOptions options = 
    DashScopeWebSocketClientOptions.builder()
        .withApiKey("sk-xxxxxxxxxxxxxxxxxxxx")  // 你的API Key
        .build();
```

**安全建议**：
```java
// ❌ 不要硬编码API Key
DashScopeWebSocketClientOptions options = 
    DashScopeWebSocketClientOptions.builder()
        .withApiKey("sk-12345678")  // 不安全！
        .build();

// ✅ 从环境变量读取
String apiKey = System.getenv("DASHSCOPE_API_KEY");
DashScopeWebSocketClientOptions options = 
    DashScopeWebSocketClientOptions.builder()
        .withApiKey(apiKey)
        .build();

// ✅ 从配置文件读取
@Value("${dashscope.api-key}")
private String apiKey;

DashScopeWebSocketClientOptions options = 
    DashScopeWebSocketClientOptions.builder()
        .withApiKey(apiKey)
        .build();
```

### 2.3 workSpaceId（工作空间ID）

**类型**：`String`  
**默认值**：`null`  
**必填**：否

**说明**：
- 多租户场景下的工作空间标识
- 用于数据隔离和资源管理
- 如果不设置，使用默认工作空间

**使用场景**：

**场景1：单租户（不需要workSpaceId）**
```java
// 个人开发者或小团队
DashScopeWebSocketClientOptions options = 
    DashScopeWebSocketClientOptions.builder()
        .withApiKey("your-api-key")
        // 不设置workSpaceId，使用默认工作空间
        .build();
```

**场景2：多租户（需要workSpaceId）**
```java
// 企业级应用，多个工作空间
DashScopeWebSocketClientOptions options = 
    DashScopeWebSocketClientOptions.builder()
        .withApiKey("your-api-key")
        .withWorkSpaceId("workspace-123")  // 指定工作空间
        .build();
```

**场景3：动态工作空间**
```java
public class MultiTenantWebSocketService {
    
    /**
     * 根据租户创建客户端
     */
    public DashScopeWebSocketClient createClientForTenant(String tenantId) {
        String workSpaceId = tenantService.getWorkSpaceId(tenantId);
        
        DashScopeWebSocketClientOptions options = 
            DashScopeWebSocketClientOptions.builder()
                .withApiKey(apiKey)
                .withWorkSpaceId(workSpaceId)  // 租户专属工作空间
                .build();
        
        return new DashScopeWebSocketClient(options);
    }
}
```

**工作空间作用**：
- 数据隔离：不同工作空间的数据相互隔离
- 资源配额：可以为不同工作空间设置不同配额
- 计费分离：按工作空间进行费用统计

### 3.3 从配置文件加载

**application.yml**:
```yaml
dashscope:
  websocket:
    url: wss://dashscope.aliyuncs.com/api-ws/v1
    api-key: ${DASHSCOPE_API_KEY}  # 从环境变量读取
    workspace-id: workspace-prod
```

**配置类**:
```java
@Configuration
@ConfigurationProperties(prefix = "dashscope.websocket")
public class DashScopeWebSocketConfig {
    
    private String url;
    private String apiKey;
    private String workspaceId;
    
    // Getters and Setters...
    
    @Bean
    public DashScopeWebSocketClient dashScopeWebSocketClient() {
        DashScopeWebSocketClientOptions options = 
            DashScopeWebSocketClientOptions.builder()
                .withUrl(url)
                .withApiKey(apiKey)
                .withWorkSpaceId(workspaceId)
                .build();
        
        return new DashScopeWebSocketClient(options);
    }
}
```

### 3.4 环境区分配置

```java
@Configuration
public class EnvironmentBasedWebSocketConfig {
    
    @Value("${spring.profiles.active}")
    private String profile;
    
    @Value("${dashscope.api-key}")
    private String apiKey;
    
    @Bean
    public DashScopeWebSocketClientOptions webSocketOptions() {
        String url = switch (profile) {
            case "dev" -> "wss://test-dashscope.aliyuncs.com/api-ws/v1";
            case "test" -> "wss://test-dashscope.aliyuncs.com/api-ws/v1";
            case "prod" -> "wss://dashscope.aliyuncs.com/api-ws/v1";
            default -> DashScopeApiConstants.DEFAULT_WEBSOCKET_URL;
        };
        
        return DashScopeWebSocketClientOptions.builder()
            .withUrl(url)
            .withApiKey(apiKey)
            .build();
    }
}
```

## 四、最佳实践

### 4.1 配置管理

```java
@Component
public class WebSocketOptionsFactory {
    
    @Value("${dashscope.api-key}")
    private String apiKey;
    
    @Value("${dashscope.websocket.url:}")
    private String customUrl;
    
    /**
     * 创建默认配置
     */
    public DashScopeWebSocketClientOptions createDefaultOptions() {
        DashScopeWebSocketClientOptions.Builder builder = 
            DashScopeWebSocketClientOptions.builder()
                .withApiKey(apiKey);
        
        // 如果配置了自定义URL，使用自定义URL
        if (customUrl != null && !customUrl.isEmpty()) {
            builder.withUrl(customUrl);
        }
        
        return builder.build();
    }
    
    /**
     * 为特定工作空间创建配置
     */
    public DashScopeWebSocketClientOptions createOptionsForWorkspace(
            String workSpaceId) {
        
        return DashScopeWebSocketClientOptions.builder()
            .withApiKey(apiKey)
            .withWorkSpaceId(workSpaceId)
            .build();
    }
}
```

### 4.2 配置验证

```java
public class WebSocketOptionsValidator {
    
    /**
     * 验证配置有效性
     */
    public static void validate(DashScopeWebSocketClientOptions options) {
        // 验证API Key
        if (options.getApiKey() == null || options.getApiKey().isEmpty()) {
            throw new IllegalArgumentException("API Key不能为空");
        }
        
        // 验证API Key格式
        if (!options.getApiKey().startsWith("sk-")) {
            throw new IllegalArgumentException("API Key格式不正确");
        }
        
        // 验证URL
        if (options.getUrl() == null || options.getUrl().isEmpty()) {
            throw new IllegalArgumentException("WebSocket URL不能为空");
        }
        
        // 验证URL协议
        if (!options.getUrl().startsWith("wss://")) {
            throw new IllegalArgumentException("WebSocket必须使用安全连接(wss://)");
        }
    }
}

// 使用
DashScopeWebSocketClientOptions options = ...;
WebSocketOptionsValidator.validate(options);
```

## 五、注意事项

### 5.1 关键注意事项

| 注意事项 | 说明 |
|---------|------|
| **API Key安全** | 不要硬编码，使用环境变量或配置中心 |
| **URL协议** | 必须使用wss://（安全WebSocket） |
| **默认值** | url有默认值，apiKey必须提供 |
| **工作空间** | 多租户场景必须设置workSpaceId |
| **不可变性** | 配置创建后不应修改 |

### 5.2 常见问题

**Q1: API Key从哪里获取？**
```
A: 登录阿里云百炼平台 → API密钥管理 → 创建/查看API Key
```

**Q2: 可以修改已创建的配置吗？**
```
A: 理论上可以（有setter方法），但不推荐。
   建议：创建新的配置实例。
```

**Q3: 如何在多环境下管理配置？**
```yaml
# application-dev.yml
dashscope:
  websocket:

```

**Q5: workSpaceId何时需要？**
```
需要：
1. 企业多租户应用
2. 需要数据隔离
3. 需要独立计费

不需要：
1. 个人开发
2. 单一团队使用
3. 原型验证
```

**Q6: Builder模式的优势是什么？**
```java
// ✅ 链式调用，代码清晰
DashScopeWebSocketClientOptions options = 
    DashScopeWebSocketClientOptions.builder()
        .withUrl(url)
        .withApiKey(apiKey)
        .withWorkSpaceId(workspaceId)
        .build();

// ❌ 传统方式，冗长
DashScopeWebSocketClientOptions options = 
    new DashScopeWebSocketClientOptions();
options.setUrl(url);
options.setApiKey(apiKey);
options.setWorkSpaceId(workspaceId);
```
