## 一、类概述

### 1.1 设计目的

`DashScopeAudioSpeechOptions` 实现了`SpeechSynthesisOptions`接口，用于配置DashScope的语音合成(TTS)参数，包括音色、语速、音量、音调等。

### 1.2 完整定义

```java
@JsonInclude(JsonInclude.Include.NON_NULL)
public class DashScopeAudioSpeechOptions implements SpeechSynthesisOptions {
    
    private String model;                        // 模型名称
    private String text;                         // 待合成文本
    private String voice;                        // 音色(v2专用)
    private RequestTextType requestTextType;     // 文本类型
    private Integer sampleRate = 48000;          // 采样率
    private Integer volume = 50;                 // 音量
    private Float speed = 1.0F;                  // 语速
    private Double pitch = 1.0;                  // 音调
    private Boolean enableWordTimestamp = false;  // 词级时间戳
    private Boolean enablePhonemeTimestamp = false; // 音素级时间戳
    private ResponseFormat responseFormat = MP3;  // 输出格式
}
```

### 1.3 TTS工作流程

```
文本输入
    ↓
文本分析（停顿、重音）
    ↓
音素转换
    ↓
韵律预测（语速、音调）
    ↓
语音合成（添加情感）
    ↓
音频流输出（MP3/WAV/PCM）
```

## 二、字段详解

### 2.1 model（模型名称）

**类型**：`String`  
**默认值**：`null`  
**必填**：✅ 是

**可用模型**：

| 模型名称 | 语言 | 特点 | 音色数量 | 推荐场景 |
|---------|------|------|---------|---------|
| **cosyvoice-v1** | 中英文 | 高质量，接近真人 | 50+ | 客服、播报 |
| **sambert-zhichu-v1** | 中文 | 自然流畅 | 30+ | 有声阅读 |
| **sambert-zhixiaobai-v1** | 中文 | 童声，活泼 | 10+ | 儿童内容 |

**使用示例**：
```java
// 使用CosyVoice（推荐）
DashScopeAudioSpeechOptions options = DashScopeAudioSpeechOptions.builder()
    .model("cosyvoice-v1")
    .voice("zhixiaoxia")
    .build();

// 使用Sambert系列
DashScopeAudioSpeechOptions options = DashScopeAudioSpeechOptions.builder()
    .model("sambert-zhichu-v1")
    .voice("zhiyan")
    .build();
```

### 2.2 text（待合成文本）

**类型**：`String`  
**默认值**：`null`  
**必填**：✅ 是（调用时）

**说明**：
- 需要合成为语音的文本内容
- 支持纯文本和SSML格式
- 中文最大3000字符，英文最大6000字符

**使用示例**：
```java
// 纯文本
DashScopeAudioSpeechOptions options = DashScopeAudioSpeechOptions.builder()
    .model("cosyvoice-v1")
    .voice("zhixiaoxia")
    .test("你好，欢迎使用语音合成服务！")
    .build();

// SSML格式（控制停顿、重音）
String ssmlText = """
    <speak>
        <prosody rate="slow">慢速朗读</prosody>
        <break time="500ms"/>
        <prosody rate="fast">快速朗读</prosody>
    </speak>
    """;

DashScopeAudioSpeechOptions options = DashScopeAudioSpeechOptions.builder()
    .model("cosyvoice-v1")
    .voice("zhixiaoxia")
    .test(ssmlText)
    .requestText(RequestTextType.SSML)
    .build();
```

### 2.4 requestTextType（文本类型）

**类型**：`RequestTextType` 枚举  
**默认值**：`PLAIN_TEXT`  
**必填**：否

**可选值**：
- **PLAIN_TEXT**：纯文本（默认）
- **SSML**：语音合成标记语言，支持高级控制

**SSML功能**：
```xml
<!-- 语速控制 -->
<prosody rate="slow">慢速朗读</prosody>
<prosody rate="fast">快速朗读</prosody>

<!-- 停顿 -->
<break time="500ms"/>  <!-- 停顿500毫秒 -->

<!-- 音量 -->
<prosody volume="loud">大声说话</prosody>
<prosody volume="soft">小声说话</prosody>

<!-- 音调 -->
<prosody pitch="high">高音</prosody>
<prosody pitch="low">低音</prosody>

<!-- 重音 -->
<emphasis level="strong">重点强调</emphasis>
```

**使用示例**：
```java
// 纯文本
DashScopeAudioSpeechOptions options = DashScopeAudioSpeechOptions.builder()
    .model("cosyvoice-v1")
    .voice("zhixiaoxia")
    .test("简单文本")
    .requestText(RequestTextType.PLAIN_TEXT)
    .build();

// SSML（精细控制）
String ssml = """
    <speak>
        大家好，<break time="300ms"/>
        我是<emphasis level="strong">智小夏</emphasis>，
        <prosody rate="slow">很高兴</prosody>为您服务。
    </speak>
    """;

DashScopeAudioSpeechOptions options = DashScopeAudioSpeechOptions.builder()
    .model("cosyvoice-v1")
    .voice("zhixiaoxia")
    .test(ssml)
    .requestText(RequestTextType.SSML)
    .build();
```

### 2.5 sampleRate（采样率）

**类型**：`Integer`  
**默认值**：`48000` (48kHz)  
**必填**：否

**可选值**：
- **8000**: 电话音质（窄带）
- **16000**: 语音识别常用（宽带）
- **24000**: 高清音质
- **48000**: 超高清音质（默认，推荐）

**质量对比**：

| 采样率 | 音质 | 文件大小 | 适用场景 |
|--------|------|---------|---------|
| 8kHz | 一般 | 小 | 电话系统 |
| 16kHz | 良好 | 中 | 智能助手 |
| 24kHz | 高清 | 较大 | 播客、有声书 |
| 48kHz | 超清 | 大 | 专业播报 |

**使用示例**：
```java
// 默认48kHz（推荐）
DashScopeAudioSpeechOptions options = DashScopeAudioSpeechOptions.builder()
    .model("cosyvoice-v1")
    .voice("zhixiaoxia")
    .sampleRate(48000)
    .build();

// 16kHz（节省带宽）
DashScopeAudioSpeechOptions options = DashScopeAudioSpeechOptions.builder()
    .model("cosyvoice-v1")
    .voice("zhixiaoxia")
    .sampleRate(16000)
    .build();
```

### 2.7 speed（语速）

**类型**：`Float`  
**默认值**：`1.0`  
**必填**：否  
**取值范围**：0.5 - 2.0

**说明**：
- 控制语音播放速度
- 1.0为正常速度
- <1.0为慢速，>1.0为快速

**速度对照**：

| speed | 描述 | 适用场景 |
|-------|------|---------|
| 0.5 | 非常慢 | 儿童学习、外语教学 |
| 0.8 | 较慢 | 复杂内容讲解 |
| 1.0 | 正常 | 一般播报（默认） |
| 1.2 | 较快 | 快节奏内容 |
| 1.5 | 快速 | 简单信息提示 |
| 2.0 | 非常快 | 紧急提示 |

**使用示例**：
```java
// 正常速度（默认）
DashScopeAudioSpeechOptions options = DashScopeAudioSpeechOptions.builder()
    .model("cosyvoice-v1")
    .voice("zhixiaoxia")
    .speed(1.0F)
    .build();

// 慢速（教学场景）

    .model("cosyvoice-v1")

    .model("cosyvoice-v1")
```

### 4.2 性能优化

```java
public class TTSOptimizer {
    
    /**
     * 根据场景选择采样率
     */
    public int selectSampleRate(String scenario) {
        return switch (scenario) {
            case "phone" -> 8000;      // 电话
            case "assistant" -> 16000; // 助手
            case "audiobook" -> 24000; // 有声书
            case "broadcast" -> 48000; // 播报
            default -> 16000;
        };
    }
    
    /**
     * 根据网络选择格式
     */
    public ResponseFormat selectFormat(String networkType) {
        return switch (networkType) {
            case "mobile" -> ResponseFormat.MP3;  // 移动网络，压缩
            case "wifi" -> ResponseFormat.WAV;    // WiFi，高质量
            case "realtime" -> ResponseFormat.PCM; // 实时，低延迟
            default -> ResponseFormat.MP3;
        };
    }
}
```

### 4.3 文本预处理

```java
public class TextPreprocessor {
    
    /**
     * 预处理文本
     */
    public String preprocess(String text) {
        // 1. 数字转中文
        text = convertNumbersToChinese(text);
        
        // 2. 标点规范化
        text = normalizePunctuation(text);
        
        // 3. 添加停顿（长句子）
        text = addPauses(text);
        
        return text;
    }
    
    private String addPauses(String text) {
        // 在句子之间添加停顿
        return text.replaceAll("([。！？])", "$1<break time=\"300ms\"/>");
    }
}
```

```
- PCM：原始流，最大（实时处理）
```
