## 一、类概述

### 1.1 设计目的

`DashScopeVideoOptions` 实现了`VideoOptions`接口，用于配置DashScope的视频生成参数，支持文本生成视频(T2V)、图像生成视频(I2V)、关键帧生成视频等多种模式。

### 1.2 完整定义

```java
public class DashScopeVideoOptions implements VideoOptions {
    
    public static final String DEFAULT_MODEL = "wanx2.1-t2v-turbo";
    
    private String model;                 // 模型名称
    private String imageUrl;              // 输入图像URL（I2V）
    private String prompt;                // 文本描述
    private String size = "832*480";      // 视频尺寸
    private Integer duration = 5;         // 时长（秒）
    private Boolean promptExtend;         // Prompt扩展
    private String resolution;            // 分辨率
    private Long seed;                    // 随机种子
    private String negativePrompt;        // 反向提示词
    private VideoTemplate template;       // 视频模板
    private String firstFrameUrl;         // 首帧URL
    private String lastFrameUrl;          // 尾帧URL
}
```

### 1.3 视频生成模式

```
模式1: 文本生成视频 (T2V)
prompt → AI生成 → 视频

模式2: 图像生成视频 (I2V)
image + prompt → AI动画化 → 视频

模式3: 关键帧生成视频
firstFrame + lastFrame + prompt → AI插值 → 视频

模式4: 模板生成视频
template + prompt → 套用模板 → 视频
```

## 二、字段详解

### 2.1 model（模型名称）

**类型**：`String`  
**默认值**：`"wanx2.1-t2v-turbo"`  
**必填**：否（有默认值）

**可用模型**：

| 模型名称 | 类型 | 特点 | 推荐场景 |
|---------|------|------|---------|
| **wanx2.1-t2v-turbo** | T2V | 快速生成 | 通用场景（默认） |
| **wanx2.1-t2v** | T2V | 高质量 | 精细视频 |
| **wanx2.1-i2v** | I2V | 图像动画化 | 图片转视频 |
| **wanx-i2v-v1** | I2V | 稳定版 | 产品演示 |

**使用示例**：
```java
// 默认模型（T2V快速）
DashScopeVideoOptions options = DashScopeVideoOptions.builder()
    .model("wanx2.1-t2v-turbo")
    .build();

// 高质量T2V
DashScopeVideoOptions options = DashScopeVideoOptions.builder()
    .model("wanx2.1-t2v")
    .build();

// 图像转视频
DashScopeVideoOptions options = DashScopeVideoOptions.builder()
    .model("wanx2.1-i2v")
    .build();
```

### 2.2 prompt（文本描述）

**类型**：`String`  
**默认值**：`null`  
**必填**：✅ 是

**说明**：
- 描述想要生成的视频内容
- 越详细越好（动作、场景、风格）
- 支持中英文

**优质Prompt结构**：
```
[主体] + [动作] + [场景] + [风格] + [镜头]

示例：
"一只橘猫在花园里追逐蝴蝶，阳光明媚，写实风格，广角镜头"
```

**使用示例**：
```java
// 简单描述
DashScopeVideoOptions options = DashScopeVideoOptions.builder()
    .prompt("海浪拍打沙滩")
    .build();

// 详细描述（推荐）
DashScopeVideoOptions options = DashScopeVideoOptions.builder()
    .prompt("一位穿着白色连衣裙的女孩在海边奔跑，" +
            "夕阳西下，金色的光芒洒在海面上，" +
            "电影感，慢镜头，广角镜头")
    .build();

// 英文描述
DashScopeVideoOptions options = DashScopeVideoOptions.builder()
    .prompt("A futuristic city with flying cars, " +
            "cyberpunk style, neon lights, rainy night, " +
            "cinematic, 4K quality")
    .build();
```

**Prompt技巧**：
```
✅ 好的Prompt：
- 具体描述：一只金毛犬在草地上奔跑
- 包含细节：阳光明媚，草地翠绿
- 指定风格：写实风格，电影感
- 镜头描述：慢镜头，广角

❌ 不好的Prompt：
- 模糊描述：一只狗
- 缺少细节：在跑
- 无风格：普通
```

### 2.6 seed（随机种子）

**类型**：`Long`  
**默认值**：`null`（随机）  
**必填**：否  
**取值范围**：0 - 2147483647

**说明**：
- 控制视频生成的随机性
- 相同seed + 相同参数 = 相似结果
- 用于复现或批量生成风格一致的视频

**使用场景**：
- 复现特定效果
- 批量生成系列视频
- A/B测试不同prompt

**使用示例**：
```java
// 随机生成
DashScopeVideoOptions options = DashScopeVideoOptions.builder()
    .prompt("海浪拍打沙滩")
    // 不设置seed，每次生成不同
    .build();

// 固定种子（可复现）
DashScopeVideoOptions options = DashScopeVideoOptions.builder()
    .prompt("海浪拍打沙滩")
    .seed(12345L)  // 固定seed
    .build();

// 批量生成（风格一致）
for (int i = 0; i < 5; i++) {
    DashScopeVideoOptions options = DashScopeVideoOptions.builder()
        .prompt("第" + (i + 1) + "个场景")
        .seed(1000L + i)  // 连续seed
        .build();
}
```

### 2.7 negativePrompt（反向提示词）

**类型**：`String`  
**默认值**：`null`  
**必填**：否

**说明**：
- 描述不想在视频中出现的内容
- 用于限制和控制生成结果
- 提高视频质量

**常用反向提示词**：
```
质量相关：
- 模糊、低分辨率、噪点
- 变形、扭曲、失真

内容相关：
- 文字、水印、logo
- 多余的手、脚
- 人物面部变形

风格相关：
- 卡通风格（如果要写实）
- 3D渲染（如果要真实）
```

**使用示例**：
```java
// 基础过滤
DashScopeVideoOptions options = DashScopeVideoOptions.builder()
    .prompt("一位美丽的女孩在花园中")
    .negativePrompt("模糊,低质量,变形,噪点")
    .build();

// 详细过滤
DashScopeVideoOptions options = DashScopeVideoOptions.builder()
    .prompt("一辆豪华跑车在公路上行驶")
    .negativePrompt("模糊,低分辨率,变形,扭曲," +
                   "文字,水印,卡通风格")
    .build();

// 写实风格强化
DashScopeVideoOptions options = DashScopeVideoOptions.builder()
    .prompt("城市街道夜景")
    .negativePrompt("卡通,3D渲染,动漫风格," +
                   "过度饱和,失真")
    .build();
```

### 2.8 promptExtend（Prompt扩展）

**类型**：`Boolean`  
**默认值**：`false`  
**必填**：否

**说明**：
- 启用后AI会自动扩展和丰富prompt
- 添加更多细节和描述
- 提高生成质量

**对比示例**：
```
原始Prompt：
"一只猫在睡觉"

promptExtend = false:
生成: 基于简单描述的视频

promptExtend = true:
AI扩展为: "一只橘色的猫蜷缩在温暖的阳光下，
在柔软的垫子上安详地睡觉，
偶尔耳朵微微抖动，
画面温馨宁静"
生成: 更丰富细腻的视频
```

**使用示例**：
```java
// 不扩展（精确控制）
DashScopeVideoOptions options = DashScopeVideoOptions.builder()
    .prompt("一只猫在睡觉")
    .promptExtend(false)
    .build();

// 自动扩展（推荐）
DashScopeVideoOptions options = DashScopeVideoOptions.builder()
    .prompt("一只猫在睡觉")
    .promptExtend(true)
    .build();
```

### 3.5 批量生成（系列视频）

```java
public class BatchVideoGenerator {
    
    /**
     * 生成系列视频
     */
    public List<String> generateSeries(List<String> prompts) {
        List<String> videoUrls = new ArrayList<>();
        long baseSeed = 1000L;
        
        for (int i = 0; i < prompts.size(); i++) {
            DashScopeVideoOptions options = DashScopeVideoOptions.builder()
                .prompt(prompts.get(i))
                .seed(baseSeed + i)  // 连续seed，风格一致
                .size("832*480")
                .promptExtend(true)
                .build();
            
            VideoResponse response = videoModel.call(
                new VideoPrompt(prompts.get(i), options)
            );
            
            videoUrls.add(response.getResult().getOutput().getUrl());
        }
        
        return videoUrls;
    }
}

// 使用
List<String> prompts = List.of(
    "第一章：日出东方",
    "第二章：正午骄阳",
    "第三章：夕阳西下",
    "第四章：星空璀璨"
);

List<String> videos = generator.generateSeries(prompts);
```

### 4.3 视频质量检查

```java
public class VideoQualityChecker {
    
    /**
     * 检查生成结果
     */
    public boolean checkQuality(VideoResponse response) {
        String videoUrl = response.getResult().getOutput().getUrl();
        
        if (videoUrl == null || videoUrl.isEmpty()) {
            return false;
        }
        
        // 检查视频是否可访问
        try {
            HttpURLConnection connection = 
                (HttpURLConnection) new URL(videoUrl).openConnection();
            connection.setRequestMethod("HEAD");
            int responseCode = connection.getResponseCode();
            return responseCode == 200;
        } catch (Exception e) {
            return false;
        }
    }
}
```

## 五、注意事项

### 5.1 关键注意事项

| 注意事项 | 说明 |
|---------|------|
| **时长限制** | 目前固定5秒 |
| **异步生成** | 视频生成需要轮询任务状态 |
| **URL有效期** | 生成的视频URL有24小时有效期 |
| **并发限制** | 建议不超过5个并发任务 |
| **尺寸限制** | 必须使用支持的尺寸 |
| **Prompt长度** | 建议500字符以内 |
