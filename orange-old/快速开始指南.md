## 进阶应用

### 1. Graph 工作流应用

#### 场景: 客户服务系统

```java
@Configuration
public class CustomerServiceWorkflowConfig {
    
    @Bean
    public StateGraph customerServiceGraph(ChatClient chatClient) {
        // 1. 定义状态工厂
        OverAllStateFactory stateFactory = () -> {
            OverAllState state = new OverAllState();
            state.registerKeyAndStrategy("input", new ReplaceStrategy());
            state.registerKeyAndStrategy("category", new ReplaceStrategy());
            state.registerKeyAndStrategy("solution", new ReplaceStrategy());
            return state;
        };
        
        // 2. 定义节点
        // 分类节点
        QuestionClassifierNode classifierNode = QuestionClassifierNode.builder()
            .chatClient(chatClient)
            .inputTextKey("input")
            .categories(List.of("技术支持", "账户问题", "产品咨询", "投诉建议"))
            .classificationInstructions(List.of(
                "根据客户问题的内容进行分类",
                "技术支持：关于产品使用、故障、配置等",
                "账户问题：登录、密码、权限等",
                "产品咨询：功能、价格、购买等",
                "投诉建议：不满意、建议改进等"
            ))
            .build();
        
        // 技术支持处理节点
        NodeAction techSupportNode = state -> {
            String input = state.get("input");
            String solution = chatClient.prompt()
                .user("作为技术支持，请回答：" + input)
                .call()
                .content();
            state.put("solution", solution);
            return NodeOutput.of(state);
        };
        
        // 账户问题处理节点
        NodeAction accountNode = state -> {
            String input = state.get("input");
            String solution = chatClient.prompt()
                .user("作为账户管理专员，请回答：" + input)
                .call()
                .content();
            state.put("solution", solution);
            return NodeOutput.of(state);
        };
        
        // 产品咨询节点
        NodeAction productNode = state -> {
            String input = state.get("input");
            String solution = chatClient.prompt()
                .user("作为产品顾问，请回答：" + input)
                .call()
                .content();
            state.put("solution", solution);
            return NodeOutput.of(state);
        };
        
        // 投诉建议节点
        NodeAction complaintNode = state -> {
            String input = state.get("input");
            String solution = chatClient.prompt()
                .user("作为客户关系经理，请专业回复：" + input)
                .call()
                .content();
            state.put("solution", solution);
            state.put("escalate", "true"); // 标记需要升级
            return NodeOutput.of(state);
        };
        
        // 3. 定义边的路由逻辑
        EdgeAction routingEdge = state -> {
            String category = state.get("category");
            if (category.contains("技术支持")) return "tech-support";
            if (category.contains("账户问题")) return "account";
            if (category.contains("产品咨询")) return "product";
            if (category.contains("投诉建议")) return "complaint";
            return "default";
        };
        
        // 4. 构建图
        return new StateGraph("customer-service", stateFactory)
            .addNode("classifier", node_async(classifierNode))
            .addNode("tech-support", node_async(techSupportNode))
            .addNode("account", node_async(accountNode))
            .addNode("product", node_async(productNode))
            .addNode("complaint", node_async(complaintNode))
            
            .addEdge(START, "classifier")
            .addConditionalEdges("classifier", edge_async(routingEdge),
                Map.of(
                    "tech-support", "tech-support",
                    "account", "account",
                    "product", "product",
                    "complaint", "complaint"
                ))
            .addEdge("tech-support", END)
            .addEdge("account", END)
            .addEdge("product", END)
            .addEdge("complaint", END);
    }
}
```

#### 使用工作流
```java
@RestController
public class CustomerServiceController {
    
    private final CompiledGraph compiledGraph;
    
    public CustomerServiceController(StateGraph customerServiceGraph) 
            throws GraphStateException {
        this.compiledGraph = customerServiceGraph.compile();
    }
    
    @PostMapping("/customer-service")
    public Map<String, Object> handleCustomerQuery(
            @RequestBody String query) throws GraphRunnerException {
        
        Map<String, Object> input = Map.of("input", query);
        Optional<OverAllState> result = compiledGraph.invoke(input);
        
        if (result.isPresent()) {
            OverAllState state = result.get();
            return Map.of(
                "category", state.get("category"),
                "solution", state.get("solution"),
                "needsEscalation", state.getOrDefault("escalate", "false")
            );
        }
        
        return Map.of("error", "处理失败");
    }
}
```

## 常见问题

### 1. 依赖冲突

**问题**: `spring-ai` 相关依赖下载失败

**解决**:
```xml
<repositories>
  <repository>
    <id>spring-milestones</id>
    <url>https://repo.spring.io/milestone</url>
  </repository>
</repositories>

<!-- 或者在 settings.xml 的 mirror 中排除 -->
<mirror>
  <id>aliyun</id>
  <mirrorOf>*,!spring-milestones</mirrorOf>
  <url>https://maven.aliyun.com/repository/public</url>
</mirror>
```

### 2. API 调用超时

**问题**: 模型调用经常超时

**解决**:
```yaml
spring:
  ai:
    alibaba:
      dashscope:
        chat:
          options:
            timeout: 120s  # 增加超时时间
            max-retries: 3  # 重试次数
```

### 3. 流式响应问题

**问题**: 流式响应不工作

**检查**:
1. 使用 `Flux<String>` 返回类型
2. 使用 `@GetMapping(produces = MediaType.TEXT_EVENT_STREAM_VALUE)`
3. 不要在流式方法中使用 `@ResponseBody`

```java
@GetMapping(value = "/stream", 
    produces = MediaType.TEXT_EVENT_STREAM_VALUE)
public Flux<String> stream(@RequestParam String message) {
    return chatClient.prompt()
        .user(message)
        .stream()
        .content();
}
```

### 4. 内存泄漏

**问题**: 长时间运行后内存不断增长

**解决**:
```yaml
spring:
  ai:
    alibaba:
      chat:
        memory:
          max-messages: 100  # 限制历史消息数量
          ttl: 3600  # 消息过期时间(秒)
```

### 5. Graph 执行失败

**问题**: `GraphStateException` 或节点执行异常

**排查步骤**:
1. 检查图结构是否有循环
2. 确保所有条件边都有对应的节点
3. 验证状态键是否正确注册

```java
// 启用 Graph 调试日志
logging:
  level:
    com.alibaba.cloud.ai.graph: DEBUG
```

### 6. Token 限制

**问题**: `Token limit exceeded`

**解决**:
```java
// 1. 截断过长的输入
String truncatedInput = input.substring(0, 
    Math.min(input.length(), 4000));

// 2. 使用更大 context 的模型
chatClient.prompt()
    .options(ChatOptions.builder()
        .withModel("qwen-long")  // 支持更长上下文
        .build())
    .user(input)
    .call()
    .content();

// 3. 实现自动摘要
if (conversationHistory.size() > 10) {
    String summary = chatClient.prompt()
        .user("总结以下对话: " + conversationHistory)
        .call()
        .content();
    // 用摘要替换旧消息
}
```

## 性能优化建议

### 1. 使用响应式编程

```java
// 不推荐：阻塞式
public String chat(String message) {
    return chatClient.prompt()
        .user(message)
        .call()
        .content();
}

// 推荐：响应式
public Mono<String> chat(String message) {
    return Mono.fromSupplier(() -> 
        chatClient.prompt()
            .user(message)
            .call()
            .content()
    ).subscribeOn(Schedulers.boundedElastic());
}
```

    }
}

@Service
public class CachedEmbeddingService {
    
    @Cacheable("embeddings")
    public List<Double> getEmbedding(String text) {
        return embeddingModel.embed(text);
    }
}

## 最佳实践总结

1. **安全性**
   - 永远不要在代码中硬编码 API Key
   - 使用环境变量或密钥管理服务
   - 实现请求限流和访问控制

2. **可靠性**
   - 实现重试机制
   - 添加超时控制
   - 使用熔断器模式

3. **性能**
   - 优先使用流式 API
   - 合理使用缓存
   - 异步处理长任务

4. **可维护性**
   - 使用 Prompt 模板
   - 良好的日志记录
   - 完整的监控和告警

5. **成本控制**
   - 监控 Token 使用量
   - 实现请求配额
   - 缓存常见查询
