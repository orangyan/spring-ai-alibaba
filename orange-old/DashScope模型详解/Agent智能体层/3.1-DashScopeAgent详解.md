## 一、类概述

### 1.1 设计目的

`DashScopeAgent` 是Spring AI `Agent` 接口的DashScope实现，提供了与阿里云百炼Agent应用的高级封装。它继承自 `Agent` 基类，实现了同步和流式的对话能力，并集成了会话管理、RAG、多模态等高级功能。

### 1.2 核心职责

```
┌──────────────────────────────────┐
│  Application Code                │
│  (业务应用层)                     │
└──────────────┬───────────────────┘
               │
               ↓
┌──────────────────────────────────┐
│  DashScopeAgent (本类)           │ ← 本文档介绍的核心
│  - Spring AI Agent接口实现       │
│  - 选项合并与管理                │
│  - 请求/响应转换                 │
│  - 同步/流式调用                 │
└──────────────┬───────────────────┘
               │
               ↓
┌──────────────────────────────────┐
│  DashScopeAgentApi               │
│  (底层API客户端)                 │
└──────────────┬───────────────────┘
               │
               ↓
┌──────────────────────────────────┐
│  DashScope Agent Service         │
│  (百炼Agent应用服务)             │
└──────────────────────────────────┘
```

### 1.3 核心特性

| 特性 | 说明 |
|------|------|
| **Agent接口** | 实现Spring AI Agent规范 |
| **选项合并** | 实例选项 + 运行时选项智能合并 |
| **同步/流式** | 支持两种调用模式 |
| **会话管理** | sessionId实现多轮对话 |
| **记忆机制** | memoryId实现长期记忆 |
| **RAG集成** | 知识库检索增强 |
| **多模态** | 支持图文混合输入 |
| **思维链** | 可观察Agent推理过程 |

```java
Agent (Spring AI接口)
  ↑
  └── DashScopeAgent (实现类)
```

## 三、核心功能

### 3.1 同步调用

**方法签名**：
```java
@Override
public ChatResponse call(Prompt prompt)
```

**功能**：同步调用Agent应用，等待完整响应

**实现流程**：
```
1. toRequest(prompt, false)
   - 合并选项（实例选项 + Prompt选项）
   - 转换为DashScopeAgentRequest
   
2. dashScopeAgentApi.call(request)
   - 调用底层API
   - 获取完整响应
   
3. toChatResponse(response)
   - 转换为Spring AI ChatResponse
   - 包装为Generation
```

**源码解析**：
```java
@Override
public ChatResponse call(Prompt prompt) {
    // 1. 转换请求（不启用流式）
    DashScopeAgentRequest request = toRequest(prompt, false);
    
    // 2. 调用API
    ResponseEntity<DashScopeAgentResponse> response = 
        this.dashScopeAgentApi.call(request);
    
    // 3. 检查响应
    if (response == null || response.getBody() == null) {
        logger.warn("app call error: request: {}", request);
        return null;
    }
    
    // 4. 转换响应
    return toChatResponse(response.getBody());
}
```

---

### 3.2 流式调用

**方法签名**：
```java
@Override
public Flux<ChatResponse> stream(Prompt prompt)
```

**功能**：流式调用Agent应用，实时接收响应

**实现流程**：
```
1. toRequest(prompt, true)
   - 合并选项（启用流式标志）
   - 转换为DashScopeAgentRequest
   
2. dashScopeAgentApi.stream(request)
   - 调用底层API
   - 获取响应流
   
3. flatMap(toChatResponse)
   - 将每个响应片段转换为ChatResponse
   - 并行发布到Flux
```

**源码解析**：
```java
@Override
public Flux<ChatResponse> stream(Prompt prompt) {
    // 1. 转换请求（启用流式）
    DashScopeAgentRequest request = toRequest(prompt, true);
    
    // 2. 调用API获取流
    Flux<DashScopeAgentResponse> response = 
        this.dashScopeAgentApi.stream(request);
    
    // 3. 转换每个响应片段
    return Flux.from(response)
        .flatMap(result -> Flux.just(toChatResponse(result)))
        .publishOn(Schedulers.parallel());  // 并行调度
}
```

### 3.3 请求转换

**方法**：`toRequest(Prompt prompt, Boolean stream)`

**功能**：将Spring AI Prompt转换为DashScope请求

**实现逻辑**：
```java
private DashScopeAgentRequest toRequest(Prompt prompt, Boolean stream) {
    // 1. 验证参数
    if (prompt == null) {
        throw new IllegalArgumentException("option is null");
    }
    
    // 2. 合并选项
    DashScopeAgentOptions runtimeOptions = mergeOptions(prompt.getOptions());
    String appId = runtimeOptions.getAppId();
    
    if (appId == null || appId.isEmpty()) {
        throw new IllegalArgumentException("appId must be set");
    }
    
    // 3. 转换消息格式
    List<Message> messages = prompt.getInstructions();
    boolean onlyOneUserMessage = 
        messages.size() == 1 && 
        messages.get(0).getMessageType() == MessageType.USER;
    
    String requestPrompt = null;
    List<DashScopeAgentRequestMessage> requestMessages = List.of();
    
    if (onlyOneUserMessage) {
        // 单条用户消息 → 使用prompt字段
        requestPrompt = messages.get(0).getText();
    } else {
        // 多条消息 → 使用messages列表
        requestMessages = messages.stream()
            .map(msg -> new DashScopeAgentRequestMessage(
                msg.getMessageType().getValue(), 
                msg.getText()
            ))
            .toList();
    }
    
    // 4. 构建RAG选项
    DashScopeAgentRagOptions ragOptions = runtimeOptions.getRagOptions();
    
    // 5. 创建请求
    return new DashScopeAgentRequest(
        appId,
        new DashScopeAgentRequest.DashScopeAgentRequestInput(
            requestPrompt,
            requestMessages,
            runtimeOptions.getSessionId(),
            runtimeOptions.getMemoryId(),
            runtimeOptions.getImages(),
            runtimeOptions.getBizParams()
        ),
        new DashScopeAgentRequest.DashScopeAgentRequestParameters(
            runtimeOptions.getFlowStreamMode(),
            runtimeOptions.getHasThoughts(),
            stream && runtimeOptions.getIncrementalOutput(),
            ragOptions == null ? null : new DashScopeAgentRequestRagOptions(...)
        )
    );
}
```

**关键点**：
- 单条用户消息使用`prompt`字段
- 多条消息使用`messages`列表
- 流式调用时才启用增量输出

### 3.4 响应转换

**方法**：`toChatResponse(DashScopeAgentResponse response)`

**功能**：将DashScope响应转换为Spring AI ChatResponse

**实现逻辑**：
```java
private ChatResponse toChatResponse(DashScopeAgentResponse response) {
    DashScopeAgentResponse.DashScopeAgentResponseOutput output = 
        response.output();
    DashScopeAgentResponse.DashScopeAgentResponseUsage usage = 
        response.usage();
    
    if (output == null) {
        throw new RuntimeException("output is null");
    }
    
    // 1. 获取文本（确保非null）
    String text = output.text();
    if (text == null) {
        text = "";
    }
    
    // 2. 构建元数据
    Map<String, Object> metadata = new HashMap<>();
    metadata.put(DashScopeApiConstants.REQUEST_ID, response.requestId());
    metadata.put(DashScopeApiConstants.USAGE, usage);
    metadata.put(DashScopeApiConstants.OUTPUT, output);
    
    // 3. 创建AssistantMessage
    var assistantMessage = new AssistantMessage(text, metadata);
    
    // 4. 创建GenerationMetadata
    var generationMetadata = ChatGenerationMetadata.builder()
        .finishReason(output.finishReason())
        .build();
    
    // 5. 创建Generation
    Generation generation = new Generation(
        assistantMessage, 
        generationMetadata
    );
    
    // 6. 创建ChatResponse
    return new ChatResponse(List.of(generation));
}
```

**元数据包含**：
- `request_id`: 请求ID
- `usage`: Token使用统计
- `output`: 完整输出（包含thoughts、docReferences等）

### 3.5 选项合并

**方法**：`mergeOptions(ChatOptions chatOptions)`

**功能**：合并实例选项和运行时选项

**合并策略**：
```
运行时选项（Prompt中的） > 实例选项（构造时的）
```

**实现逻辑**：
```java
private DashScopeAgentOptions mergeOptions(ChatOptions chatOptions) {
    // 1. 将ChatOptions转换为DashScopeAgentOptions
    DashScopeAgentOptions agentOptions = 
        ModelOptionsUtils.copyToTarget(
            chatOptions, 
            ChatOptions.class,
            DashScopeAgentOptions.class
        );
    
    // 2. 合并选项（运行时优先）
    return ModelOptionsUtils.merge(
        agentOptions,       // 运行时选项
        this.options,       // 实例选项
        DashScopeAgentOptions.class
    );
}
```

### 4.2 字段详解

#### 4.2.1 appId（必填）

**说明**：Agent应用的唯一标识

**获取方式**：
1. 登录阿里云百炼平台
2. 创建Agent应用
3. 获取应用ID

**示例**：
```java
.withAppId("app-12345678")
```

---

#### 4.2.2 sessionId（可选）

**说明**：会话ID，用于实现多轮对话

**特点**：
- 同一个sessionId的多轮对话共享上下文
- 服务端自动管理会话历史
- 有时效性（通常24小时）

**使用场景**：
```java
// 第一轮对话
Prompt prompt1 = new Prompt("我叫张三");
ChatResponse response1 = agent.call(prompt1);

// 从响应中获取sessionId
String sessionId = (String) response1.getResult()
    .getOutput()
    .getMetadata()
    .get("session_id");

// 第二轮对话（使用相同sessionId）
DashScopeAgentOptions options2 = DashScopeAgentOptions.builder()
    .withAppId("your-app-id")
    .withSessionId(sessionId)
    .build();

Prompt prompt2 = new Prompt(
    new UserMessage("我叫什么名字？"),
    options2
);
ChatResponse response2 = agent.call(prompt2);
// 输出: 你叫张三
```

---

#### 4.2.3 memoryId（可选）

**说明**：记忆ID，用于实现长期记忆

**与sessionId的区别**：
- `sessionId`: 短期会话，关注当前对话
- `memoryId`: 长期记忆，跨会话持久化

**使用场景**：
```java
// 用户的个人助手，记住用户偏好
DashScopeAgentOptions options = DashScopeAgentOptions.builder()
    .withAppId("personal-assistant-app")
    .withMemoryId("user-123-memory")  // 用户专属记忆
    .build();
```

---

#### 4.2.4 incrementalOutput（可选）

**说明**：是否启用增量输出（仅流式有效）

**默认值**：`false`

**特点**：
- `true`: 增量输出（每次返回新增部分）
- `false`: 全量输出（每次返回全部内容）

**示例**：
```java
// 流式调用启用增量输出
DashScopeAgentOptions options = DashScopeAgentOptions.builder()
    .withAppId("your-app-id")
    .withIncrementalOutput(true)  // 增量输出
    .build();

Prompt prompt = new Prompt(new UserMessage("讲一个故事"), options);

agent.stream(prompt).subscribe(response -> {
    // 只输出新增的文本
    System.out.print(response.getResult().getOutput().getText());
});
```

---

#### 4.2.5 hasThoughts（可选）

**说明**：是否返回思维链（推理过程）

**默认值**：`false`

**使用场景**：

**示例**：

## 六、最佳实践

### 6.1 会话管理封装

```java
public class AgentSessionManager {
    
    private final DashScopeAgent agent;
    private String currentSessionId;
    
    public AgentSessionManager(DashScopeAgent agent) {
        this.agent = agent;
    }
    
    /**
     * 发送消息（自动管理sessionId）
     */
    public String chat(String message) {
        DashScopeAgentOptions options = DashScopeAgentOptions.builder()
            .withAppId("your-app-id")
            .withSessionId(currentSessionId)
            .build();
        
        Prompt prompt = new Prompt(new UserMessage(message), options);
        ChatResponse response = agent.call(prompt);
        
        // 更新sessionId
        Map<String, Object> metadata = response.getResult()
            .getOutput()
            .getMetadata();
        this.currentSessionId = (String) metadata.get("session_id");
        
        return response.getResult().getOutput().getText();
    }
    
    /**
     * 重置会话
     */
    public void resetSession() {
        this.currentSessionId = null;
    }
}
```

### 6.2 流式响应累积器

```java
public class StreamingResponseCollector {
    
    /**
     * 累积流式响应
     */
    public CompletableFuture<String> collect(
            DashScopeAgent agent,
            Prompt prompt) {
        
        CompletableFuture<String> future = new CompletableFuture<>();
        StringBuilder accumulated = new StringBuilder();
        
        agent.stream(prompt).subscribe(
            response -> {
                String text = response.getResult().getOutput().getText();
                accumulated.append(text);
                System.out.print(text);  // 实时显示
            },
            error -> future.completeExceptionally(error),
            () -> future.complete(accumulated.toString())
        );
        
        return future;
    }
}
```

```java
public class AgentPresets {
    
    /**
     * 调试模式（启用思维链）
     */
    public static DashScopeAgentOptions debugMode(String appId) {
        return DashScopeAgentOptions.builder()
            .withAppId(appId)
            .withHasThoughts(true)
            .withIncrementalOutput(false)
            .build();
    }
    
    /**
     * 流式模式
     */
    public static DashScopeAgentOptions streamingMode(String appId) {
        return DashScopeAgentOptions.builder()
            .withAppId(appId)
            .withIncrementalOutput(true)
            .withHasThoughts(false)
            .build();
    }
    
    /**
     * RAG模式
     */
    public static DashScopeAgentOptions ragMode(
            String appId,
            List<String> pipelineIds) {
        
        DashScopeAgentRagOptions ragOptions = 
            DashScopeAgentRagOptions.builder()
                .withPipelineIds(pipelineIds)
                .build();
        
        return DashScopeAgentOptions.builder()
            .withAppId(appId)
            .withRagOptions(ragOptions)
            .build();
    }
}

// 使用
DashScopeAgentOptions options = AgentPresets.debugMode("your-app-id");
```

## 七、注意事项

### 7.1 关键注意事项

| 注意事项 | 说明 |
|---------|------|
| **appId必填** | 每个请求必须提供Agent应用ID |
| **选项合并** | 运行时选项优先于实例选项 |
| **sessionId管理** | 需要手动保存和传递sessionId |
| **增量输出** | 仅在流式调用时生效 |
| **思维链开销** | 启用思维链会增加响应时间和Token消耗 |
| **元数据获取** | 从ChatResponse.metadata中获取详细信息 |

### 7.2 常见问题

**Q1: 如何获取sessionId？**
```java
ChatResponse response = agent.call(prompt);
String sessionId = (String) response.getResult()
    .getOutput()
    .getMetadata()
    .get("session_id");
```

**Q2: 如何获取thoughts？**
```java
Map<String, Object> metadata = response.getResult()
    .getOutput()
    .getMetadata();
DashScopeAgentResponse.DashScopeAgentResponseOutput output = 
    (DashScopeAgentResponse.DashScopeAgentResponseOutput) 
    metadata.get("output");

List<Thoughts> thoughts = output.thoughts();
```

**Q3: 单条消息和多条消息有什么区别？**
```
单条用户消息 → 使用prompt字段
多条消息 → 使用messages列表

建议多轮对话使用messages格式
```

**Q4: 如何实现会话持久化？**
```
1. 保存sessionId到数据库
2. 每次请求时从数据库读取
3. 设置到DashScopeAgentOptions中
```

**Q5: 选项合并规则是什么？**
```
运行时选项（Prompt中的） > 实例选项（构造时的）

非null的运行时选项会覆盖实例选项
```
