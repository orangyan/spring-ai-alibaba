## 一、类概述

### 1.1 设计目的

`DashScopeAgentRagOptions` 用于配置Agent应用的RAG（Retrieval-Augmented Generation）功能，控制知识库检索的各种参数，包括知识库ID、文件过滤、标签过滤、元数据过滤等。

### 1.2 完整定义

```java
package com.alibaba.cloud.ai.dashscope.agent;

import com.fasterxml.jackson.annotation.JsonProperty;
import com.fasterxml.jackson.databind.JsonNode;
import java.util.List;

public class DashScopeAgentRagOptions {
    
    /** 知识库Pipeline IDs */
    @JsonProperty("pipeline_ids")
    private List<String> pipelineIds;
    
    /** 知识库文件IDs */
    @JsonProperty("file_ids")
    private List<String> fileIds;
    
    /** 知识库标签 */
    @JsonProperty("tags")
    private List<String> tags;
    
    /** 元数据过滤条件 */
    @JsonProperty("metadata_filter")
    private JsonNode metadataFilter;
    
    /** 结构化过滤条件 */
    @JsonProperty("structured_filter")
    private JsonNode structuredFilter;
    
    /** 会话级文件IDs */
    @JsonProperty("session_file_ids")
    private List<String> sessionFileIds;
    
    // Getters and Setters...
    
    public static Builder builder() {
        return new Builder();
    }
}
```

### 1.3 RAG工作流程

```
用户问题
    ↓
1. 检索（Retrieval）
   - 根据RAG配置查询知识库
   - 应用过滤条件（Pipeline/File/Tag）
   - 使用元数据/结构化过滤
    ↓
2. 相关文档
   - 返回Top-K相关文档片段
   - 包含文本、图像、页码等
    ↓
3. 增强（Augmentation）
   - 将文档片段添加到上下文
   - Agent基于上下文生成回答
    ↓
4. 生成（Generation）
   - 生成最终回复
   - 附带文档引用信息
```

## 二、字段详解

### 2.1 pipelineIds（知识库Pipeline IDs）

**类型**：`List<String>`  
**必填**：否  
**默认值**：`null`

**说明**：
- 指定要检索的知识库Pipeline ID列表
- Pipeline是百炼平台上配置的检索管道
- 可以指定多个Pipeline，实现多知识库联合检索

**使用场景**：
```java
// 单个Pipeline
DashScopeAgentRagOptions options = DashScopeAgentRagOptions.builder()
    .withPipelineIds(List.of("pipeline-123"))
    .build();

// 多个Pipeline（多知识库联合检索）
DashScopeAgentRagOptions options = DashScopeAgentRagOptions.builder()
    .withPipelineIds(List.of(
        "tech-docs-pipeline",
        "faq-pipeline",
        "manual-pipeline"
    ))
    .build();
```

**注意**：
- Pipeline ID需要在百炼平台预先配置
- 不同Pipeline可能对应不同的向量数据库
- 多Pipeline检索会增加延迟

---

### 2.2 fileIds（文件IDs）

**类型**：`List<String>`  
**必填**：否  
**默认值**：`null`

**说明**：
- 指定要检索的特定文件ID列表
- 限制检索范围到指定文件
- 文件需要预先上传到知识库

**使用场景**：
```java
// 只在特定文件中检索
DashScopeAgentRagOptions options = DashScopeAgentRagOptions.builder()
    .withPipelineIds(List.of("pipeline-123"))
    .withFileIds(List.of(
        "file-001",  // Spring AI文档
        "file-002"   // Spring Boot文档
    ))
    .build();
```

**使用建议**：
- 适用于已知相关文档的场景
- 可以提高检索精度
- 减少检索范围，提升性能

---

### 2.3 tags（标签）

**类型**：`List<String>`  
**必填**：否  
**默认值**：`null`

**说明**：
- 基于标签过滤文档
- 标签在文档上传时设置
- 支持多标签过滤（AND逻辑）

**使用场景**：
```java
// 按标签过滤
DashScopeAgentRagOptions options = DashScopeAgentRagOptions.builder()
    .withPipelineIds(List.of("pipeline-123"))
    .withTags(List.of(
        "技术文档",
        "Spring AI",
        "2024"
    ))
    .build();
```

**标签策略**：
```
文档分类标签：
├── 技术文档
│   ├── API参考
│   ├── 开发指南
│   └── 最佳实践
├── 业务文档
│   ├── 产品说明
│   └── 用户手册
└── 时间标签
    ├── 2024
    └── 最新版
```

### 2.4 metadataFilter（元数据过滤）

**类型**：`JsonNode`  
**必填**：否  
**默认值**：`null`

**说明**：
- 基于文档元数据进行高级过滤
- 支持复杂的查询条件
- 使用JSON格式定义过滤规则

**过滤语法**：
```json
{
  "and": [
    {
      "field": "category",
      "operator": "eq",
      "value": "技术文档"
    },
    {
      "field": "version",
      "operator": "gte",
      "value": "2.0"
    },
    {
      "or": [
        {
          "field": "author",
          "operator": "eq",
          "value": "张三"
        },
        {
          "field": "author",
          "operator": "eq",
          "value": "李四"
        }
      ]
    }
  ]
}
```

**支持的操作符**：
- `eq`: 等于
- `ne`: 不等于
- `gt`: 大于
- `gte`: 大于等于
- `lt`: 小于
- `lte`: 小于等于
- `in`: 在列表中
- `nin`: 不在列表中

**使用示例**：
```java
import com.fasterxml.jackson.databind.ObjectMapper;
import com.fasterxml.jackson.databind.node.ObjectNode;

ObjectMapper mapper = new ObjectMapper();

// 简单过滤
ObjectNode filter = mapper.createObjectNode();
filter.put("field", "category");
filter.put("operator", "eq");
filter.put("value", "API文档");

DashScopeAgentRagOptions options = DashScopeAgentRagOptions.builder()
    .withPipelineIds(List.of("pipeline-123"))
    .withMetadataFilter(filter)
    .build();

// 复杂过滤（AND + OR）
String filterJson = """
    {
      "and": [
        {"field": "type", "operator": "eq", "value": "tutorial"},
        {"field": "level", "operator": "in", "value": ["beginner", "intermediate"]}
      ]
    }
    """;

JsonNode complexFilter = mapper.readTree(filterJson);

DashScopeAgentRagOptions options2 = DashScopeAgentRagOptions.builder()
    .withPipelineIds(List.of("pipeline-123"))
    .withMetadataFilter(complexFilter)
    .build();
```

### 2.5 structuredFilter（结构化过滤）

**类型**：`JsonNode`  
**必填**：否  
**默认值**：`null`

**说明**：
- 基于结构化数据进行过滤
- 适用于有明确结构的文档
- 支持嵌套字段查询

**使用场景**：
```java
// 结构化文档过滤
String structuredFilterJson = """
    {
      "product": {
        "name": "Spring AI Alibaba",
        "version": {"$gte": "1.0.0"}
      },
      "status": "published"
    }
    """;

JsonNode structuredFilter = mapper.readTree(structuredFilterJson);

DashScopeAgentRagOptions options = DashScopeAgentRagOptions.builder()
    .withPipelineIds(List.of("pipeline-123"))
    .withStructuredFilter(structuredFilter)
    .build();
```

**与metadataFilter的区别**：
- `metadataFilter`: 通用元数据过滤，扁平结构
- `structuredFilter`: 结构化数据过滤，支持嵌套

---

### 2.6 sessionFileIds（会话级文件IDs）

**类型**：`List<String>`  
**必填**：否  
**默认值**：`null`

**说明**：
- 临时关联到当前会话的文件ID列表
- 文件只在当前会话中可检索
- 会话结束后自动清理

**使用场景**：
```java
// 用户在对话中上传了文档，临时添加到检索范围
DashScopeAgentRagOptions options = DashScopeAgentRagOptions.builder()
    .withPipelineIds(List.of("pipeline-123"))
    .withSessionFileIds(List.of(
        "temp-file-001",  // 用户刚上传的合同
        "temp-file-002"   // 用户刚上传的发票
    ))
    .build();
```

**与fileIds的区别**：
- `fileIds`: 知识库永久文件，所有会话共享
- `sessionFileIds`: 会话临时文件，仅当前会话可用

**生命周期**：
```
用户上传文件
    ↓
生成临时fileId
    ↓
添加到sessionFileIds
    ↓
当前会话中可检索
    ↓
会话结束
    ↓
自动清理（或根据配置保留一段时间）
```

## 三、使用示例

### 3.1 基础RAG配置

```java
// 最简单的RAG配置
DashScopeAgentRagOptions ragOptions = DashScopeAgentRagOptions.builder()
    .withPipelineIds(List.of("default-pipeline"))
    .build();

DashScopeAgentOptions agentOptions = DashScopeAgentOptions.builder()
    .withAppId("your-app-id")
    .withRagOptions(ragOptions)
    .build();

    new UserMessage("Spring AI Alibaba支持哪些模型？"),

    .getOutput()
    .getMetadata();

    (DashScopeAgentResponse.DashScopeAgentResponseOutput)

List<DocReference> docRefs = output.docReferences();

for (var docRef : docRefs) {
    System.out.println("- " + docRef.docName() + " (页码: " + docRef.pageNumber() + ")");
}
```

## 四、高级用法

### 4.1 动态RAG配置

```java
public class DynamicRagConfig {
    
    /**
     * 根据问题类型选择知识库
     */
    public DashScopeAgentRagOptions selectPipelines(String question) {
        List<String> pipelineIds = new ArrayList<>();
        
        if (question.contains("API") || question.contains("接口")) {
            pipelineIds.add("api-docs-pipeline");
        }
        
        if (question.contains("教程") || question.contains("如何")) {
            pipelineIds.add("tutorial-pipeline");
        }
        
        if (question.contains("示例") || question.contains("代码")) {
            pipelineIds.add("examples-pipeline");
        }
        
        // 默认添加主知识库
        if (pipelineIds.isEmpty()) {
            pipelineIds.add("main-pipeline");
        }
        
        return DashScopeAgentRagOptions.builder()
            .withPipelineIds(pipelineIds)
            .build();
    }
}
```

### 4.2 分层过滤策略

```java
public class LayeredFilterStrategy {
    
    /**
     * 分层过滤：Pipeline > Tags > Metadata
     */
    public DashScopeAgentRagOptions buildLayeredFilter(
            String category,
            String difficulty,
            String language) {
        
        // 第1层：Pipeline（粗过滤）
        List<String> pipelineIds = List.of("tech-docs-pipeline");
        
        // 第2层：Tags（中过滤）
        List<String> tags = List.of(category, language);
        
        // 第3层：Metadata（细过滤）
        ObjectMapper mapper = new ObjectMapper();
        ObjectNode filter = mapper.createObjectNode();
        filter.put("field", "difficulty");
        filter.put("operator", "eq");
        filter.put("value", difficulty);
        
        return DashScopeAgentRagOptions.builder()
            .withPipelineIds(pipelineIds)
            .withTags(tags)
            .withMetadataFilter(filter)
            .build();
    }
}

// 使用
DashScopeAgentRagOptions ragOptions = strategy.buildLayeredFilter(
    "Spring AI",   // category
    "beginner",    // difficulty
    "中文"         // language
);
```

## 五、最佳实践

### 5.1 性能优化

```java
public class RagPerformanceOptimizer {
    
    /**
     * 优化检索性能
     */
    public DashScopeAgentRagOptions optimize(String query) {
        // 1. 尽量限制Pipeline数量（1-3个最佳）
        List<String> pipelineIds = selectRelevantPipelines(query);
        
        // 2. 使用标签快速过滤
        List<String> tags = extractKeywordsAsTags(query);
        
        // 3. 避免过于复杂的元数据过滤
        // 简单过滤比复杂AND/OR组合快
        
        return DashScopeAgentRagOptions.builder()
            .withPipelineIds(pipelineIds)
            .withTags(tags)
            .build();
    }
}
```

**性能建议**：
- Pipeline数量：1-3个（最多5个）
- 标签数量：2-5个
- 避免深层嵌套的元数据过滤

### 5.3 错误处理

```java
public class SafeRagOptionsBuilder {
    
    /**
     * 安全构建RAG选项
     */
    public DashScopeAgentRagOptions buildSafely(
            List<String> pipelineIds,
            JsonNode metadataFilter) {
        
        try {
            // 验证Pipeline IDs
            if (pipelineIds == null || pipelineIds.isEmpty()) {
                logger.warn("No pipeline IDs provided, using default");
                pipelineIds = List.of("default-pipeline");
            }
            
            // 验证元数据过滤格式
            if (metadataFilter != null) {
                validateMetadataFilter(metadataFilter);
            }
            
            return DashScopeAgentRagOptions.builder()
                .withPipelineIds(pipelineIds)
                .withMetadataFilter(metadataFilter)
                .build();
                
        } catch (Exception e) {
            logger.error("Failed to build RAG options", e);
            // 返回默认配置
            return DashScopeAgentRagOptions.builder()
                .withPipelineIds(List.of("default-pipeline"))
                .build();
        }
    }
    
    private void validateMetadataFilter(JsonNode filter) {
        // 验证过滤器格式
        if (!filter.has("field") && !filter.has("and") && !filter.has("or")) {
            throw new IllegalArgumentException("Invalid metadata filter format");
        }
    }
}
```

## 六、注意事项

### 6.1 关键注意事项

| 注意事项 | 说明 |
|---------|------|
| **Pipeline必须存在** | pipelineIds必须在平台预先配置 |
| **性能影响** | 过多Pipeline和复杂过滤会影响性能 |
| **会话文件清理** | sessionFileIds有生命周期限制 |
| **过滤语法** | metadataFilter需要严格遵循JSON格式 |
| **标签命名** | 建议使用规范的标签命名体系 |

### 6.2 常见问题

**Q1: Pipeline ID从哪里获取？**
```
A: 登录阿里云百炼平台 → 知识库管理 → 查看Pipeline ID
```

**Q2: 如何调试RAG检索结果？**
```java
// 启用思维链查看检索过程
DashScopeAgentOptions options = DashScopeAgentOptions.builder()
    .withAppId("your-app-id")
    .withHasThoughts(true)
    .withRagOptions(ragOptions)
    .build();

// 查看docReferences
List<DocReference> docs = output.docReferences();
for (var doc : docs) {
    System.out.println("检索到: " + doc.docName());
    System.out.println("相关度: " + doc.score());  // 如果有
}
```

**Q3: metadataFilter和tags有什么区别？**
```
tags: 简单的标签匹配，性能好
metadataFilter: 复杂的条件查询，功能强大但性能较低

建议：先用tags粗过滤，再用metadataFilter细过滤
```

**Q4: 如何处理检索不到结果的情况？**
```java
ChatResponse response = agent.call(prompt);
DashScopeAgentResponse.DashScopeAgentResponseOutput output = ...;

if (output.docReferences() == null || output.docReferences().isEmpty()) {
    System.out.println("未检索到相关文档，Agent使用通用知识回答");
}
```

**Q5: sessionFileIds的生命周期是多久？**
```
A: 通常与会话绑定，会话结束后清理。
   具体时长取决于平台配置，一般为1-24小时。
```
