## 一、类概述

### 1.1 设计目的

`DashScopeAudioTranscriptionModel` 是用于将语音转换为文本（ASR, Automatic Speech Recognition）的核心实现类。支持异步、同步和实时流式三种识别模式。

### 1.2 什么是 ASR？

```
输入音频：🔊 语音文件（WAV/MP3/PCM等）
    ↓
语音识别模型处理
    ↓
输出文本："你好，欢迎使用 Spring AI Alibaba"
```

### 1.3 核心特性

| 特性 | 说明 |
|------|------|
| **异步识别** | 提交任务 → 轮询结果，适合录音文件 |
| **同步识别** | 一次调用返回结果（内部轮询） |
| **实时流式** | 边说边识别，低延迟 |
| **热词定制** | 支持自定义热词提升识别准确率 |
| **多语言** | 支持中文、英文、日语等 |
| **去除口语化** | 可去除"嗯"、"啊"等语气词 |

### 1.4 三种识别模式

| 模式 | 方法 | 适用场景 | 延迟 |
|------|------|----------|------|
| **异步识别** | `asyncCall() + fetch()` | 录音文件、批量处理 | 数秒 |
| **同步识别** | `call()` | 简单场景 | 数秒 |
| **实时流式** | `stream()` | 实时对话、语音助手 | <1秒 |

## 二、核心功能详解

### 2.1 异步识别（推荐用于文件）

```java
// Step 1: 提交识别任务
AudioTranscriptionPrompt prompt = new AudioTranscriptionPrompt(audioResource);
AudioTranscriptionResponse submitResponse = model.asyncCall(prompt);

// Step 2: 获取任务ID
String taskId = (String) submitResponse.getMetadata().get("taskId");

// Step 3: 轮询结果
while (true) {
    AudioTranscriptionResponse result = model.fetch(taskId);
    String status = (String) result.getMetadata().get("taskStatus");
    
    if ("SUCCEEDED".equals(status)) {
        String text = result.getResult().getOutput();
        System.out.println("识别结果: " + text);
        break;
    }
    else if ("FAILED".equals(status)) {
        System.err.println("识别失败");
        break;
    }
    
    Thread.sleep(1000);  // 等待1秒后重试
}
```

---

### 2.2 同步识别（最简单）

```java
// 一次调用，内部自动轮询
Resource audioResource = new FileSystemResource("audio.wav");
AudioTranscriptionPrompt prompt = new AudioTranscriptionPrompt(audioResource);

AudioTranscriptionResponse response = model.call(prompt);
String text = response.getResult().getOutput();

System.out.println("识别结果: " + text);
```

---

### 2.3 实时流式识别

```java
Resource audioResource = new FileSystemResource("audio.wav");
AudioTranscriptionPrompt prompt = new AudioTranscriptionPrompt(audioResource);

Flux<AudioTranscriptionResponse> stream = model.stream(prompt);

stream.subscribe(
    response -> {
        // 实时获取识别结果
        String partialText = response.getResult().getOutput();
        System.out.print(partialText + " ");
    },
    error -> System.err.println("识别失败: " + error.getMessage()),
    () -> System.out.println("\n识别完成")
);
```

## 三、主要方法详解

### 3.1 asyncCall() - 异步提交

**方法签名**：
```java
@Override
public AudioTranscriptionResponse asyncCall(AudioTranscriptionPrompt prompt)
```

**使用场景**：录音文件、批量处理

---

### 3.2 fetch() - 获取异步结果

**方法签名**：
```java
@Override
public AudioTranscriptionResponse fetch(String taskId)
```

**使用场景**：轮询异步任务状态

---

### 3.3 call() - 同步识别

**方法签名**：
```java
@Override
public AudioTranscriptionResponse call(AudioTranscriptionPrompt prompt)
```

**内部实现**：
1. 调用 `asyncCall()` 提交任务
2. 获取 taskId
3. 循环调用 `fetch()` 轮询
4. 直到成功或失败

---

### 3.4 stream() - 流式识别

**方法签名**：
```java
@Override
public Flux<AudioTranscriptionResponse> stream(AudioTranscriptionPrompt prompt)
```

**内部实现**：
1. 建立 WebSocket 连接
2. 发送音频数据（分块）
3. 实时接收识别结果

## 五、完整使用示例

### 5.1 录音文件识别

```java
@Service
public class AudioTranscriptionService {
    
    private final AudioTranscriptionModel transcriptionModel;
    
    public String transcribeFile(String audioFilePath) {
        // 加载音频文件
        Resource audioResource = new FileSystemResource(audioFilePath);
        
        // 创建提示
        AudioTranscriptionPrompt prompt = new AudioTranscriptionPrompt(
            audioResource,
            DashScopeAudioTranscriptionOptions.builder()
                .withDisfluencyRemovalEnabled(true)
                .build()
        );
        
        // 执行识别（同步）
        AudioTranscriptionResponse response = transcriptionModel.call(prompt);
        
        // 返回文本
        return response.getResult().getOutput();
    }
}
```

---

### 5.2 实时语音识别

```java
@Service
public class RealtimeTranscriptionService {
    
    private final AudioTranscriptionModel transcriptionModel;
    
    public void transcribeRealtime(InputStream audioStream) {
        // 将InputStream转为Resource
        Resource audioResource = new InputStreamResource(audioStream);
        
        // 创建提示
        AudioTranscriptionPrompt prompt = new AudioTranscriptionPrompt(
            audioResource,
            DashScopeAudioTranscriptionOptions.builder()
                .withSampleRate(16000)
                .withFormat("pcm")
                .build()
        );
        
        // 流式识别
        Flux<AudioTranscriptionResponse> stream = transcriptionModel.stream(prompt);
        
        // 实时输出
        stream.subscribe(
            response -> {
                String text = response.getResult().getOutput();
                if (text != null && !text.isEmpty()) {
                    System.out.print(text + " ");
                }
            },
            error -> logger.error("识别失败", error),
            () -> System.out.println("\n识别完成")
        );
    }
}
```

### 5.3 批量文件识别

```java
@Service
public class BatchTranscriptionService {
    
    private final AudioTranscriptionModel transcriptionModel;
    
    public Map<String, String> batchTranscribe(List<String> audioFilePaths) {
        Map<String, String> results = new ConcurrentHashMap<>();
        
        audioFilePaths.parallelStream().forEach(filePath -> {
            try {
                Resource audioResource = new FileSystemResource(filePath);
                AudioTranscriptionPrompt prompt = new AudioTranscriptionPrompt(audioResource);
                
                AudioTranscriptionResponse response = transcriptionModel.call(prompt);
                String text = response.getResult().getOutput();
                
                results.put(filePath, text);
                logger.info("识别完成: {}", filePath);
            }
            catch (Exception e) {
                logger.error("识别失败: " + filePath, e);
                results.put(filePath, "[识别失败]");
            }
        });
        
        return results;
    }
}
```

### 5.4 REST API 示例

```java
@RestController
@RequestMapping("/api/asr")
public class ASRController {
    
    private final AudioTranscriptionModel transcriptionModel;
    
    @PostMapping("/transcribe")
    public TranscriptionResult transcribe(
            @RequestParam("file") MultipartFile file) throws IOException {
        
        // 保存临时文件
        Path tempFile = Files.createTempFile("audio_", ".wav");
        file.transferTo(tempFile);
        
        try {
            // 识别
            Resource audioResource = new FileSystemResource(tempFile.toFile());
            AudioTranscriptionPrompt prompt = new AudioTranscriptionPrompt(audioResource);
            
            long startTime = System.currentTimeMillis();
            AudioTranscriptionResponse response = transcriptionModel.call(prompt);
            long duration = System.currentTimeMillis() - startTime;
            
            String text = response.getResult().getOutput();
            
            return new TranscriptionResult(
                text,
                duration,
                file.getOriginalFilename()
            );
        }
        finally {
            // 删除临时文件
            Files.deleteIfExists(tempFile);
        }
    }
}

@Data
@AllArgsConstructor
class TranscriptionResult {
    private String text;
    private long durationMs;
    private String filename;
}
```

```java
// 场景1：录音文件 → 同步识别
transcriptionModel.call(prompt);

transcriptionModel.asyncCall(prompt);
```

### 6.2 音频格式要求

- **采样率**：16000 Hz
- **位深度**：16 bit
- **声道数**：单声道
- **格式**：WAV 或 PCM

## 七、注意事项与FAQ

### 7.1 注意事项

| 注意事项 | 说明 |
|---------|------|
| **音频时长限制** | 异步模式 < 5小时，实时模式 < 1小时 |
| **音频文件大小** | < 512MB |
| **采样率** | 推荐 8000/16000 Hz |
| **音频质量** | 清晰的音频识别准确率更高 |
| **网络稳定性** | 流式识别需要稳定网络 |
| **热词数量** | 建议 < 1000个 |

---

### 7.2 常见问题

**Q1: 识别准确率不高怎么办？**
```
A: 
1. 提供清晰的音频（减少噪音）
2. 使用热词定制
3. 指定语言提示
4. 提高采样率（16kHz）
```

**Q2: 如何处理长音频？**
```
A: 
1. 使用异步模式
2. 或者切分成短音频分段识别
3. 最后拼接结果
```

**Q3: 实时识别延迟高怎么办？**
```
A: 
1. 使用更低的采样率（8kHz）
2. 减小音频块大小
3. 优化网络连接
4. 使用专用实时模型
```

**Q4: 如何识别多人对话？**
```
A: 
1. 使用多声道音频
2. 指定 channelId 分别识别
3. 或使用声纹识别区分说话人
```

**Q5: 支持哪些语言？**
```
A: 
主要支持：
- 中文（普通话、粤语、四川话等）
- 英语
- 日语
- 韩语
- 等
```
