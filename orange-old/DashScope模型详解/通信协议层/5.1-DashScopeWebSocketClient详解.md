## 一、类概述

### 1.1 设计目的

`DashScopeWebSocketClient` 是基于OkHttp WebSocket实现的客户端，用于与阿里云百炼服务进行实时双向通信。它支持文本和二进制数据的流式传输，并使用Reactor的Flux进行响应式处理。

### 1.2 核心职责

```
┌──────────────────────────────────────┐
│  高层API                             │
│  (DashScopeAudioSpeechApi等)         │
└──────────────┬───────────────────────┘
               │
               ↓
┌──────────────────────────────────────┐
│  DashScopeWebSocketClient (本类)     │ ← 本文档介绍的核心
│  - WebSocket连接管理                 │
│  - 文本/二进制消息发送                │
│  - 事件监听与处理                    │
│  - Flux流式响应                      │
└──────────────┬───────────────────────┘
               │
               ↓
┌──────────────────────────────────────┐
│  OkHttp WebSocket                    │
│  (底层WebSocket实现)                 │
└──────────────┬───────────────────────┘
               │
               ↓
┌──────────────────────────────────────┐
│  DashScope WebSocket Service         │
│  (百炼WebSocket服务)                 │
└──────────────────────────────────────┘
```

### 1.3 核心特性

| 特性 | 说明 |
|------|------|
| **双向通信** | 支持客户端→服务端和服务端→客户端 |
| **流式处理** | 使用Reactor Flux实现响应式流 |
| **文本/二进制** | 支持两种数据格式 |
| **事件驱动** | 基于WebSocketListener的事件模型 |
| **自动重连** | 连接断开时支持重建 |
| **线程安全** | 使用AtomicBoolean保证状态一致性 |
| **背压支持** | Flux的BUFFER策略处理背压 |

### 1.4 继承关系

```java
WebSocketListener (OkHttp接口)
  ↑
  └── DashScopeWebSocketClient (实现类)
```

## 三、核心功能

### 3.1 流式二进制输出

**方法签名**：
```java
public Flux<ByteBuffer> streamBinaryOut(String text)
```

**功能**：发送文本命令，接收二进制流响应

**使用场景**：语音合成（TTS）- 发送文本，接收音频数据

**实现逻辑**：
```java
public Flux<ByteBuffer> streamBinaryOut(String text) {
    // 1. 创建Flux，设置binary_emitter
    Flux<ByteBuffer> flux = Flux.<ByteBuffer>create(emitter -> {
        this.binary_emitter = emitter;
    }, FluxSink.OverflowStrategy.BUFFER);
    
    // 2. 发送文本命令
    sendText(text);
    
    // 3. 返回Flux（后续通过binary_emitter推送数据）
    return flux;
}
```

**工作流程**：
```
1. 客户端调用streamBinaryOut("请求文本")
2. 创建Flux并保存binary_emitter
3. 通过WebSocket发送文本
4. 服务端处理并返回二进制数据
5. onMessage(bytes)接收到数据
6. binary_emitter.next(bytes)推送到Flux
7. 订阅者实时接收数据
```

### 3.2 流式文本输出

**方法签名**：
```java
public Flux<String> streamTextOut(Flux<ByteBuffer> binary)
```

**功能**：发送二进制流，接收文本流响应

**使用场景**：语音识别（ASR）- 发送音频数据，接收识别文本

**实现逻辑**：
```java
public Flux<String> streamTextOut(Flux<ByteBuffer> binary) {
    // 1. 创建Flux，设置text_emitter
    Flux<String> flux = Flux.<String>create(emitter -> {
        this.text_emitter = emitter;
    }, FluxSink.OverflowStrategy.BUFFER);
    
    // 2. 订阅输入的二进制流，发送每个数据块
    binary.subscribe(this::sendBinary);
    
    // 3. 返回Flux（后续通过text_emitter推送数据）
    return flux;
}
```

**工作流程**：
```
1. 客户端调用streamTextOut(audioFlux)
2. 创建Flux并保存text_emitter
3. 订阅audioFlux，实时发送音频数据
4. 服务端识别并返回文本
5. onMessage(text)接收到数据
6. text_emitter.next(text)推送到Flux
7. 订阅者实时接收识别文本
```

### 3.5 建立WebSocket连接

**方法**：`establishWebSocketClient()`

**功能**：创建并配置OkHttp WebSocket客户端

**实现逻辑**：
```java
private void establishWebSocketClient() {
    // 1. 配置日志拦截器
    HttpLoggingInterceptor logging = new HttpLoggingInterceptor();
    logging.setLevel(HttpLoggingInterceptor.Level.NONE);
    
    // 2. 配置调度器（并发控制）
    Dispatcher dispatcher = new Dispatcher();
    dispatcher.setMaxRequests(32);
    dispatcher.setMaxRequestsPerHost(32);
    
    // 3. 创建OkHttpClient
    OkHttpClient.Builder clientBuilder = new OkHttpClient.Builder();
    clientBuilder
        .connectTimeout(Duration.ofSeconds(120))  // 连接超时
        .readTimeout(Duration.ofSeconds(300))     // 读超时
        .writeTimeout(Duration.ofSeconds(60))     // 写超时
        .addInterceptor(logging)
        .dispatcher(dispatcher)
        .protocols(Collections.singletonList(Protocol.HTTP_1_1))
        .connectionPool(new ConnectionPool(32, 300, TimeUnit.SECONDS));
    
    OkHttpClient httpClient = clientBuilder.build();
    
    // 4. 创建WebSocket连接
    try {
        webSocketClient = httpClient.newWebSocket(
            buildConnectionRequest(),  // 请求配置
            this                       // 事件监听器
        );
    } catch (Throwable ex) {
        logger.error("create websocket failed: msg={}", ex.getMessage());
    }
}
```

**超时配置**：

| 超时类型 | 默认值 | 说明 |
|---------|--------|------|
| **connectTimeout** | 120秒 | 建立连接的超时时间 |
| **readTimeout** | 300秒 | 读取数据的超时时间 |
| **writeTimeout** | 60秒 | 写入数据的超时时间 |
| **idleTimeout** | 300秒 | 连接池空闲超时 |

**连接池配置**：
- 最大连接数：32
- 空闲超时：300秒
- 最大请求数：32
- 每主机最大请求数：32

## 四、事件处理

### 4.1 事件监听器方法

DashScopeWebSocketClient继承自`WebSocketListener`，实现了以下事件处理方法：

| 方法 | 触发时机 | 处理逻辑 |
|------|---------|----------|
| `onOpen` | 连接成功建立 | 设置isOpen=true，记录日志 |
| `onMessage(String)` | 接收到文本消息 | 解析事件，分发到text_emitter |
| `onMessage(ByteString)` | 接收到二进制消息 | 转换为ByteBuffer，发送到binary_emitter |
| `onClosing` | 开始关闭连接 | 完成emitters，确认关闭 |
| `onClosed` | 连接已关闭 | 设置isOpen=false，完成emitters |
| `onFailure` | 连接失败 | 设置isOpen=false，emitters发送错误 |

---

### 4.3 onMessage(String) - 接收文本

```java
@Override
public void onMessage(WebSocket webSocket, String text) {
    logger.debug("receive ws event onMessage(text): handle={}, text={}", 
        webSocket, text);
    
    // 解析JSON消息
    EventMessage message = objectMapper.readValue(text, EventMessage.class);
    
    // 根据事件类型处理
    switch (message.header.event) {
        case TASK_STARTED:
            logger.info("task started: text={}", text);
            break;
            
        case TASK_FINISHED:
            logger.info("task finished: text={}", text);
            emittersComplete("finished");  // 完成流
            break;
            
        case TASK_FAILED:
            logger.error("task failed: text={}", text);
            emittersError("task failed", new Exception());  // 错误流
            break;
            
        case RESULT_GENERATED:
            if (this.text_emitter != null) {
                text_emitter.next(text);  // 推送结果到Flux
            }
            break;
            
        default:
            logger.error("task error: text={}", text);
            emittersError("unsupported event", new Exception());
    }
}
```

**事件类型**：

| 事件 | 值 | 说明 |
|------|---|------|
| **TASK_STARTED** | task-started | 任务开始 |
| **RESULT_GENERATED** | result-generated | 生成了结果（实时推送） |
| **TASK_FINISHED** | task-finished | 任务完成 |
| **TASK_FAILED** | task-failed | 任务失败 |

### 4.8 Emitter管理

**完成流**：
```java
private void emittersComplete(String event) {
    if (this.binary_emitter != null && !this.binary_emitter.isCancelled()) {
        logger.info("binary emitter handling: complete on {}", event);
        this.binary_emitter.complete();
    }
    if (this.text_emitter != null && !this.text_emitter.isCancelled()) {
        logger.info("text emitter handling: complete on {}", event);
        this.text_emitter.complete();
    }
}
```

**错误流**：
```java
private void emittersError(String event, Throwable t) {
    if (this.binary_emitter != null && !this.binary_emitter.isCancelled()) {
        logger.info("binary emitter handling: error on {}", event);
        this.binary_emitter.error(t);
    }
    if (this.text_emitter != null && !this.text_emitter.isCancelled()) {
        logger.info("text emitter handling: error on {}", event);
        this.text_emitter.error(t);
    }
}
```

### 5.3 实时音频流处理

```java
public class RealtimeAudioProcessor {
    
    private final DashScopeWebSocketClient client;
    
    /**
     * 实时处理麦克风输入
     */
    public void processMicrophoneInput() {
        // 1. 发送开始命令
        client.sendText(buildStartCommand());
        
        // 2. 创建麦克风音频流
        Flux<ByteBuffer> microphoneFlux = createMicrophoneFlux();
        
        // 3. 发送音频并接收结果
        Flux<String> resultStream = client.streamTextOut(microphoneFlux);
        
        // 4. 实时显示识别结果
        resultStream.subscribe(
            result -> updateUI(result),
            error -> handleError(error),
            () -> cleanup()
        );
    }
    
    private Flux<ByteBuffer> createMicrophoneFlux() {
        return Flux.create(sink -> {
            // 从麦克风读取音频
            microphone.start();
            microphone.onData(data -> {
                sink.next(ByteBuffer.wrap(data));
            });
            microphone.onStop(() -> {
                sink.complete();
            });
        }, FluxSink.OverflowStrategy.BUFFER);
    }
}
```

### 6.1 连接管理

```java
public class ManagedWebSocketClient {
    
    private final DashScopeWebSocketClient client;
    private volatile boolean isActive = false;
    
    /**
     * 安全关闭连接
     */
    public void shutdown() {
        if (isActive) {
            // 发送结束命令
            client.sendText(buildFinishCommand());
            
            // 等待一段时间让数据发送完成
            Thread.sleep(1000);
            
            isActive = false;
        }
    }
    
    /**
     * 确保连接可用
     */
    public void ensureConnected() {
        if (!isActive) {
            // WebSocket会在首次发送时自动连接
            isActive = true;
        }
    }
}
```

## 七、注意事项

### 7.1 关键注意事项

| 注意事项 | 说明 |
|---------|------|
| **连接状态** | 使用AtomicBoolean保证线程安全 |
| **自动重连** | 首次发送时自动建立连接 |
| **背压处理** | 使用BUFFER策略，注意内存消耗 |
| **超时设置** | 合理配置各类超时时间 |
| **资源清理** | 及时完成或取消Flux |
| **线程模型** | WebSocket回调在OkHttp线程池执行 |
| **事件顺序** | 保证事件按顺序处理 |

### 7.2 常见问题

**Q1: WebSocket何时建立连接？**
```
A: 首次调用sendText或sendBinary时自动建立连接。
   不需要手动调用连接方法。
```

**Q2: 如何判断连接是否成功？**
```
A: 监听日志中的onOpen事件，或检查第一次发送是否成功。
```

**Q3: 连接断开后会自动重连吗？**
```
A: 会。下次发送时检测到isOpen=false会自动重建连接。
```

**Q4: Flux什么时候complete？**
```
A: 接收到TASK_FINISHED事件或连接关闭时。
```

**Q5: 如何处理超时？**
```java
// 在Flux上添加超时
flux.timeout(Duration.ofMinutes(5))
    .onErrorResume(TimeoutException.class, e -> {
        // 处理超时
        return Flux.empty();
    });
```

**Q6: 可以同时发送文本和二进制吗？**
```
A: 可以，但通常一个WebSocket连接专注于一个方向。
   TTS: 发送文本 → 接收二进制
   ASR: 发送二进制 → 接收文本
```

**Q7: 如何调试WebSocket通信？**
```java
// 1. 启用OkHttp日志
HttpLoggingInterceptor logging = new HttpLoggingInterceptor();
logging.setLevel(HttpLoggingInterceptor.Level.BODY);

// 2. 查看应用日志
// DashScopeWebSocketClient使用slf4j，可以配置日志级别
```
