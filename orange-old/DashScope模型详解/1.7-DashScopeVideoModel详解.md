## 一、类概述

### 1.1 设计目的

`DashScopeVideoModel` 是用于生成视频的核心实现类。它基于阿里云百炼的视频生成服务，支持文生视频、图生视频等多种生成模式。

### 1.2 什么是视频生成？

```
输入：
  - 文本提示词："一只熊猫在竹林里玩耍"
  - 或参考图片
    ↓
AI视频生成模型
    ↓
输出：视频文件（MP4/MOV等）
```

### 1.3 核心特性

| 特性 | 说明 |
|------|------|
| **异步任务模式** | 提交任务 → 轮询状态 → 获取视频 |
| **文生视频（T2V）** | 从文本提示词生成视频 |
| **图生视频（I2V）** | 从参考图生成视频 |
| **首尾帧控制** | 指定视频首帧和尾帧 |
| **时长控制** | 可指定视频时长 |
| **分辨率控制** | 支持多种分辨率 |
| **负提示词** | 排除不想要的内容 |

### 1.4 支持的模型

| 模型名称 | 模型ID | 特点 |
|---------|--------|------|
| **通义万相-视频** | `wanx-v2v-v1` | 图生视频 |
| **文生视频** | `wanx-t2v-v1` | 文本生成视频 |

### 1.5 使用场景

- ✅ **短视频创作**：快速生成短视频内容
- ✅ **营销素材**：广告视频、产品展示
- ✅ **教育培训**：动画教学视频
- ✅ **游戏开发**：过场动画生成
- ✅ **内容创作**：AI辅助视频制作

## 二、核心功能详解

### 2.1 异步任务模式

视频生成通常需要较长时间（几分钟到几十分钟），因此采用异步模式：

```
1. 提交任务 (submitGenTask)
   ↓
2. 获取 taskId
   ↓
3. 轮询任务状态 (getVideoTask)
   ↓
4. 状态判断：
   - PENDING/RUNNING → 继续等待
   - SUCCEEDED → 获取视频URL
   - FAILED → 返回错误
   ↓
5. 下载视频
```

## 三、主要方法详解

### 3.1 call() - 生成视频

**方法签名**：
```java
@Override
public VideoResponse call(VideoPrompt prompt)
```

**内部流程**：
```java
public VideoResponse call(VideoPrompt prompt) {
    // 1. 参数验证
    Assert.notNull(prompt, "Prompt must not be null");
    
    // 2. 提交任务
    String taskId = submitGenTask(prompt);
    if (Objects.isNull(taskId)) {
        return new VideoResponse(null);
    }
    
    // 3. 轮询任务状态（使用重试模板）
    return this.retryTemplate.execute(context -> {
        var resp = getVideoTask(taskId);
        
        if (Objects.nonNull(resp)) {
            String status = resp.getOutput().getTaskStatus();
            
            switch (status) {
                case "SUCCEEDED" -> {
                    return toVideoResponse(resp);
                }
                case "FAILED" -> {
                    return new VideoResponse(null);
                }
            }
        }
        
        // 任务未完成，抛出瞬时异常触发重试
        throw new TransientAiException("Video generation still pending");
    });
}
```

---

### 3.2 submitGenTask() - 提交任务

**方法签名**：
```java
public String submitGenTask(VideoPrompt prompt)
```

**实现逻辑**：
```java
public String submitGenTask(VideoPrompt prompt) {
    // 1. 构建请求
    DashScopeVideoApi.VideoGenerationRequest request = 
        buildDashScopeVideoRequest(prompt);
    
    // 2. 提交任务
    VideoGenerationResponse response = 
        this.dashScopeVideoApi.submitVideoGenTask(request).getBody();
    
    // 3. 检查响应
    if (Objects.isNull(response) || 
        Objects.isNull(response.getOutput().getTaskId())) {
        logger.warn("Failed to submit video generation task");
        return null;
    }
    
    // 4. 返回任务ID
    return response.getOutput().getTaskId();
}
```

---

### 3.3 getVideoTask() - 获取任务状态

```java
private DashScopeVideoApi.VideoGenerationResponse getVideoTask(String taskId) {
    ResponseEntity<VideoGenerationResponse> response = 
        this.dashScopeVideoApi.queryVideoGenTask(taskId);
    
    if (response.getStatusCode().is2xxSuccessful()) {
        return response.getBody();
    }
    else {
        logger.warn("Failed to query video task: {}", 
            response.getStatusCode());
        return null;
    }
}
```

### 5.3 异步任务处理

```java
@Service
public class AsyncVideoService {
    
    private final VideoModel videoModel;
    
    public String submitVideoTask(String prompt) {
        VideoPrompt videoPrompt = new VideoPrompt(prompt);
        
        // 提交任务
        String taskId = videoModel.submitGenTask(videoPrompt);
        
        // 保存任务ID到数据库或返回给用户
        return taskId;
    }
    
    public String checkTaskStatus(String taskId) {
        // 查询任务状态
        DashScopeVideoApi.VideoGenerationResponse response = 
            videoModel.getVideoTask(taskId);
        
        if (response != null) {
            String status = response.getOutput().getTaskStatus();
            
            if ("SUCCEEDED".equals(status)) {
                // 返回视频URL
                return response.getOutput().getVideoUrl();
            }
            else if ("FAILED".equals(status)) {
                return "生成失败";
            }
            else {
                return "生成中: " + status;
            }
        }
        
        return "查询失败";
    }
}
```

### 5.4 批量视频生成

```java
@Service
public class BatchVideoService {
    
    private final VideoModel videoModel;
    
    public Map<String, String> batchGenerate(List<String> prompts) {
        Map<String, String> taskIds = new ConcurrentHashMap<>();
        
        // 批量提交任务
        prompts.forEach(prompt -> {
            String taskId = videoModel.submitGenTask(
                new VideoPrompt(prompt)
            );
            taskIds.put(prompt, taskId);
        });
        
        // 等待所有任务完成
        Map<String, String> results = new ConcurrentHashMap<>();
        taskIds.forEach((prompt, taskId) -> {
            while (true) {
                DashScopeVideoApi.VideoGenerationResponse response = 
                    videoModel.getVideoTask(taskId);
                
                if (response != null) {
                    String status = response.getOutput().getTaskStatus();
                    
                    if ("SUCCEEDED".equals(status)) {
                        results.put(prompt, response.getOutput().getVideoUrl());
                        break;
                    }
                    else if ("FAILED".equals(status)) {
                        results.put(prompt, "[生成失败]");
                        break;
                    }
                }
                
                try {
                    Thread.sleep(5000);  // 等待5秒
                }
                catch (InterruptedException e) {
                    break;
                }
            }
        });
        
        return results;
    }
}
```

### 5.5 REST API 示例

```java
@RestController
@RequestMapping("/api/video")
public class VideoController {
    
    private final VideoModel videoModel;
    
    @PostMapping("/generate")
    public VideoTaskResponse generateVideo(@RequestBody VideoRequest request) {
        // 创建提示
        VideoPrompt prompt = new VideoPrompt(
            request.getPrompt(),
            DashScopeVideoOptions.builder()
                .withDuration(request.getDuration())
                .withSize(request.getSize())
                .withNegativePrompt(request.getNegativePrompt())
                .build()
        );
        
        // 提交任务
        String taskId = videoModel.submitGenTask(prompt);
        
        return new VideoTaskResponse(
            taskId,
            "PENDING",
            "任务已提交"
        );
    }
    
    @GetMapping("/status/{taskId}")
    public VideoTaskResponse checkStatus(@PathVariable String taskId) {
        DashScopeVideoApi.VideoGenerationResponse response = 
            videoModel.getVideoTask(taskId);
        
        if (response != null) {
            String status = response.getOutput().getTaskStatus();
            String videoUrl = "SUCCEEDED".equals(status) 
                ? response.getOutput().getVideoUrl() 
                : null;
            
            return new VideoTaskResponse(taskId, status, videoUrl);
        }
        
        return new VideoTaskResponse(taskId, "UNKNOWN", "查询失败");
    }
}

@Data
class VideoRequest {
    private String prompt;
    private Integer duration = 5;
    private String size = "1280*720";
    private String negativePrompt;
}

@Data
@AllArgsConstructor
class VideoTaskResponse {
    private String taskId;
    private String status;
    private String videoUrl;
}
```

## 七、注意事项与FAQ

### 7.1 注意事项

| 注意事项 | 说明 |
|---------|------|
| **生成时间** | 通常需要几分钟到几十分钟 |
| **视频时长限制** | 单个视频建议 < 30秒 |
| **分辨率限制** | 最高支持 1920*1080 |

| **内容合规** | 确保生成内容符合法律法规 |

### 7.2 常见问题

**Q1: 视频生成需要多久？**
```
A: 根据视频时长和复杂度：
- 5秒视频：约 2-5 分钟
- 10秒视频：约 5-10 分钟
- 30秒视频：约 15-30 分钟
```

**Q2: 如何提高生成质量？**
```
A: 
1. 提供详细的提示词
2. 使用高分辨率
3. 使用负提示词排除不想要的内容
4. 固定随机种子保证可重现性
```

**Q3: 如何处理生成失败？**
```
A: 
1. 检查提示词是否合规
2. 检查网络连接
3. 重试任务
4. 联系技术支持
```

**Q4: 支持哪些视频格式？**
```
A: 主要输出 MP4 格式
```

**Q5: 可以生成多长的视频？**
```
A: 
- 推荐：5-10秒
- 最长：30秒
- 超长视频建议分段生成后拼接
```
