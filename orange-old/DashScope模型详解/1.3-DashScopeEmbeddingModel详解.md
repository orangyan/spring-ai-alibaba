## 一、类概述

### 1.1 设计目的

`DashScopeEmbeddingModel` 是 Spring AI Alibaba 框架中用于调用阿里云百炼（DashScope）文本嵌入（Text Embedding）能力的核心实现类。它将文本转换为高维向量表示，是 RAG（检索增强生成）、语义搜索、文本聚类等AI应用的基础组件。

### 1.2 什么是 Embedding？

**Embedding（嵌入向量）** 是将文本转换为固定维度的数值向量的过程。相似的文本在向量空间中距离更近，不相似的文本距离更远。

```
文本                        向量表示
"猫是可爱的动物"  →  [0.23, -0.15, 0.87, ..., 0.42]  (1536维)
"狗很忠诚"        →  [0.19, -0.12, 0.82, ..., 0.39]  (1536维)
"今天天气很好"    →  [-0.45, 0.67, -0.23, ..., 0.12] (1536维)

相似度计算：
cos_sim("猫是可爱的动物", "狗很忠诚") = 0.85  ← 语义相关
cos_sim("猫是可爱的动物", "今天天气很好") = 0.12  ← 语义无关
```

### 1.3 核心特性

| 特性 | 说明 |
|------|------|
| **高质量向量** | 基于大规模预训练，捕获深层语义 |
| **多种维度** | 支持 512、768、1024、1536 等多种维度 |
| **批量处理** | 支持批量文本向量化，提高效率 |
| **文档嵌入** | 支持 Document 对象嵌入，自动处理元数据 |
| **MetadataMode** | 灵活控制元数据是否参与嵌入 |
| **TextType** | 支持 query 和 document 两种文本类型 |
| **可观测性** | 集成 Micrometer Observation 监控 |
| **重试机制** | 内置重试逻辑，提高可靠性 |

### 1.4 支持的模型

| 模型名称 | 模型ID | 维度 | 特点 |
|---------|--------|------|------|
| **通用文本-v1** | `text-embedding-v1` | 1536 | 通用文本嵌入 |
| **通用文本-v2** | `text-embedding-v2` | 1536 | 性能更优 |
| **通用文本-v3** | `text-embedding-v3` | 1024 | 最新版本，支持多维度 |
| **多语言-v1** | `text-embedding-v1-multilingual` | 1536 | 多语言支持 |

### 1.5 使用场景

- ✅ **语义搜索**：根据语义而非关键词检索
- ✅ **RAG应用**：检索相关文档增强生成
- ✅ **文本聚类**：将相似文本分组
- ✅ **推荐系统**：基于内容的推荐
- ✅ **相似度计算**：计算文本之间的相似度
- ✅ **异常检测**：识别异常或离群文本
- ✅ **分类标注**：作为分类模型的特征

```java

    List.of("文本1", "文本2", "文本3"),

    .withTextType("document")
```

```java
        "它提供了统一的 API 接口"
```

**维度选择建议**：
| 维度 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| **512** | 存储小、计算快 | 精度稍低 | 快速原型、大规模数据 |
| **768** | 平衡性能和精度 | - | 通用场景 |
| **1024** | 高精度 | 存储大、计算慢 | 高精度要求 |
| **1536** | 最高精度 | 存储最大、计算最慢 | 精度优先场景 |

## 五、主要方法详解

### 5.1 call() - 核心嵌入方法

**方法签名**：
```java
@Override
public EmbeddingResponse call(EmbeddingRequest request)
```

**内部实现逻辑**：
```java
public EmbeddingResponse call(EmbeddingRequest request) {
    // 1. 构建请求（合并配置）
    EmbeddingRequest embeddingRequest = buildEmbeddingRequest(request);
    
    // 2. 创建API请求
    DashScopeApi.EmbeddingRequest apiRequest = createRequest(embeddingRequest);
    
    // 3. 创建观测上下文
    var observationContext = EmbeddingModelObservationContext.builder()
        .embeddingRequest(embeddingRequest)
        .provider(DashScopeApiConstants.PROVIDER_NAME)
        .build();
    
    // 4. 执行观测调用
    return EmbeddingModelObservationDocumentation.EMBEDDING_MODEL_OPERATION
        .observation(this.observationConvention, 
                     DEFAULT_OBSERVATION_CONVENTION,
                     () -> observationContext,
                     this.observationRegistry)
        .observe(() -> {
            // 5. 重试执行API调用
            DashScopeApi.EmbeddingList apiEmbeddingResponse = 
                this.retryTemplate.execute(ctx -> {
                    try {
                        return this.dashScopeApi.embeddings(apiRequest).getBody();
                    }
                    catch (Exception e) {
                        logger.error("Error embedding request: {}", 
                            request.getInstructions(), e);
                        throw e;
                    }
                });
            
            // 6. 检查响应
            if (apiEmbeddingResponse == null) {
                logger.warn("No embeddings returned for request: {}", request);
                return new EmbeddingResponse(List.of());
            }
            
            // 7. 检查错误
            if (apiEmbeddingResponse.message() != null) {
                logger.error("Error message returned for request: {}", 
                    apiEmbeddingResponse.message());
                throw new RuntimeException("Embedding failed: error code:" + 
                    apiEmbeddingResponse.code() + ", message:" + 
                    apiEmbeddingResponse.message());
            }
            
            // 8. 获取使用量
            DashScopeApi.EmbeddingUsage usage = apiEmbeddingResponse.usage();
            Usage embeddingUsage = usage != null 
                ? this.getDefaultUsage(usage) 
                : new EmptyUsage();
            
            // 9. 构建元数据
            var metadata = generateResponseMetadata(
                apiRequest.model(), 
                embeddingUsage
            );
            
            // 10. 转换为 Embedding 列表
            List<Embedding> embeddings = apiEmbeddingResponse.output()
                .embeddings()
                .stream()
                .map(e -> new Embedding(e.embedding(), e.textIndex()))
                .toList();
            
            // 11. 构建响应
            EmbeddingResponse embeddingResponse = 
                new EmbeddingResponse(embeddings, metadata);
            
            // 12. 设置观测响应
            observationContext.setResponse(embeddingResponse);
            
            return embeddingResponse;
        });
}
```

### 5.6 buildEmbeddingRequest() - 构建请求

**方法签名**：
```java
private EmbeddingRequest buildEmbeddingRequest(EmbeddingRequest embeddingRequest)
```

**实现逻辑**：
```java
private EmbeddingRequest buildEmbeddingRequest(EmbeddingRequest embeddingRequest) {
    // 1. 处理运行时配置
    DashScopeEmbeddingOptions runtimeOptions = null;
    if (embeddingRequest.getOptions() != null) {
        runtimeOptions = ModelOptionsUtils.copyToTarget(
            embeddingRequest.getOptions(),
            EmbeddingOptions.class,
            DashScopeEmbeddingOptions.class
        );
    }
    
    // 2. 合并配置
    DashScopeEmbeddingOptions requestOptions = runtimeOptions == null 
        ? this.defaultOptions
        : DashScopeEmbeddingOptions.builder()
            // 合并通用选项
            .withModel(ModelOptionsUtils.mergeOption(
                runtimeOptions.getModel(), 
                this.defaultOptions.getModel()
            ))
            .withDimensions(ModelOptionsUtils.mergeOption(
                runtimeOptions.getDimensions(),
                defaultOptions.getDimensions()
            ))
            // 合并 DashScope 特有选项
            .withTextType(ModelOptionsUtils.mergeOption(
                runtimeOptions.getTextType(), 
                defaultOptions.getTextType()
            ))
            .build();
    
    // 3. 返回新的请求
    return new EmbeddingRequest(
        embeddingRequest.getInstructions(), 
        requestOptions
    );
}
```

### 7.2 向量化流程

```
输入文本
    ↓
1. Tokenization（分词）
    ↓
2. Token Embedding（Token向量化）
    ↓
3. Transformer Encoding（编码）
    ↓
4. Pooling（池化）
    ↓
5. Normalization（归一化）
    ↓
输出向量 [0.23, -0.15, ..., 0.42]
```

### 8.2 语义搜索示例

```java
@Service
public class SemanticSearchService {
    
    private final EmbeddingModel embeddingModel;
    private final List<Document> documents;  // 文档库
    private final Map<String, float[]> embeddingCache;  // 嵌入缓存
    
    public SemanticSearchService(EmbeddingModel embeddingModel) {
        this.embeddingModel = embeddingModel;
        this.documents = loadDocuments();
        this.embeddingCache = new HashMap<>();
        
        // 预先嵌入所有文档
        precomputeEmbeddings();
    }
    
    private void precomputeEmbeddings() {
        for (Document doc : documents) {
            float[] embedding = embeddingModel.embed(doc);
            embeddingCache.put(doc.getId(), embedding);
        }
    }
    
    public List<Document> search(String query, int topK) {
        // 1. 嵌入查询
        float[] queryEmbedding = embeddingModel.embed(query);
        
        // 2. 计算相似度
        List<ScoredDocument> scoredDocs = new ArrayList<>();
        for (Document doc : documents) {
            float[] docEmbedding = embeddingCache.get(doc.getId());
            double similarity = cosineSimilarity(queryEmbedding, docEmbedding);
            scoredDocs.add(new ScoredDocument(doc, similarity));
        }
        
        // 3. 排序并返回 Top-K
        return scoredDocs.stream()
            .sorted(Comparator.comparingDouble(ScoredDocument::score).reversed())
            .limit(topK)
            .map(ScoredDocument::document)
            .toList();
    }
    
    private double cosineSimilarity(float[] a, float[] b) {
        double dotProduct = 0.0;
        double normA = 0.0;
        double normB = 0.0;
        
        for (int i = 0; i < a.length; i++) {
            dotProduct += a[i] * b[i];
            normA += a[i] * a[i];
            normB += b[i] * b[i];
        }
        
        return dotProduct / (Math.sqrt(normA) * Math.sqrt(normB));
    }
    
    private record ScoredDocument(Document document, double score) {}
}

// 使用示例
List<Document> results = searchService.search("如何使用 Spring AI?", 5);
```

### 8.4 文本聚类示例

```java
@Service
public class TextClusteringService {
    
    private final EmbeddingModel embeddingModel;
    
    public Map<Integer, List<String>> clusterTexts(
            List<String> texts, 
            int numClusters) {
        
        // 1. 嵌入所有文本
        List<float[]> embeddings = embeddingModel.embed(texts);
        
        // 2. K-means 聚类
        KMeansPlusPlusClusterer<DoublePoint> clusterer = 
            new KMeansPlusPlusClusterer<>(numClusters);
        
        List<DoublePoint> points = embeddings.stream()
            .map(e -> new DoublePoint(toDoubleArray(e)))
            .toList();
        
        List<CentroidCluster<DoublePoint>> clusters = 
            clusterer.cluster(points);
        
        // 3. 整理结果
        Map<Integer, List<String>> result = new HashMap<>();
        for (int i = 0; i < clusters.size(); i++) {
            List<String> clusterTexts = new ArrayList<>();
            for (DoublePoint point : clusters.get(i).getPoints()) {
                int idx = points.indexOf(point);
                clusterTexts.add(texts.get(idx));
            }
            result.put(i, clusterTexts);
        }
        
        return result;
    }
    
    private double[] toDoubleArray(float[] floats) {
        double[] doubles = new double[floats.length];
        for (int i = 0; i < floats.length; i++) {
            doubles[i] = floats[i];
        }
        return doubles;
    }
}
```

```java
@RestController
@RequestMapping("/api/embeddings")
public class EmbeddingController {
    
    private final EmbeddingModel embeddingModel;
    
    @PostMapping("/embed")
    public EmbeddingResult embedTexts(@RequestBody EmbeddingRequest request) {
        // 嵌入文本
        EmbeddingResponse response = embeddingModel.embedForResponse(
            request.getTexts()
        );
        
        // 构建结果
        List<VectorResult> vectors = response.getResults().stream()
            .map(e -> new VectorResult(
                e.getIndex(),
                e.getOutput(),
                e.getOutput().length
            ))
            .toList();
        
        return new EmbeddingResult(
            vectors,
            response.getMetadata().getModel(),
            response.getMetadata().getUsage().getTotalTokens()
        );
    }
    
    @PostMapping("/similarity")
    public SimilarityResult calculateSimilarity(
            @RequestBody SimilarityRequest request) {
        
        // 嵌入两个文本
        float[] embedding1 = embeddingModel.embed(request.getText1());
        float[] embedding2 = embeddingModel.embed(request.getText2());
        
        // 计算余弦相似度
        double similarity = cosineSimilarity(embedding1, embedding2);
        
        return new SimilarityResult(
            request.getText1(),
            request.getText2(),
            similarity
        );
    }
}
```

## 十、注意事项与FAQ

### 10.1 注意事项

| 注意事项 | 说明 |
|---------|------|
| **文本长度限制** | 单个文本不超过 2048 tokens |
| **批量大小** | 建议每次不超过 25 个文本 |
| **向量存储** | 大量向量需要专用向量数据库 |
| **相似度计算** | 推荐使用余弦相似度 |
| **缓存策略** | 相同文本应缓存嵌入结果 |
| **维度一致性** | 同一应用保持维度一致 |

### 10.2 常见问题

**Q1: 嵌入的向量可以用于其他模型吗？**
```
A: 不建议。不同模型的向量空间不兼容，
   应该使用相同模型的嵌入进行比较。
```

**Q2: 如何选择合适的维度？**
```
A: 
- 512维：快速原型、大规模数据
- 1024维：通用场景（推荐）
- 1536维：高精度要求
```

**Q3: query 和 document 有什么区别？**
```
A: 
- query：短文本，搜索查询
- document：长文本，文档内容
使用正确的类型可以提高检索准确性。
```

**Q4: 如何计算相似度？**
```
A: 推荐使用余弦相似度：
cos_sim = dot(a, b) / (norm(a) * norm(b))

范围：[-1, 1]
- 1：完全相同
- 0：无关
- -1：完全相反
```

**Q5: 向量维度可以动态修改吗？**
```
A: 不建议。已存储的向量维度改变后无法直接比较，
   需要重新嵌入所有文档。
```
