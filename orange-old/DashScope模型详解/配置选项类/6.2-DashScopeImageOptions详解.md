## 一、类概述

### 1.1 设计目的

`DashScopeImageOptions` 实现了Spring AI的`ImageOptions`接口，用于配置DashScope图像生成模型的参数，支持文本生成图像(T2I)、图像编辑、风格迁移等功能。

### 1.2 完整定义

```java
@JsonInclude(JsonInclude.Include.NON_NULL)
public class DashScopeImageOptions implements ImageOptions {
    
    // 基础参数
    private String model;              // 模型名称
    private Integer n;                 // 生成数量
    private Integer width;             // 宽度
    private Integer height;            // 高度
    private String size;               // 尺寸（自动计算）
    
    // 风格控制
    private String style;              // 风格
    private Integer seed;              // 随机种子
    
    // 参考图像
    private String refImg;             // 参考图像URL
    private Float refStrength;         // 参考强度
    private String refMode;            // 参考模式
    
    // 高级功能
    private String negativePrompt;     // 反向提示词
    private Boolean promptExtend;      // Prompt扩展
    private Boolean watermark;         // 水印
    private String responseFormat;     // 输出格式
    
    // 图像编辑
    private String function;           // 功能模式
    private String baseImageUrl;       // 基础图像
    private String maskImageUrl;       // 遮罩图像
    private String sketchImageUrl;     // 草图
    private Integer sketchWeight;      // 草图权重
    private Boolean sketchExtraction;  // 草图提取
    private Integer[][] sketchColor;   // 草图颜色
    private Integer[][] maskColor;     // 遮罩颜色
}
```

### 1.3 图像生成模式

```
模式1: 文本生成图像 (T2I)
prompt → AI生成 → 图像

模式2: 参考图像生成
refImg + prompt → 风格化 → 图像

模式3: 图像编辑
baseImage + mask + prompt → 局部编辑 → 图像

模式4: 草图生成
sketch + prompt → 上色/细化 → 图像
```

## 二、字段详解

### 2.1 model（模型名称）

**类型**：`String`  
**默认值**：`null`  
**必填**：✅ 是

**可用模型**：

| 模型名称 | 特点 | 推荐场景 |
|---------|------|---------|
| **wanx-v1** | 通用文生图 | 通用场景 |
| **wanx-style-repaint-v1** | 风格化 | 艺术创作 |
| **wanx-background-generation-v2** | 背景生成 | 产品拍摄 |
| **wanx-sketch-to-image-v1** | 草图转图像 | 设计草图 |

**使用示例**：
```java
// 通用模型
DashScopeImageOptions options = DashScopeImageOptions.builder()
    .withModel("wanx-v1")
    .build();

// 风格化模型
DashScopeImageOptions options = DashScopeImageOptions.builder()
    .withModel("wanx-style-repaint-v1")
    .build();
```

### 2.2 n（生成数量）

**类型**：`Integer`  
**默认值**：`null`（默认1）  
**必填**：否  
**取值范围**：1-4

**说明**：
- 一次生成多张图像
- 提供更多选择
- 增加成本

**使用示例**：
```java

    .withN(1)
    .build();

// 生成4张（提供更多选择）

    .withN(4)
    .build();
```

### 2.5 seed（随机种子）

**类型**：`Integer`  
**默认值**：`null`（随机）  
**必填**：否  
**取值范围**：0 - 4294967290

**说明**：
- 控制图像生成的随机性
- 相同seed + 相同参数 = 相似图像
- 用于复现效果

**使用场景**：
- 复现特定效果
- 批量生成风格一致的图像
- A/B测试

**使用示例**：
```java
// 随机生成
DashScopeImageOptions options = DashScopeImageOptions.builder()
    // 不设置seed，每次不同
    .build();

// 固定效果
DashScopeImageOptions options = DashScopeImageOptions.builder()
    .withSeed(12345)
    .build();

// 批量生成（风格一致）
for (int i = 0; i < 10; i++) {
    DashScopeImageOptions options = DashScopeImageOptions.builder()
        .withSeed(1000 + i)  // 连续seed
        .build();
}
```

### 2.6 refImg（参考图像URL）

**类型**：`String`  
**默认值**：`null`  
**必填**：参考模式必填

**说明**：
- 提供参考图像进行风格迁移
- 支持JPG、PNG、TIFF、WebP
- 必须是公开可访问的HTTP(S) URL

**使用场景**：
- 风格迁移
- 图像变体
- 保持构图

**使用示例**：
```java
// 风格迁移
DashScopeImageOptions options = DashScopeImageOptions.builder()
    .withModel("wanx-style-repaint-v1")
    .withRefImg("https://example.com/reference.jpg")
    .withRefStrength(0.7f)  // 参考强度
    .build();
```

---

### 2.7 refStrength（参考强度）

**类型**：`Float`  
**默认值**：`null`  
**必填**：否  
**取值范围**：0.0 - 1.0

**说明**：
- 控制参考图像的影响程度
- 0.0：完全忽略参考图像
- 1.0：完全按照参考图像

**取值建议**：

| refStrength | 效果 | 适用场景 |
|------------|------|---------|
| 0.3-0.5 | 弱参考 | 只借鉴风格 |
| 0.5-0.7 | 中度参考 | 保留构图 |
| 0.7-0.9 | 强参考 | 高度相似 |

**使用示例**：
```java
// 弱参考（只借鉴风格）
DashScopeImageOptions options = DashScopeImageOptions.builder()
    .withRefImg("https://example.com/ref.jpg")
    .withRefStrength(0.4f)
    .build();

// 强参考（保持构图）
DashScopeImageOptions options = DashScopeImageOptions.builder()
    .withRefImg("https://example.com/ref.jpg")
    .withRefStrength(0.8f)
    .build();
```

### 2.8 refMode（参考模式）

**默认值**：`null`  
**必填**：否

**可选值**：

```java
// 仅参考模式

    .withRefImg("https://example.com/ref.jpg")
    .withRefMode("refonly")
    .build();
```

### 2.9 negativePrompt（反向提示词）

**类型**：`String`  
**默认值**：`null`  
**必填**：否

**说明**：
- 描述不想在图像中出现的内容
- 提高生成质量
- 避免常见问题

**常用反向提示词**：
```
质量问题：
- 模糊、低分辨率、噪点
- 变形、扭曲、失真
- 多余的手指、肢体

内容问题：
- 文字、水印、logo
- 丑陋、恐怖
- 色情、暴力

风格问题：
- 卡通（如果要写实）
- 3D渲染（如果要2D）
```

**使用示例**：
```java
// 基础过滤
DashScopeImageOptions options = DashScopeImageOptions.builder()
    .withNegativePrompt("模糊,低质量,变形")
    .build();

// 详细过滤
DashScopeImageOptions options = DashScopeImageOptions.builder()
    .withNegativePrompt("模糊,低分辨率,噪点,变形,扭曲," +
                       "多余的手指,文字,水印,丑陋")
    .build();

// 风格控制
DashScopeImageOptions options = DashScopeImageOptions.builder()
    .withStyle("photography")
    .withNegativePrompt("卡通,动漫,3D渲染,插画")
    .build();
```

### 2.10 promptExtend（Prompt扩展）

**类型**：`Boolean`  
**默认值**：`null`（默认false）  
**必填**：否

**说明**：
- 启用后AI自动扩展prompt
- 添加更多细节描述
- 提高生成质量

**对比示例**：
```
原始Prompt：
"一只猫"

promptExtend = false:
生成：基于简单描述的猫

promptExtend = true:
AI扩展为："一只可爱的橘色猫咪，
毛茸茸的，大眼睛，
坐在阳光下，
高清，细节丰富"
生成：更精致的猫咪图像
```

**使用示例**：
```java
// 不扩展（精确控制）
DashScopeImageOptions options = DashScopeImageOptions.builder()
    .withPromptExtend(false)
    .build();

// 自动扩展（推荐）
DashScopeImageOptions options = DashScopeImageOptions.builder()
    .withPromptExtend(true)
    .build();
```

### 2.13 图像编辑字段

#### function（功能模式）

**可选值**：
- **generation**：生成（默认）
- **inpainting**：局部重绘
- **outpainting**：外延扩展

#### baseImageUrl（基础图像）

**说明**：需要编辑的原始图像URL

#### maskImageUrl（遮罩图像）

**说明**：指定编辑区域的遮罩图像

#### sketchImageUrl（草图）

**说明**：草图转图像的输入草图

#### sketchWeight（草图权重）

**取值范围**：0-100，控制草图的影响程度

**使用示例**：
```java
// 局部重绘（Inpainting）
DashScopeImageOptions options = DashScopeImageOptions.builder()
    .withFunction("inpainting")
    .withBaseImageUrl("https://example.com/base.jpg")
    .withMaskImageUrl("https://example.com/mask.jpg")
    .build();

// 草图转图像
DashScopeImageOptions options = DashScopeImageOptions.builder()
    .withModel("wanx-sketch-to-image-v1")
    .withSketchImageUrl("https://example.com/sketch.jpg")
    .withSketchWeight(80)
    .build();
```

### 3.6 批量生成（系列图像）

```java
public class BatchImageGenerator {
    
    /**
     * 生成系列图像
     */
    public List<String> generateSeries(
            List<String> prompts,
            String style) {
        
        List<String> imageUrls = new ArrayList<>();
        int baseSeed = 1000;
        
        for (int i = 0; i < prompts.size(); i++) {
            DashScopeImageOptions options = 
                DashScopeImageOptions.builder()
                    .withModel("wanx-v1")
                    .withStyle(style)
                    .withSeed(baseSeed + i)  // 连续seed
                    .withWidth(1024)
                    .withHeight(1024)
                    .withPromptExtend(true)
                    .build();
            
            ImageResponse response = imageModel.call(
                new ImagePrompt(prompts.get(i), options)
            );
            
            imageUrls.add(response.getResult().getOutput().getUrl());
        }
        
        return imageUrls;
    }
}

// 使用
List<String> prompts = List.of(
    "春天的樱花盛开",
    "夏日的海边度假",
    "秋天的枫叶红了",
    "冬季的雪景"
);

List<String> images = generator.generateSeries(prompts, "photography");
```

### 4.2 Prompt优化

```java
public class ImagePromptOptimizer {
    
    /**
     * 优化prompt
     */
    public String optimize(String basicPrompt, String style) {
        StringBuilder optimized = new StringBuilder(basicPrompt);
        
        // 根据风格添加关键词
        switch (style) {
            case "photography":
                optimized.append(", 专业摄影, 高清, 细节丰富");
                break;
            case "anime":
                optimized.append(", 精美插画, 细致, 色彩鲜艳");
                break;
            case "oil painting":
                optimized.append(", 油画质感, 笔触清晰, 色彩浓郁");
                break;
        }
        
        return optimized.toString();
    }
    
    /**
     * 生成反向提示词
     */
    public String generateNegativePrompt(String style) {
        String base = "模糊,低质量,噪点,变形,扭曲";
        
        if (style.equals("photography")) {
            return base + ",卡通,动漫,插画,3D";
        } else if (style.equals("anime")) {
            return base + ",写实,照片,真人";
        }
        
        return base;
    }
}
```

```java
     */
    public boolean checkQuality(ImageResponse response) {
        if (response == null || response.getResult() == null) {
            return false;
        }
        
        String url = response.getResult().getOutput().getUrl();
        if (url == null || url.isEmpty()) {
            return false;
        }
        
        // 检查URL可访问性
        try {
            HttpURLConnection connection = 
                (HttpURLConnection) new URL(url).openConnection();
            connection.setRequestMethod("HEAD");
            int code = connection.getResponseCode();
            return code == 200;
        } catch (Exception e) {
            return false;
        }
    }
}
```
