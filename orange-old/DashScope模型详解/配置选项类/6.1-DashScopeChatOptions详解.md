## 一、类概述

### 1.1 设计目的

`DashScopeChatOptions` 是Spring AI `ChatOptions`和`ToolCallingChatOptions`接口的完整实现，提供了DashScope对话模型的所有配置参数，包括基础参数、采样控制、工具调用、联网搜索、多模态、思维链等高级功能。

### 1.2 完整字段列表（25+）

```java
@JsonInclude(JsonInclude.Include.NON_NULL)
public class DashScopeChatOptions implements ToolCallingChatOptions {
    
    // 基础参数
    private String model;                    // 模型名称
    private Boolean stream;                  // 流式输出
    private Integer maxTokens;               // 最大Token数
    
    // 采样参数
    private Double temperature;              // 温度
    private Integer seed;                    // 随机种子
    private Double topP;                     // 核采样
    private Integer topK;                    // Top-K采样
    private List<Object> stop;               // 停止词
    private Double repetitionPenalty;        // 重复惩罚
    
    // 输出控制
    private Boolean incrementalOutput;       // 增量输出
    private DashScopeResponseFormat responseFormat; // 响应格式
    
    // 搜索功能
    private Boolean enableSearch;            // 启用搜索
    private SearchOptions searchOptions;     // 搜索选项
    
    // 工具调用
    private List<FunctionTool> tools;        // 工具列表
    private Object toolChoice;               // 工具选择
    private Boolean parallelToolCalls;       // 并行工具调用
    private List<ToolCallback> toolCallbacks; // 工具回调
    private Set<String> toolNames;           // 工具名称
    private Boolean internalToolExecutionEnabled; // 内部工具执行
    private Map<String,Object> toolContext;  // 工具上下文
    
    // 多模态
    private Boolean vlHighResolutionImages;  // 高分辨率图像
    private Boolean multiModel;              // 多模型
    
    // 思维链
    private Boolean enableThinking;          // 启用思维
    private Integer thinkingBudget;          // 思维预算
    
    // HTTP配置
    private Map<String, String> httpHeaders; // HTTP头
}
```

## 二、基础参数

### 2.1 model（模型名称）

**类型**：`String`  
**默认值**：`null`  
**必填**：✅ 是

**可用模型**：

| 模型系列 | 模型名称 | 特点 | 推荐场景 |
|---------|---------|------|---------|
| **Qwen-Plus** | qwen-plus | 平衡性能 | 通用对话 |
| **Qwen-Turbo** | qwen-turbo | 快速响应 | 高并发场景 |
| **Qwen-Max** | qwen-max | 最强性能 | 复杂任务 |
| **Qwen-VL-Max** | qwen-vl-max | 多模态 | 图文理解 |
| **Qwen2.5系列** | qwen2.5-72b-instruct | 最新版 | 最佳质量 |

**使用示例**：
```java
// 通用模型
DashScopeChatOptions options = DashScopeChatOptions.builder()
    .withModel("qwen-plus")
    .build();

// 多模态模型
DashScopeChatOptions options = DashScopeChatOptions.builder()
    .withModel("qwen-vl-max")
    .build();
```

---

### 2.2 stream（流式输出）

**类型**：`Boolean`  
**默认值**：`null`（由调用方法决定）  
**必填**：否

**说明**：
- `true`：流式返回（实时输出）
- `false`：一次性返回完整结果
- 通常由`call()`和`stream()`方法自动设置

**使用示例**：
```java
// 同步调用（自动设置stream=false）
ChatResponse response = chatModel.call(prompt);

// 流式调用（自动设置stream=true）
Flux<ChatResponse> stream = chatModel.stream(prompt);
```

---

### 2.3 maxTokens（最大Token数）

**类型**：`Integer`  
**默认值**：`null`（模型默认）  
**必填**：否

**说明**：
- 限制单次回复的最大Token数
- 用于控制成本和响应长度
- 不同模型有不同上限

**取值建议**：

| 场景 | 推荐maxTokens | 说明 |
|------|--------------|------|
| 简单问答 | 500-1000 | 简短回复 |
| 一般对话 | 1500-2000 | 标准回复 |
| 长文本生成 | 4000-6000 | 文章、报告 |
| 无限制 | 不设置 | 使用模型默认 |

**使用示例**：
```java
// 限制为1000 tokens
DashScopeChatOptions options = DashScopeChatOptions.builder()
    .withModel("qwen-plus")
    .withMaxToken(1000)
    .build();

// 长文本生成
DashScopeChatOptions options = DashScopeChatOptions.builder()
    .withModel("qwen-plus")
    .withMaxToken(4000)
    .build();
```

## 三、采样参数

### 3.1 temperature（温度）

**类型**：`Double`  
**默认值**：`0.85`（系统默认）  
**必填**：否  
**取值范围**：[0, 2)

**说明**：
- 控制输出的随机性和创造性
- 0：确定性最强，每次输出几乎相同
- 接近2：随机性最强，输出更有创意
- **不建议设置为0**

**取值指南**：

| temperature | 特点 | 适用场景 |
|------------|------|---------|
| 0.1-0.3 | 非常确定 | 事实问答、数据提取 |
| 0.5-0.7 | 较确定 | 客服、翻译 |
| 0.8-1.0 | 平衡 | 通用对话（推荐） |
| 1.0-1.5 | 较创意 | 创意写作、头脑风暴 |
| 1.5-2.0 | 非常创意 | 艺术创作、故事生成 |

**使用示例**：
```java
// 事实问答（低温度）
DashScopeChatOptions options = DashScopeChatOptions.builder()
    .withModel("qwen-plus")
    .withTemperature(0.3)
    .build();

// 创意写作（高温度）
DashScopeChatOptions options = DashScopeChatOptions.builder()
    .withModel("qwen-plus")
    .withTemperature(1.2)
    .build();
```

---

### 3.2 seed（随机种子）

**类型**：`Integer`  
**默认值**：`null`（随机）  
**必填**：否  
**取值范围**：无符号64位整数

**说明**：
- 控制生成的可复现性
- 相同seed + 相同参数 ≈ 相似结果
- 注意：**不保证完全相同**

**使用场景**：
- 测试和调试
- A/B测试
- 需要一致性的场景

**使用示例**：
```java
// 可复现的结果
DashScopeChatOptions options = DashScopeChatOptions.builder()
    .withModel("qwen-plus")
    .withSeed(12345)
    .withTemperature(0.7)
    .build();
```

---

### 3.3 topP（核采样）

**类型**：`Double`  
**默认值**：`0.8`  
**必填**：否  
**取值范围**：(0, 1.0)

**说明**：
- 核采样阈值
- 只考虑累积概率达到topP的Token
- topP=0.8表示考虑累积概率前80%的Token

**与temperature的关系**：
- temperature控制分布平滑度
- topP控制候选范围
- 通常只调整一个，另一个用默认值

**使用示例**：
```java
// 更确定的输出
DashScopeChatOptions options = DashScopeChatOptions.builder()
    .withModel("qwen-plus")
    .withTopP(0.5)  // 只考虑前50%
    .build();

// 更多样的输出
DashScopeChatOptions options = DashScopeChatOptions.builder()
    .withModel("qwen-plus")
    .withTopP(0.95)  // 考虑前95%
    .build();
```

---

### 3.4 topK（Top-K采样）

**类型**：`Integer`  
**默认值**：`null`（禁用）  
**必填**：否

**说明**：
- 采样候选池大小
- topK=50表示只从分数最高的50个Token中采样
- topK > 100或null时禁用，只使用topP

**使用示例**：
```java
// 启用Top-K
DashScopeChatOptions options = DashScopeChatOptions.builder()
    .withModel("qwen-plus")
    .withTopK(50)
    .build();
```

---

### 3.5 repetitionPenalty（重复惩罚）

**类型**：`Double`  
**默认值**：`1.1`  
**必填**：否

**说明**：
- 控制内容重复度
- 1.0：无惩罚
- >1.0：惩罚重复，值越大惩罚越强

**使用示例**：
```java
// 减少重复
DashScopeChatOptions options = DashScopeChatOptions.builder()
    .withModel("qwen-plus")
    .withRepetitionPenalty(1.2)
    .build();
```

---

### 3.6 stop（停止词）

**类型**：`List<Object>`  
**默认值**：`null`  
**必填**：否

**说明**：
- 遇到停止词时自动停止生成
- 支持字符串或Token ID数组
- **注意**：生成内容不包含停止词

**使用示例**：
```java
// 字符串停止词
DashScopeChatOptions options = DashScopeChatOptions.builder()
    .withModel("qwen-plus")
    .withStop(List.of("结束", "完毕"))
    .build();

// Token ID停止词
DashScopeChatOptions options = DashScopeChatOptions.builder()
    .withModel("qwen-plus")
    .withStop(List.of(37763, 367))  // "Observation"的Token IDs
    .build();
```

## 四、工具调用

### 4.1 tools（工具列表）

**类型**：`List<FunctionTool>`

**必填**：Function Calling时必填

- 定义模型可以调用的工具（函数）

    .build();

---

### 4.2 toolChoice（工具选择策略）

**类型**：`Object`  
**默认值**：`"auto"`（tools非空时）  
**必填**：否

**可选值**：
- **"none"**：不调用任何工具
- **"auto"**：模型自动决定（默认）
- **对象**：指定调用特定工具

**使用示例**：
```java

DashScopeChatOptions options = DashScopeChatOptions.builder()
    .withModel("qwen-plus")
    .withTools(tools)
    .withToolChoice("auto")
    .build();

// 不调用工具
DashScopeChatOptions options = DashScopeChatOptions.builder()
    .withModel("qwen-plus")
    .withTools(tools)
    .withToolChoice("none")
    .build();

// 指定工具
Map<String, Object> toolChoice = Map.of(
    "type", "function",
    "function", Map.of("name", "get_weather")
);

DashScopeChatOptions options = DashScopeChatOptions.builder()
    .withModel("qwen-plus")
    .withTools(tools)
    .withToolChoice(toolChoice)
    .build();
```

---

### 4.3 parallelToolCalls（并行工具调用）

**类型**：`Boolean`  
**默认值**：`null`（默认false）  
**必填**：否

**说明**：
- `true`：允许一次调用多个工具
- `false`：每次只调用一个工具

**使用示例**：
```java

### 5.3 incrementalOutput（增量输出）

**类型**：`Boolean`  
**默认值**：`true`  
**必填**：否

**说明**：
- 控制流式输出的模式
- `true`：增量输出（每次只返回新增部分）
- `false`：全量输出（每次返回完整内容）
- 只在stream=true时生效

**对比示例**：
```
incrementalOutput = true（增量）：
"今" → "天" → "天" → "气" → "很" → "好"
需要累积：result = "今天天气很好"

incrementalOutput = false（全量）：
"今" → "今天" → "今天天" → "今天天气" → "今天天气很" → "今天天气很好"
直接取最后：result = "今天天气很好"
```

**使用示例**：
```java
// 增量输出（默认，需要累积）
DashScopeChatOptions options = DashScopeChatOptions.builder()
    .withModel("qwen-plus")
    .withIncrementalOutput(true)
    .build();

// 全量输出（每次都是完整的）
DashScopeChatOptions options = DashScopeChatOptions.builder()
    .withModel("qwen-plus")
    .withIncrementalOutput(false)
    .build();
```

## 七、最佳实践

### 7.1 场景配置预设

```java
public class ChatPresets {
    
    /**
     * 通用对话
     */
    public static DashScopeChatOptions general() {
        return DashScopeChatOptions.builder()
            .withModel("qwen-plus")

## 八、注意事项

### 8.1 关键注意事项

| 注意事项 | 说明 |
|---------|------|
| **参数优先级** | 运行时选项 > 实例选项 |

| **incrementalOutput** | 影响流式输出处理方式 |
| **enableThinking** | 只适用于Qwen3系列 |
| **vlHighResolutionImages** | 只适用于VL模型 |

### 8.2 常见问题

**Q1: temperature和topP如何选择？**
```
通常只调整一个：
- 调temperature：简单直观（推荐）
- 调topP：更精细控制

不要同时大幅调整
```

**Q2: 如何提高回复的确定性？**
```
1. 降低temperature（0.1-0.3）
2. 设置seed
3. 降低topP（0.5-0.7）
```

**Q3: Function Calling最小配置？**
```java
.withTools(tools)
.withToolCallbacks(callbacks)
.withInternalToolExecutionEnabled(true)
```

**Q4: 流式输出如何累积？**
```
incrementalOutput=true时需要手动累积：
StringBuilder result = new StringBuilder();
stream.subscribe(chunk -> {
    result.append(chunk.getText());
});
```

**Q5: 如何限制成本？**
```
1. 设置maxTokens
2. 使用turbo模型
3. 降低temperature（减少重试）
4. 合理使用stop词
```
