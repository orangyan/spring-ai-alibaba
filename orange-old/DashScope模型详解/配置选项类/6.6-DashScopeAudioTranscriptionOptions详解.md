## 一、类概述

### 1.1 设计目的

`DashScopeAudioTranscriptionOptions` 实现了`AudioTranscriptionOptions`接口，用于配置DashScope的语音识别(ASR)参数，包括热词、采样率、音频格式、语言提示等。

### 1.2 完整定义

```java
public class DashScopeAudioTranscriptionOptions implements AudioTranscriptionOptions {
    
    private String model = "paraformer-v2";           // 模型名称
    private String vocabularyId;                      // 热词表ID
    private String phraseId;                          // 短语ID
    private Integer sampleRate;                       // 采样率
    private AudioFormat format;                       // 音频格式
    private List<Integer> channelId = List.of(0);    // 声道ID
    private Boolean disfluencyRemovalEnabled = false; // 去除口语化
    private List<String> languageHints = List.of("zh", "en"); // 语言提示
}
```

### 1.3 ASR工作流程

```
音频输入
    ↓
预处理（降噪、归一化）
    ↓
特征提取（MFCC/Fbank）
    ↓
声学模型（识别音素）
    ↓
语言模型（组合成词）
    ↓
后处理（标点、热词）
    ↓
文本输出
```

## 二、字段详解

### 2.1 model（模型名称）

**类型**：`String`  
**默认值**：`"paraformer-v2"`  
**必填**：否（有默认值）

**可用模型**：

| 模型名称 | 语言 | 特点 | 推荐场景 |
|---------|------|------|---------|
| **paraformer-v2** | 中英文 | 高精度，支持实时 | 通用场景（推荐） |
| **paraformer-realtime-v2** | 中英文 | 低延迟，流式 | 实时对话、会议 |
| **paraformer-8k-v1** | 中文 | 电话音质优化 | 客服、电话录音 |

**使用示例**：
```java
// 使用默认模型（通用）
DashScopeAudioTranscriptionOptions options = 
    DashScopeAudioTranscriptionOptions.builder()
        .withModel("paraformer-v2")
        .build();

// 实时场景
DashScopeAudioTranscriptionOptions options = 
    DashScopeAudioTranscriptionOptions.builder()
        .withModel("paraformer-realtime-v2")
        .build();

// 电话场景
DashScopeAudioTranscriptionOptions options = 
    DashScopeAudioTranscriptionOptions.builder()
        .withModel("paraformer-8k-v1")
        .withSampleRate(8000)
        .build();
```

### 2.2 vocabularyId（热词表ID）

**类型**：`String`  
**默认值**：`null`  
**必填**：否

**说明**：
- 热词表用于提高特定词汇的识别准确率
- 需要在百炼平台预先创建热词表
- 适用于专业术语、人名、地名等

**使用场景**：
- 医疗：病名、药名
- 金融：专业术语
- 教育：人名、课程名
- 企业：产品名、人名

**创建热词表**：
1. 登录阿里云百炼平台
2. 进入ASR服务
3. 创建热词表，添加词汇
4. 获取vocabularyId

**使用示例**：
```java
// 医疗场景热词
DashScopeAudioTranscriptionOptions options = 
    DashScopeAudioTranscriptionOptions.builder()
        .withModel("paraformer-v2")
        .withVocabularyId("medical-vocab-001")
        .build();

// 企业场景热词
DashScopeAudioTranscriptionOptions options = 
    DashScopeAudioTranscriptionOptions.builder()
        .withModel("paraformer-v2")
        .withVocabularyId("company-vocab-123")
        .build();
```

**热词表示例**：
```
热词列表（医疗）：
- 阿莫西林
- 头孢克肟
- 布洛芬
- 高血压
- 糖尿病

识别效果：
无热词：阿莫西宁（错误）
有热词：阿莫西林（正确）
```

### 2.4 sampleRate（采样率）

**类型**：`Integer`  
**默认值**：`null`（自动检测）  
**必填**：否

**可选值**：
- **8000**: 电话音质（窄带）
- **16000**: 标准音质（宽带，推荐）
- **48000**: 高清音质（超宽带）

**说明**：
- 必须与实际音频采样率一致
- 不指定时会自动检测
- 不匹配会导致识别失败或质量下降

**使用示例**：
```java
// 标准采样率（推荐）
DashScopeAudioTranscriptionOptions options = 
    DashScopeAudioTranscriptionOptions.builder()
        .withModel("paraformer-v2")
        .withSampleRate(16000)
        .build();

// 电话录音（8kHz）
DashScopeAudioTranscriptionOptions options = 
    DashScopeAudioTranscriptionOptions.builder()
        .withModel("paraformer-8k-v1")
        .withSampleRate(8000)
        .build();

// 高清音频（48kHz）
DashScopeAudioTranscriptionOptions options = 
    DashScopeAudioTranscriptionOptions.builder()
        .withModel("paraformer-v2")
        .withSampleRate(48000)
        .build();
```

### 2.5 format（音频格式）

**类型**：`AudioFormat` 枚举  
**默认值**：`null`（自动检测）  
**必填**：否

**支持格式**：

| 格式 | 说明 | 常见场景 |
|------|------|---------|
| **PCM** | 原始音频流 | 实时录音 |
| **WAV** | 无损音频文件 | 文件识别 |
| **MP3** | 压缩音频 | 网络传输 |
| **OPUS** | 高压缩比 | 低带宽场景 |
| **SPEEX** | 语音优化 | VoIP |
| **AAC** | 高质量压缩 | 移动应用 |
| **AMR** | 低码率 | 移动网络 |

**使用示例**：
```java

DashScopeAudioTranscriptionOptions options = 
    DashScopeAudioTranscriptionOptions.builder()
        .withModel("paraformer-realtime-v2")
        .withFormat(AudioFormat.PCM)
        .withSampleRate(16000)
        .build();

// MP3文件

    DashScopeAudioTranscriptionOptions.builder()
        .withModel("paraformer-v2")
        .withFormat(AudioFormat.MP3)

    DashScopeAudioTranscriptionOptions.builder()
```

### 2.6 channelId（声道ID）

**类型**：`List<Integer>`  
**默认值**：`List.of(0)`（单声道）  
**必填**：否

**说明**：
- 指定要识别的音频声道
- 0表示第一个声道，1表示第二个声道
- 多声道音频可以分别识别

**使用场景**：
- 双声道录音（面试、会议）
- 立体声音频处理
- 多人对话识别

**使用示例**：
```java
// 单声道（默认）
DashScopeAudioTranscriptionOptions options = 
    DashScopeAudioTranscriptionOptions.builder()
        .withModel("paraformer-v2")
        .withChannelId(List.of(0))
        .build();

// 双声道（分别识别）
DashScopeAudioTranscriptionOptions options = 
    DashScopeAudioTranscriptionOptions.builder()
        .withModel("paraformer-v2")
        .withChannelId(List.of(0, 1))  // 两个声道都识别
        .build();

// 只识别右声道
DashScopeAudioTranscriptionOptions options = 
    DashScopeAudioTranscriptionOptions.builder()
        .withModel("paraformer-v2")
        .withChannelId(List.of(1))
        .build();
```

### 2.7 disfluencyRemovalEnabled（去除口语化）

**类型**：`Boolean`  
**默认值**：`false`  
**必填**：否

**说明**：
- 启用后会去除口语中的冗余词汇
- 包括"嗯"、"啊"、"那个"等语气词
- 使识别结果更加简洁

**对比示例**：
```
原始语音：
"嗯，那个，我想，嗯，预约明天的，嗯，体检"

disfluencyRemovalEnabled = false（默认）：
"嗯，那个，我想，嗯，预约明天的，嗯，体检"

disfluencyRemovalEnabled = true：
"我想预约明天的体检"
```

**使用场景**：
- 会议记录
- 客服对话记录
- 字幕生成
- 文档整理

**使用示例**：
```java
// 保留口语化（默认）
DashScopeAudioTranscriptionOptions options = 
    DashScopeAudioTranscriptionOptions.builder()
        .withModel("paraformer-v2")
        .withDisfluencyRemovalEnabled(false)
        .build();

// 去除口语化（推荐用于文档）
DashScopeAudioTranscriptionOptions options = 
    DashScopeAudioTranscriptionOptions.builder()
        .withModel("paraformer-v2")
        .withDisfluencyRemovalEnabled(true)
        .build();
```

### 4.4 识别质量评估

```java
public class TranscriptionQualityChecker {
    
    /**
     * 评估识别质量
     */
    public double evaluateQuality(String transcription) {
        double score = 100.0;
        
        // 1. 检查空结果
        if (transcription == null || transcription.isEmpty()) {
            return 0.0;
        }
        
        // 2. 检查异常字符
        if (containsGarbledText(transcription)) {
            score -= 30;
        }
        
        // 3. 检查重复
        if (hasExcessiveRepetition(transcription)) {
            score -= 20;
        }
        
        // 4. 检查长度合理性
        if (transcription.length() < 10) {
            score -= 10;
        }
        
        return Math.max(0, score);
    }
    
    private boolean containsGarbledText(String text) {
        // 检查是否包含乱码
        return text.matches(".*[\\x00-\\x08\\x0B-\\x0C\\x0E-\\x1F].*");
    }
}
```

## 五、注意事项

### 5.1 关键注意事项

| 注意事项 | 说明 |
|---------|------|
| **采样率匹配** | 必须与实际音频采样率一致 |
| **格式支持** | 不同模型支持的格式可能不同 |
| **热词限制** | 每个热词表最多1000个词 |
| **音频时长** | 单次识别最长60分钟 |
| **实时延迟** | 实时模式延迟约200-500ms |
| **多声道** | 双声道文件可能需要分别识别 |

### 5.2 常见问题

**Q1: 如何提高识别准确率？**
```
1. 使用热词表（vocabularyId）
2. 确保音频质量（降噪、清晰）
3. 匹配正确的采样率和格式
4. 启用语言提示（languageHints）
5. 选择合适的模型
```

**Q2: 电话录音识别质量差怎么办？**
```
1. 使用paraformer-8k-v1模型
2. 设置采样率为8000
3. 启用去除口语化
4. 添加客服场景热词
```

**Q3: 实时识别延迟高怎么优化？**
```
1. 使用paraformer-realtime-v2
2. 使用PCM格式（无需解码）
3. 设置合适的分片大小（200-400ms）
4. 优化网络连接
```

**Q4: 如何处理多人对话？**
```
方案1：双声道录音，分声道识别
方案2：使用声纹识别+ASR
方案3：基于时间戳切分音频

推荐：双声道 + channelId
```

**Q5: 热词不生效怎么办？**
```
检查：
1. vocabularyId是否正确
2. 热词是否在词表中
3. 音频质量是否足够清晰
4. 热词发音是否标准
```

**Q6: disfluencyRemovalEnabled什么时候用？**
```
适用场景：
- ✅ 会议记录
- ✅ 文档整理
- ✅ 字幕生成
- ❌ 法律取证（需保留原始内容）
- ❌ 情感分析（语气词有意义）
```
