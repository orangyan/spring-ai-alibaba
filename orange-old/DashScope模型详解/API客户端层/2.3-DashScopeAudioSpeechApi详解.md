## 一、类概述

### 1.1 设计目的

`DashScopeAudioSpeechApi` 是专门用于语音合成（TTS）服务的WebSocket客户端，负责与阿里云百炼的语音合成API进行实时流式通信。它是 `DashScopeAudioSpeechModel` 的底层支持。

### 1.2 核心职责

```
┌─────────────────────────────────────┐
│  DashScopeAudioSpeechModel          │
│   (语音合成模型)                     │
└──────────────┬──────────────────────┘
               │
               ↓
┌─────────────────────────────────────┐
│  DashScopeAudioSpeechApi (本类)     │ ← 本文档介绍的核心
│  - WebSocket流式通信                 │
│  - 实时音频流输出                    │
│  - 请求构建与发送                    │
└──────────────┬──────────────────────┘
               │
               ↓
┌─────────────────────────────────────┐
│  DashScopeWebSocketClient           │
│  (WebSocket底层客户端)               │
└──────────────┬──────────────────────┘
               │
               ↓
┌─────────────────────────────────────┐
│  DashScope TTS Service              │
│  (阿里云百炼语音合成服务)            │
└─────────────────────────────────────┘
```

### 1.3 核心特性

| 特性 | 说明 |
|------|------|
| **WebSocket通信** | 基于WebSocket的实时双向通信 |
| **流式输出** | 实时返回音频数据流（ByteBuffer） |
| **多种音色** | 支持6种预定义音色 |
| **多种格式** | PCM/WAV/MP3格式支持 |
| **时间戳支持** | 可获取音素和单词级时间戳 |
| **低延迟** | 首包延迟低，适合实时场景 |

## 三、核心功能

### 3.1 流式音频输出

**方法签名**：
```java
public Flux<ByteBuffer> streamOut(Request request)
```

**功能**：将文本转换为音频，实时流式返回音频数据

**实现逻辑**：
```java
public Flux<ByteBuffer> streamOut(Request request) {
    try {
        // 1. 将请求对象序列化为JSON
        String message = (new ObjectMapper()).writeValueAsString(request);
        
        // 2. 通过WebSocket发送请求，并接收二进制流
        return this.webSocketClient.streamBinaryOut(message);
    }
    catch (JsonProcessingException e) {
        throw new RuntimeException(e);
    }
}
```

**关键点**：
- 输入：Request对象（包含文本和参数）
- 输出：`Flux<ByteBuffer>`（音频数据流）
- 通信：通过WebSocket发送文本，接收二进制音频

**WebSocket通信流程**：
```
1. 客户端发送JSON请求（文本 + 参数）
   ↓
2. 服务端接收请求，开始语音合成
   ↓
3. 服务端实时推送音频数据块（ByteBuffer）
   ↓
4. 客户端接收并处理音频流
   ↓
5. 完成后关闭流
```

## 五、使用示例

### 5.1 基础语音合成

```java
// 创建API实例
DashScopeAudioSpeechApi api = new DashScopeAudioSpeechApi("your-api-key");

// 构建请求
DashScopeAudioSpeechApi.Request request = new DashScopeAudioSpeechApi.Request(
    new DashScopeAudioSpeechApi.Request.RequestHeader(
        "run-task",
        UUID.randomUUID().toString(),
        "out"
    ),
    new DashScopeAudioSpeechApi.Request.RequestPayload(
        "sambert-zhichu-v1",  // 模型
        "audio",              // taskGroup
        "tts",                // task
        "SpeechSynthesizer",  // function
        new DashScopeAudioSpeechApi.Request.RequestPayload.RequestPayloadInput(
            "你好，欢迎使用Spring AI Alibaba语音合成功能！"  // 文本
        ),
        new DashScopeAudioSpeechApi.Request.RequestPayload.RequestPayloadParameters(
            50,          // volume
            "PlainText", // textType
            "zhixiaoxia", // voice
            16000,       // sampleRate
            1.0f,        // rate
            "pcm",       // format
            0.0,         // pitch
            false,       // phonemeTimestampEnabled
            false        // wordTimestampEnabled
        )
    )
);

// 执行流式合成
Flux<ByteBuffer> audioStream = api.streamOut(request);

// 订阅并保存音频
List<ByteBuffer> audioChunks = new ArrayList<>();
audioStream.subscribe(
    chunk -> audioChunks.add(chunk),
    error -> System.err.println("合成失败: " + error.getMessage()),
    () -> {
        // 合并所有音频块
        int totalSize = audioChunks.stream()
            .mapToInt(ByteBuffer::remaining)
            .sum();
        
        ByteBuffer combined = ByteBuffer.allocate(totalSize);
        audioChunks.forEach(chunk -> combined.put(chunk));
        combined.flip();
        
        // 保存为文件
        try (FileOutputStream fos = new FileOutputStream("output.pcm")) {
            fos.write(combined.array());
            System.out.println("音频已保存到 output.pcm");
        }
        catch (IOException e) {
            e.printStackTrace();
        }
    }
);
```

### 7.2 常见问题

**Q1: 如何添加WAV文件头？**
```java
public byte[] addWavHeader(byte[] pcmData, int sampleRate, int channels) {
    int totalDataLen = pcmData.length + 36;
    int byteRate = sampleRate * channels * 2;  // 16bit
    
    byte[] header = new byte[44];
    
    // RIFF header
    header[0] = 'R'; header[1] = 'I'; header[2] = 'F'; header[3] = 'F';
    // File size
    header[4] = (byte) (totalDataLen & 0xff);
    header[5] = (byte) ((totalDataLen >> 8) & 0xff);
    header[6] = (byte) ((totalDataLen >> 16) & 0xff);
    header[7] = (byte) ((totalDataLen >> 24) & 0xff);
    // WAVE header
    header[8] = 'W'; header[9] = 'A'; header[10] = 'V'; header[11] = 'E';
    // fmt chunk
    header[12] = 'f'; header[13] = 'm'; header[14] = 't'; header[15] = ' ';
    // fmt chunk size (16)
    header[16] = 16; header[17] = 0; header[18] = 0; header[19] = 0;
    // Audio format (1 = PCM)
    header[20] = 1; header[21] = 0;
    // Number of channels
    header[22] = (byte) channels; header[23] = 0;
    // Sample rate
    header[24] = (byte) (sampleRate & 0xff);
    header[25] = (byte) ((sampleRate >> 8) & 0xff);
    header[26] = (byte) ((sampleRate >> 16) & 0xff);
    header[27] = (byte) ((sampleRate >> 24) & 0xff);
    // Byte rate
    header[28] = (byte) (byteRate & 0xff);
    header[29] = (byte) ((byteRate >> 8) & 0xff);
    header[30] = (byte) ((byteRate >> 16) & 0xff);
    header[31] = (byte) ((byteRate >> 24) & 0xff);
    // Block align
    header[32] = (byte) (channels * 2); header[33] = 0;
    // Bits per sample
    header[34] = 16; header[35] = 0;
    // data chunk
    header[36] = 'd'; header[37] = 'a'; header[38] = 't'; header[39] = 'a';
    // data size
    header[40] = (byte) (pcmData.length & 0xff);
    header[41] = (byte) ((pcmData.length >> 8) & 0xff);
    header[42] = (byte) ((pcmData.length >> 16) & 0xff);
    header[43] = (byte) ((pcmData.length >> 24) & 0xff);
    
    // Combine header and data
    byte[] wavData = new byte[header.length + pcmData.length];
    System.arraycopy(header, 0, wavData, 0, header.length);
    System.arraycopy(pcmData, 0, wavData, header.length, pcmData.length);
    
    return wavData;
}
```

**Q3: 如何实现暂停和恢复？**
```
A: WebSocket流式API不支持暂停/恢复。
   建议：
   1. 缓存音频数据
   2. 在应用层实现暂停/恢复播放
```

**Q4: 支持哪些语言？**
```
A: 主要支持中文。
   英文和其他语言需使用专门的多语言模型。
```

**Q5: 如何减少延迟？**
```
A: 
1. 使用PCM格式（无编码延迟）
2. 降低采样率（8000或16000）
3. 使用就近的WebSocket端点
4. 减少网络跳数
```
