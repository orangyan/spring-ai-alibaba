## 一、类概述

### 1.1 设计目的

`DashScopeAudioTranscriptionApi` 是专门用于语音识别（ASR）服务的双模式客户端，同时支持REST API（异步识别）和WebSocket（实时流式识别）。它是 `DashScopeAudioTranscriptionModel` 的底层支持。

### 1.2 核心职责

```
┌────────────────────────────────────────┐
│  DashScopeAudioTranscriptionModel      │
│   (语音识别模型)                        │
└──────────────┬─────────────────────────┘
               │
               ↓
┌────────────────────────────────────────┐
│  DashScopeAudioTranscriptionApi (本类)  │ ← 本文档介绍的核心
│  ┌──────────────┐  ┌────────────────┐  │
│  │ REST Client  │  │ WebSocket      │  │
│  │ (异步识别)   │  │ (实时识别)     │  │
│  └──────────────┘  └────────────────┘  │
└──────────────┬─────────────────────────┘
               │
               ↓
┌────────────────────────────────────────┐
│  DashScope ASR Service                 │
│  (阿里云百炼语音识别服务)               │
└────────────────────────────────────────┘
```

### 1.3 双模式设计

| 模式 | 通信方式 | 适用场景 | 延迟 | 复杂度 |
|------|---------|----------|------|--------|
| **REST异步** | HTTP + 轮询 | 录音文件识别 | 数秒 | 低 |
| **WebSocket实时** | WebSocket流 | 实时对话 | <1秒 | 中等 |

### 1.4 核心特性

| 特性 | 说明 |
|------|------|
| **双模式通信** | REST + WebSocket |
| **异步任务** | 提交任务 → 轮询结果 |
| **实时流式** | 边说边识别 |
| **热词定制** | 提升特定词汇准确率 |
| **去除口语化** | 自动去除"嗯"、"啊"等 |
| **多语言** | 支持中文、英文等 |
| **详细结果** | 包含时间戳、置信度等 |

### 3.1 REST API - 异步识别

#### 3.1.1 提交识别任务

**方法签名**：
```java
public ResponseEntity<Response> call(Request request)
```

**功能**：提交音频文件识别任务

**实现逻辑**：
```java
public ResponseEntity<Response> call(Request request) {
    return restClient.post()
        .uri(AUDIO_TRANSCRIPTION_RESTFUL_URL)  // /api/v1/services/audio/...
        .body(request)
        .retrieve()
        .toEntity(Response.class);
}
```

**使用场景**：
- 录音文件识别
- 批量识别任务
- 不需要实时反馈

---

#### 3.1.2 查询任务结果

**方法签名**：
```java
public ResponseEntity<Response> callWithTaskId(Request request, String taskId)
```

**功能**：根据taskId查询识别结果

**实现逻辑**：
```java
public ResponseEntity<Response> callWithTaskId(Request request, String taskId) {
    String uri = "/api/v1/tasks/" + taskId;
    return restClient.post()
        .uri(uri)
        .body(request)
        .retrieve()
        .toEntity(Response.class);
}
```

**轮询模式**：
```
1. 调用 call() 提交任务 → 获取taskId
2. 循环调用 callWithTaskId() 查询状态
   - PENDING/RUNNING → 继续等待
   - SUCCEEDED → 获取结果
   - FAILED → 任务失败
3. 从结果URL下载识别文本
```

#### 3.1.3 获取识别结果

**方法签名**：
```java
public Outcome getOutcome(String transcriptionUrl)
```

**功能**：从结果URL下载识别文本

**实现逻辑**：
```java
public Outcome getOutcome(String transcriptionUrl) {
    ObjectMapper objectMapper = new ObjectMapper();
    
    try {
        // 从URL读取JSON
        InputStream inputStream = URI.create(transcriptionUrl).toURL().openStream();
        Outcome outcome = objectMapper.readValue(inputStream, Outcome.class);
        inputStream.close();
        return outcome;
    }
    catch (Exception e) {
        throw new DashScopeException("get transcription outcome failed", e);
    }
}
```

### 3.2 WebSocket API - 实时识别

#### 3.2.1 发送控制消息

**方法签名**：
```java
public void realtimeControl(RealtimeRequest request)
```

**功能**：发送控制消息（启动/结束任务）

**实现逻辑**：
```java
public void realtimeControl(RealtimeRequest request) {
    try {
        String message = (new ObjectMapper()).writeValueAsString(request);
        this.webSocketClient.sendText(message);
    }
    catch (JsonProcessingException e) {
        throw new RuntimeException(e);
    }
}
```

**控制消息类型**：
- `RUN_TASK`: 启动识别任务
- `FINISH_TASK`: 结束识别任务

---

#### 3.2.2 实时流式识别

**方法签名**：
```java
public Flux<RealtimeResponse> realtimeStream(Flux<ByteBuffer> audio)
```

**功能**：发送音频流，实时接收识别结果

**实现逻辑**：
```java
public Flux<RealtimeResponse> realtimeStream(Flux<ByteBuffer> audio) {
    return this.webSocketClient.streamTextOut(audio).handle((msg, sink) -> {
        try {
            // 将接收的JSON字符串转换为对象
            sink.next((new ObjectMapper()).readValue(msg, RealtimeResponse.class));
        }
        catch (JsonProcessingException e) {
            sink.error(new DashScopeException(String.valueOf(e)));
        }
    });
}
```

**实时识别流程**：
```
1. 发送 RUN_TASK 控制消息
   ↓
2. 开始发送音频数据流（ByteBuffer）
   ↓
3. 实时接收识别结果（RealtimeResponse）
   ↓
4. 发送 FINISH_TASK 控制消息
   ↓
5. 完成识别
```

## 五、使用示例

### 5.1 REST异步识别

```java
// 创建API实例
DashScopeAudioTranscriptionApi api = DashScopeAudioTranscriptionApi.builder()
    .apiKey(new SimpleApiKey("your-api-key"))
    .model("paraformer-realtime-v2")
    .restClientBuilder(RestClient.builder())
    .build();

// 构建请求
DashScopeAudioTranscriptionApi.Request request = 
    new DashScopeAudioTranscriptionApi.Request(
        "paraformer-realtime-v2",  // model
        new DashScopeAudioTranscriptionApi.Request.Input(
            List.of("https://example.com/audio.wav")  // 音频文件URL
        ),
        new DashScopeAudioTranscriptionApi.Request.Parameters(
            null,   // channelId
            null,   // vocabularyId
            null,   // phraseId
            true,   // disfluencyRemovalEnabled: 去除口语化
            List.of("zh", "en")  // languageHints
        )
    );

// 提交任务
ResponseEntity<DashScopeAudioTranscriptionApi.Response> submitResponse = 
    api.call(request);

String taskId = submitResponse.getBody().output().taskId();
System.out.println("任务ID: " + taskId);

// 轮询任务状态
while (true) {
    ResponseEntity<DashScopeAudioTranscriptionApi.Response> queryResponse = 
        api.callWithTaskId(request, taskId);
    
    DashScopeAudioTranscriptionApi.TaskStatus status = 
        queryResponse.getBody().output().taskStatus();
    
    System.out.println("任务状态: " + status);
    
    if (status == DashScopeAudioTranscriptionApi.TaskStatus.SUCCEEDED) {
        // 获取结果URL
        String transcriptionUrl = queryResponse.getBody()
            .output()
            .results()
            .get(0)
            .transcriptionUrl();
        
        // 下载识别结果
        DashScopeAudioTranscriptionApi.Outcome outcome = 
            api.getOutcome(transcriptionUrl);
        
        // 输出识别文本
        String text = outcome.transcripts().get(0).text();
        System.out.println("识别结果: " + text);
        break;
    }
    else if (status == DashScopeAudioTranscriptionApi.TaskStatus.FAILED) {
        System.err.println("识别失败");
        break;
    }
    
    Thread.sleep(3000);  // 等待3秒后重试
}
```

### 5.2 WebSocket实时识别

```java
// 创建API实例
DashScopeAudioTranscriptionApi api = DashScopeAudioTranscriptionApi.builder()
    .apiKey(new SimpleApiKey("your-api-key"))
    .model("paraformer-realtime-v2")
    .webSocketUrl("wss://dashscope.aliyuncs.com/ws")
    .restClientBuilder(RestClient.builder())
    .build();

// 构建控制请求
DashScopeAudioTranscriptionApi.RealtimeRequest runRequest = 
    new DashScopeAudioTranscriptionApi.RealtimeRequest(
        new DashScopeAudioTranscriptionApi.RealtimeRequest.Header(
            DashScopeWebSocketClient.EventType.RUN_TASK,
            UUID.randomUUID().toString(),
            "duplex"
        ),
        new DashScopeAudioTranscriptionApi.RealtimeRequest.Payload(
            "paraformer-realtime-v2",
            "audio", "asr", "recognition",
            new DashScopeAudioTranscriptionApi.RealtimeRequest.Payload.Input(),
            new DashScopeAudioTranscriptionApi.RealtimeRequest.Payload.Parameters(
                16000,  // sampleRate
                DashScopeAudioTranscriptionOptions.AudioFormat.PCM,
                true    // disfluencyRemovalEnabled
            )
        )
    );

// 发送启动消息
api.realtimeControl(runRequest);

// 读取音频文件并创建音频流
Resource audioResource = new FileSystemResource("audio.wav");
Flux<ByteBuffer> audioStream = DataBufferUtils
    .read(audioResource, new DefaultDataBufferFactory(), 16384)
    .map(dataBuffer -> {
        byte[] bytes = new byte[dataBuffer.readableByteCount()];
        dataBuffer.read(bytes);
        ByteBuffer byteBuffer = ByteBuffer.wrap(bytes);
        DataBufferUtils.release(dataBuffer);
        return byteBuffer;
    })
    .delayElements(Duration.ofMillis(100))  // 控制发送速度
    .doOnComplete(() -> {
        // 音频发送完成，发送结束消息
        DashScopeAudioTranscriptionApi.RealtimeRequest finishRequest = 
            new DashScopeAudioTranscriptionApi.RealtimeRequest(
                new DashScopeAudioTranscriptionApi.RealtimeRequest.Header(
                    DashScopeWebSocketClient.EventType.FINISH_TASK,
                    runRequest.header().taskId(),
                    "duplex"
                ),
                runRequest.payload()
            );
        api.realtimeControl(finishRequest);
    });

// 开始实时识别
Flux<DashScopeAudioTranscriptionApi.RealtimeResponse> resultStream = 
    api.realtimeStream(audioStream);

// 订阅结果
resultStream.subscribe(
    response -> {
        // 获取识别文本
        String text = response.payload()
            .output()
            .sentence()
            .text();
        
        if (text != null && !text.isEmpty()) {
            System.out.print(text + " ");
        }
    },
    error -> System.err.println("识别失败: " + error.getMessage()),
    () -> System.out.println("\n识别完成")
);
```

## 六、最佳实践

### 6.1 智能轮询策略（指数退避）

```java
public String waitForTaskCompletion(
        DashScopeAudioTranscriptionApi api, 
        String taskId) throws InterruptedException {
    
    int waitTime = 1000;  // 初始等待1秒
    int maxWaitTime = 10000;  // 最大等待10秒
    int attempts = 0;
    int maxAttempts = 60;  // 最多尝试60次
    
    DashScopeAudioTranscriptionApi.Request request = buildRequest(null);
    
    while (attempts < maxAttempts) {
        ResponseEntity<DashScopeAudioTranscriptionApi.Response> response = 
            api.callWithTaskId(request, taskId);
        
        DashScopeAudioTranscriptionApi.TaskStatus status = 
            response.getBody().output().taskStatus();
        
        if (status == DashScopeAudioTranscriptionApi.TaskStatus.SUCCEEDED) {
            // 成功，获取结果
            String transcriptionUrl = response.getBody()
                .output()
                .results()
                .get(0)
                .transcriptionUrl();
            
            DashScopeAudioTranscriptionApi.Outcome outcome = 
                api.getOutcome(transcriptionUrl);
            
            return outcome.transcripts().get(0).text();
        }
        else if (status == DashScopeAudioTranscriptionApi.TaskStatus.FAILED) {
            throw new RuntimeException("Transcription failed");
        }
        
        // 继续等待
        Thread.sleep(waitTime);
        
        // 指数退避
        waitTime = Math.min(waitTime * 2, maxWaitTime);
        attempts++;
    }
    
    throw new RuntimeException("Task timeout");
}
```

```java
// 如果音频不符合要求，可以使用FFmpeg转换
public void convertAudio(String inputPath, String outputPath) {
    ProcessBuilder pb = new ProcessBuilder(
        "ffmpeg",
        "-i", inputPath,
        "-ar", "16000",      // 采样率16kHz
        "-ac", "1",          // 单声道
        "-f", "wav",         // WAV格式
        outputPath
    );
    
    try {
        Process process = pb.start();
        process.waitFor();
    }
    catch (Exception e) {
        throw new RuntimeException("Audio conversion failed", e);
    }
}
```

### 6.3 错误处理

```java
public String safeTranscribe(String audioUrl) {
    try {
        DashScopeAudioTranscriptionApi.Request request = buildRequest(audioUrl);
        ResponseEntity<DashScopeAudioTranscriptionApi.Response> response = 
            api.call(request);
        
        if (response.getStatusCode().is2xxSuccessful()) {
            String taskId = response.getBody().output().taskId();
            return waitForTaskCompletion(api, taskId);
        }
        
        throw new RuntimeException("Failed to submit task");
    }
    catch (DashScopeException e) {
        logger.error("DashScope API error", e);
        return "[识别失败]";
    }
    catch (Exception e) {
        logger.error("Unexpected error", e);
        return "[系统错误]";
    }
}
```

### 7.1 关键注意事项

### 7.2 常见问题

**Q1: 如何提高识别准确率？**
```
A: 
1. 提供清晰的音频（减少噪音）
2. 使用热词定制
3. 指定语言提示
4. 使用合适的采样率
5. 去除背景音乐和杂音
```

**Q2: 如何处理长音频？**
```
A: 
1. 使用REST异步模式
2. 或切分成短音频分段识别
3. 最后拼接结果
```

**Q3: WebSocket连接超时怎么办？**
```
A: 
1. 实现重连机制
2. 设置合理的超时时间
3. 使用心跳保持连接
4. 监控网络质量
```

**Q4: 如何获取详细的时间戳？**
```
A: 
在Outcome对象中：
- Sentence包含句子级时间戳
- Word包含单词级时间戳
用于字幕生成、视频对齐等场景
```

**Q5: 支持多人对话识别吗？**
```
A: 
支持。在RealtimeResponse中包含：
- speakerId: 说话人ID
- channelId: 声道ID
可用于区分不同说话人
```
