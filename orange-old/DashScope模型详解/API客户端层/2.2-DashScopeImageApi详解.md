## 一、类概述

### 1.1 设计目的

`DashScopeImageApi` 是专门用于图像生成服务的HTTP客户端，负责与阿里云百炼的图像生成API进行通信。它是 `DashScopeImageModel` 的底层支持。

### 1.2 核心职责

```
┌─────────────────────────────────────┐
│     DashScopeImageModel             │
│   (图像生成模型)                     │
└──────────────┬──────────────────────┘
               │
               ↓
┌─────────────────────────────────────┐
│   DashScopeImageApi (本类)           │ ← 本文档介绍的核心
│  - 提交图像生成任务                  │
│  - 查询任务状态                      │
│  - 异步任务管理                      │
└──────────────┬──────────────────────┘
               │
               ↓
┌─────────────────────────────────────┐
│  DashScope Image Service            │
│  (阿里云百炼图像生成服务)            │
└─────────────────────────────────────┘
```

### 1.3 支持的功能

| 功能 | 方法 | 说明 |
|------|------|------|
| **提交任务** | `submitImageGenTask()` | 提交图像生成任务，返回taskId |
| **查询任务** | `getImageGenTaskResult()` | 查询任务状态和结果 |

## 三、核心功能

### 3.1 提交图像生成任务

**方法签名**：
```java
public ResponseEntity<DashScopeImageAsyncResponse> submitImageGenTask(
    DashScopeImageRequest request
)
```

**功能**：提交图像生成任务到DashScope服务

**实现逻辑**：
```java
public ResponseEntity<DashScopeImageAsyncResponse> submitImageGenTask(
        DashScopeImageRequest request) {
    
    // 1. 确定API端点
    String baseUrl = "/api/v1/services/aigc/";
    String model = request.model();
    
    // 2. 根据模型类型选择端点
    String endpoint = isImage2ImageModel(model) 
        ? "image2image"   // 图生图模型
        : "text2image";   // 文生图模型
    
    String url = baseUrl + endpoint + "/image-synthesis";
    
    // 3. 发送POST请求
    return this.restClient.post()
        .uri(url)
        .header(HEADER_ASYNC, ENABLED)  // 异步模式
        .body(request)
        .retrieve()
        .toEntity(DashScopeImageAsyncResponse.class);
}

// 判断是否为图生图模型
private boolean isImage2ImageModel(String model) {
    return model.equals(ImageModel.WANX2_1_IMAGE_EDIT.getValue())
        || model.equals(ImageModel.WANX_X_PAINTING.getValue())
        || model.equals(ImageModel.WANX_SKETCH_TO_IMAGE_LITE.getValue())
        || model.equals(ImageModel.IMAGE_OUT_PAINTING.getValue());
}
```

**关键点**：
- 使用 `X-DashScope-Async: enable` 头启用异步模式
- 根据模型类型自动选择 `text2image` 或 `image2image` 端点

### 3.2 查询任务结果

**方法签名**：
```java
public ResponseEntity<DashScopeImageAsyncResponse> getImageGenTaskResult(
    String taskId
)
```

**功能**：根据taskId查询任务状态和结果

**实现逻辑**：
```java
public ResponseEntity<DashScopeImageAsyncResponse> getImageGenTaskResult(
        String taskId) {
    
    return this.restClient.get()
        .uri("/api/v1/tasks/{task_id}", taskId)
        .retrieve()
        .toEntity(DashScopeImageAsyncResponse.class);
}
```

**任务状态**：
- `PENDING`: 等待中
- `RUNNING`: 执行中
- `SUCCEEDED`: 成功完成
- `FAILED`: 失败
- `UNKNOWN`: 未知状态

## 五、使用示例

### 5.1 基础文生图

```java
// 创建API实例
DashScopeImageApi api = DashScopeImageApi.builder()
    .baseUrl("https://dashscope.aliyuncs.com")
    .apiKey(new SimpleApiKey("your-api-key"))
    .restClientBuilder(RestClient.builder())
    .build();

// 构建请求
DashScopeImageApi.DashScopeImageRequest request = 
    new DashScopeImageApi.DashScopeImageRequest(
        "wanx-v1",  // 模型
        new DashScopeImageApi.DashScopeImageRequest.DashScopeImageRequestInput(
            "一只可爱的熊猫在竹林里",  // prompt
            null,   // negativePrompt
            null, null, null, null, null
        ),
        new DashScopeImageApi.DashScopeImageRequest.DashScopeImageRequestParameter(
            "<auto>",     // style
            "1024*1024",  // size
            1,            // n
            null, null, null, null, null, null, null, null, null
        )
    );

// 提交任务
ResponseEntity<DashScopeImageApi.DashScopeImageAsyncResponse> submitResponse = 
    api.submitImageGenTask(request);

String taskId = submitResponse.getBody().output().taskId();
System.out.println("任务ID: " + taskId);

// 轮询任务状态
while (true) {
    ResponseEntity<DashScopeImageApi.DashScopeImageAsyncResponse> queryResponse = 
        api.getImageGenTaskResult(taskId);
    
    String status = queryResponse.getBody().output().taskStatus();
    System.out.println("任务状态: " + status);
    
    if ("SUCCEEDED".equals(status)) {
        String imageUrl = queryResponse.getBody()
            .output()
            .results()
            .get(0)
            .url();
        System.out.println("图片URL: " + imageUrl);
        break;
    }
    else if ("FAILED".equals(status)) {
        System.err.println("生成失败: " + 
            queryResponse.getBody().output().message());
        break;
    }
    
    Thread.sleep(3000);  // 等待3秒后重试
}
```

## 六、最佳实践

### 6.1 轮询策略

```java
// 实现智能轮询（指数退避）
public String waitForTaskCompletion(DashScopeImageApi api, String taskId) 
        throws InterruptedException {
    
    int waitTime = 1000;  // 初始等待1秒
    int maxWaitTime = 10000;  // 最大等待10秒
    int attempts = 0;
    int maxAttempts = 60;  // 最多尝试60次
    
    while (attempts < maxAttempts) {
        ResponseEntity<DashScopeImageApi.DashScopeImageAsyncResponse> response = 
            api.getImageGenTaskResult(taskId);
        
        String status = response.getBody().output().taskStatus();
        
        if ("SUCCEEDED".equals(status)) {
            return response.getBody().output().results().get(0).url();
        }
        else if ("FAILED".equals(status)) {
            throw new RuntimeException("Image generation failed: " + 
                response.getBody().output().message());
        }
        
        Thread.sleep(waitTime);
        
        // 指数退避
        waitTime = Math.min(waitTime * 2, maxWaitTime);
        attempts++;
    }
    
    throw new RuntimeException("Task timeout");
}
```

### 6.2 错误处理

```java
public String safeSubmitTask(DashScopeImageApi api, 
                              DashScopeImageApi.DashScopeImageRequest request) {
    try {
        ResponseEntity<DashScopeImageApi.DashScopeImageAsyncResponse> response = 
            api.submitImageGenTask(request);
        
        if (response.getStatusCode().is2xxSuccessful()) {
            return response.getBody().output().taskId();
        }
        
        throw new RuntimeException("Failed to submit task");
    }
    catch (Exception e) {
        logger.error("Error submitting image generation task", e);
        return null;
    }
}
```

### 6.3 批量任务管理

```java
public class BatchImageGenerator {
    
    private final DashScopeImageApi api;
    
    public Map<String, String> batchGenerate(List<String> prompts) {
        Map<String, String> taskIds = new HashMap<>();
        
        // 1. 批量提交任务
        for (String prompt : prompts) {
            DashScopeImageApi.DashScopeImageRequest request = buildRequest(prompt);
            ResponseEntity<DashScopeImageApi.DashScopeImageAsyncResponse> response = 
                api.submitImageGenTask(request);
            
            String taskId = response.getBody().output().taskId();
            taskIds.put(prompt, taskId);
        }
        
        // 2. 并发轮询所有任务
        Map<String, String> results = new ConcurrentHashMap<>();
        taskIds.entrySet().parallelStream().forEach(entry -> {
            try {
                String imageUrl = waitForTaskCompletion(api, entry.getValue());
                results.put(entry.getKey(), imageUrl);
            }
            catch (Exception e) {
                logger.error("Task failed: " + entry.getKey(), e);
            }
        });
        
        return results;
    }
}
```
