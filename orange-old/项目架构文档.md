## 项目概述

### 基本信息
- **项目名称**: Spring AI Alibaba
- **当前版本**: 1.1.0.0-SNAPSHOT
- **JDK 版本要求**: JDK 17+
- **Spring Boot 版本**: 3.4.8
- **Spring AI 版本**: 1.0.1
- **开源协议**: Apache License 2.0
- **官网**: https://java2ai.com

### 项目定位
Spring AI Alibaba 是一款以 Spring AI 为基础，深度集成阿里云百炼平台，支持 ChatBot、工作流、多智能体应用开发模式的企业级 AI 应用框架。

### 核心特性
1. **Graph 多智能体框架** - 支持工作流和多智能体应用编排
2. **企业级 AI 生态集成** - 深度集成百炼平台、ARMS、Nacos等
3. **通用智能体产品与平台** - JManus、DeepResearch 等智能体实现

### 2. spring-ai-alibaba-graph-core (Graph 多智能体框架)

#### 功能概述
Spring AI Alibaba Graph 是一款工作流和多智能体框架，用于构建复杂的 AI 应用流程编排。设计理念参考 LangGraph，增强了与 Spring 生态的集成。

#### 核心概念

##### 2.1 StateGraph (状态图)

**定义**
```java
com.alibaba.cloud.ai.graph.StateGraph

// 状态图定义工作流的主类
StateGraph graph = new StateGraph("workflow-name", stateFactory)
    .addNode("node1", nodeAction)
    .addNode("node2", nodeAction)
    .addEdge(START, "node1")
    .addConditionalEdges("node1", edgeAction, edgeMapping)
    .addEdge("node2", END);
```

**核心功能**
- 添加节点 (addNode)
- 添加边 (addEdge)
- 添加条件边 (addConditionalEdges)
- 支持子图嵌套
- 图结构校验
- 编译为可执行图

##### 2.2 Node (节点)

**节点类型**

1. **同步节点**
```java
public interface NodeAction {
    NodeOutput apply(OverAllState state);
}
```

2. **异步节点**
```java
node_async(NodeAction action)
// 包装为异步执行
```

**预定义节点**
```java
// 分类节点
QuestionClassifierNode - 问题分类
// HTTP 节点
HttpNode - HTTP 请求
// LLM 节点
LLMNode - 大模型调用
```

##### 2.3 Edge (边)

**边类型**

1. **普通边**
```java
.addEdge(START, "nextNode")
```

2. **条件边**
```java
public interface EdgeAction {
    String apply(OverAllState state);
}

.addConditionalEdges("node", edgeAction, 
    Map.of(
        "condition1", "nextNode1",
        "condition2", "nextNode2"
    ))
```

##### 2.4 OverAllState (全局状态)

**状态管理**
```java
com.alibaba.cloud.ai.graph.state.OverAllState

// 状态工厂
OverAllStateFactory stateFactory = () -> {
    OverAllState state = new OverAllState();
    // 注册状态键和更新策略
    state.registerKeyAndStrategy("input", new ReplaceStrategy());
    state.registerKeyAndStrategy("messages", new AppendStrategy());
    return state;
};
```

**状态策略**
- **ReplaceStrategy**: 替换策略 (覆盖旧值)
- **AppendStrategy**: 追加策略 (列表追加)
- **MergeStrategy**: 合并策略 (Map 合并)

##### 2.5 CompiledGraph (已编译图)

**编译和执行**
```java
// 编译配置
CompileConfig config = CompileConfig.builder()
    .withLifecycleListener(listener)
    .build();

// 编译
CompiledGraph compiledGraph = stateGraph.compile(config);

// 执行
Optional<OverAllState> result = compiledGraph.invoke(inputMap);

// 流式执行
Flux<NodeOutput> stream = compiledGraph.stream(inputMap);
```

#### Agent 类型

##### React Agent
```java
com.alibaba.cloud.ai.graph.agent.ReactAgent
- Reasoning and Acting 模式
- 支持工具调用
- 支持自主推理
```


#### 可视化支持

**导出格式**
- PlantUML 格式
- Mermaid 格式
- 支持在线可视化调试

#### 高级特性

1. **Human-in-the-loop** - 人工干预节点
2. **Checkpoint** - 流程快照和恢复
3. **Parallel Execution** - 并行节点执行

### 3. spring-ai-alibaba-mcp (MCP 工具集成)

#### 功能概述
MCP (Model Context Protocol) 是一个用于工具集成的标准协议。Spring AI Alibaba MCP 提供企业级的 MCP 实现，支持分布式注册发现、自动路由等功能。

#### 模块结构

```
spring-ai-alibaba-mcp/
├── spring-ai-alibaba-mcp-common     # 通用组件
├── spring-ai-alibaba-mcp-registry   # MCP 注册中心
├── spring-ai-alibaba-mcp-router     # MCP 路由器
├── spring-ai-alibaba-mcp-discovery  # 服务发现
├── spring-ai-alibaba-mcp-gateway    # MCP 网关
└── spring-ai-alibaba-mcp-recovery   # 容错恢复
```

#### 核心组件

**架构设计**

### 4. spring-ai-alibaba-a2a (Agent-to-Agent 通信)

#### 功能概述
A2A (Agent-to-Agent) 协议支持多个智能体之间的标准化通信。基于 JSON-RPC 2.0 和 HTTP/SSE 实现。

#### 架构设计

```
┌──────────────┐                    ┌──────────────┐
│   Agent A    │◄────JSON-RPC────►│   Agent B    │
│  (A2A Client)│                    │ (A2A Server) │
└──────┬───────┘                    └──────┬───────┘
       │                                   │
       │ 1. AgentCard 获取                 │
       │    GET /.well-known/agent.json    │
       ├───────────────────────────────────►
       │◄───────────────────────────────────┤
       │                                   │
       │ 2. 发送消息                        │
       │    POST /a2a                      │
       ├───────────────────────────────────►
       │                                   │
       │ 3. SSE 流式响应                    │
       │◄───────────────────────────────────┤
       │                                   │
```

#### 核心组件

##### 4.1 A2A Server

**服务端处理器**
```java
com.alibaba.cloud.ai.a2a.server.JsonRpcA2aRequestHandler

// 核心功能
- getAgentCard(): 返回智能体能力卡片
- onHandler(): 处理 JSON-RPC 请求
- 支持流式和非流式响应
```

**Agent 执行器**
```java
com.alibaba.cloud.ai.a2a.server.GraphAgentExecutor

// 基于 Graph Agent 的执行
- 支持 ReactAgent
- 支持流式执行
- 支持上下文管理
```

**路由配置**
```java
com.alibaba.cloud.ai.a2a.route.JsonRpcA2aRouterProvider

// 路由端点
GET  /.well-known/agent.json  -> AgentCard
POST /a2a                      -> Message Handler
```

##### 4.2 A2A Client

**客户端调用**
```java
// 通过 A2A SDK 实现
io.github.a2asdk:a2a-java-sdk-client

// 支持同步和异步调用
// 自动处理 JSON-RPC 协议
```

##### 4.3 协议规范

**Agent Card 结构**
```json
{
  "name": "agent-name",
  "version": "1.0.0",
  "protocolVersion": "0.2.5",
  "description": "Agent description",
  "capabilities": {
    "streaming": true
  },
  "transport": {
    "type": "JSONRPC",
    "endpoint": "http://host:port/a2a"
  }
}
```

**消息格式**
```json
{
  "jsonrpc": "2.0",
  "method": "agent/message/send",
  "params": {
    "message": {
      "parts": [
        {
          "kind": "text",
          "text": "用户输入内容"
        }
      ]
    },
    "metadata": {
      "streaming": true
    }
  },
  "id": "request-id"
}
```

### 5. Graph 工作流

```java
@Configuration
public class WorkflowConfig {
    
    @Bean
    public StateGraph workflowGraph(ChatClient chatClient) {
        // 状态工厂
        OverAllStateFactory stateFactory = () -> {
            OverAllState state = new OverAllState();
            state.registerKeyAndStrategy("input", new ReplaceStrategy());
            state.registerKeyAndStrategy("output", new ReplaceStrategy());
            return state;
        };
        
        // 构建图
        return new StateGraph("workflow", stateFactory)
            .addNode("analyze", analyzeNode(chatClient))
            .addNode("process", processNode(chatClient))
            .addNode("summarize", summarizeNode(chatClient))
            .addEdge(START, "analyze")
            .addEdge("analyze", "process")
            .addEdge("process", "summarize")
            .addEdge("summarize", END);
    }
    
    private NodeAction analyzeNode(ChatClient chatClient) {
        return state -> {
            String input = state.get("input");
            String result = chatClient.prompt()
                .user("分析：" + input)
                .call()
                .content();
            state.put("analysis", result);
            return NodeOutput.of(state);
        };
    }
}
```
