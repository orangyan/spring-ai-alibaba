### 架构说明

**应用层**
- 基于框架构建的实际应用
- JManus: 通用智能体平台
- DeepResearch: 深度研究智能体
- Playground: 示例和演示应用

**框架层**
- Graph: 工作流和多智能体编排
- A2A: 智能体间标准通信
- MCP: 工具协议集成
- NL2SQL: 自然语言转SQL

**核心层**
- 各种模型的抽象和实现
- Agent 基础能力
- 文档处理和 RAG

**集成层**
- 与外部服务的集成
- 模型服务、数据库、监控

**基础设施层**
- Spring 生态基础组件
- 响应式编程支持
- 可观测性基础

4. **Starter 封装**: 整合自动配置和依赖，开发者直接使用

## 数据流图

### 1. 请求响应数据流

```
HTTP Request
     │
     ├─→ Headers (API Key, Content-Type)
     ├─→ Body (JSON)
     │   {
     │     "message": "用户输入",
     │     "conversationId": "xxx",
     │     "options": {...}
     │   }
     │
     ↓
Controller
     │
     ├─→ 参数验证
     ├─→ 认证授权
     │
     ↓
Service Layer
     │
     ├─→ ChatClient.prompt()
     ├─→ 构建 Prompt 对象
     │   Prompt {
     │     instructions: [Message],
     │     options: ChatOptions
     │   }
     │
     ↓
Advisor Chain
     │
     ├─→ DocumentRetrievalAdvisor
     │   增强 Prompt (添加检索文档)
     │
     ├─→ MessageChatMemoryAdvisor
     │   添加历史消息
     │
     ↓
ChatModel
     │
     ├─→ DashScopeApi
     ├─→ HTTP POST to DashScope
     │   {
     │     "model": "qwen-max",
     │     "messages": [...],
     │     "temperature": 0.7,
     │     "stream": false
     │   }
     │
     ↓
DashScope Service
     │
     ├─→ 模型推理
     ├─→ Token 计费
     │
     ↓
HTTP Response
     │
     ├─→ ChatResponse
     │   {
     │     "choices": [{
     │       "message": {
     │         "role": "assistant",
     │         "content": "AI回答..."
     │       }
     │     }],
     │     "usage": {
     │       "promptTokens": 50,
     │       "completionTokens": 100
     │     }
     │   }
     │
     ↓
Return to User
```
